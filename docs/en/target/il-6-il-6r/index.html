JAK–STAT · downstream JAK (pan) / JAK1 / JAK2 / TYK2
IL-4Rα / IL-13 / IL-6 / IL-6R / IL-23 / IL-23R / IL-2 (receptor) / IL-15 / IFNAR / type I interferon / IL-12 → JAK (pan) / JAK1 / JAK2 / TYK2 → STAT3 / STAT6
Cytokine receptors activate STATs via JAKs; IL-4/IL-13 signal through STAT6, IL-6 and IL-23 through STAT3.
Innate immunity and inflammasome · upstream IRAK4 / NLRP3 / STING / ENPP1
TLR7/8/9 / TLR4 → IRAK4 / NLRP3 / STING / ENPP1 → IL-1β / IL-1R / IL-18 / IL-6 / IL-6R / IFNAR / type I interferon
TLRs signal through IRAK4; the NLRP3 inflammasome makes IL-1β and IL-18; STING senses cytosolic DNA and ENPP1 degrades its messenger cGAMP.
