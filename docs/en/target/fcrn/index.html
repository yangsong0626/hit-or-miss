Class and pathways

Class: Cytokines and immune receptors › Lymphocyte trafficking and IgG recycling
Same family: α4β7 integrin · VAP-1 · Galectin-3 · GAD65 (antigen-specific immunity)

Plasma cells and pathogenic IgG · upstream BCMA / CD38
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL sustain plasma cells (BCMA, CD38), which make IgG that FcRn recycles; blocking FcRn clears pathogenic antibodies.
