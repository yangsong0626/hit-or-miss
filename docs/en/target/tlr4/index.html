Innate immunity and inflammasome · downstream IRAK4 / NLRP3 / STING / ENPP1
TLR7/8/9 / TLR4 → IRAK4 / NLRP3 / STING / ENPP1 → IL-1β / IL-1R / IL-18 / IL-6 / IL-6R / IFNAR / type I interferon
TLRs signal through IRAK4; the NLRP3 inflammasome makes IL-1β and IL-18; STING senses cytosolic DNA and ENPP1 degrades its messenger cGAMP.
