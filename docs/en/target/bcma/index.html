Class and pathways

Class: Tumour surface antigens (ADC, bispecific, CAR-T) › Haematological antigens
Same family: CD19 · CD20 · CD22 · CD3 · GPRC5D · FcRH5 · CD38 · CD123 · CD33 · CLL1 / CD371 · CD7 · CD30 · CD70

Plasma cells and pathogenic IgG · upstream BAFF / APRIL · downstream FcRn
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL sustain plasma cells (BCMA, CD38), which make IgG that FcRn recycles; blocking FcRn clears pathogenic antibodies.

Ligand–receptor: BAFF / APRIL
Common bispecific pairing: CD3
