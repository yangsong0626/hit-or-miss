Class and pathways

Class: Cytokines and immune receptors › Interferons and B-cell factors
Same family: IFNAR / type I interferon · BDCA2

Plasma cells and pathogenic IgG · downstream BCMA / CD38
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL sustain plasma cells (BCMA, CD38), which make IgG that FcRn recycles; blocking FcRn clears pathogenic antibodies.

Ligand–receptor: BCMA
