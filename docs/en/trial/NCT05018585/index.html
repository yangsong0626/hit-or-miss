DIAGNODE-3 NCT05018585

A Phase III Study to Investigate if the Study Drug Diamyd Can Preserve Insulin Production and Improve Glycemic Control in Patients Newly Diagnosed With Type 1 Diabetes

Missed

  • Design: randomised, quadruple-blind, placebo-controlled
  • actual enrollment n=321

Likely reasons

  • Sponsor's stated reason classified as “Efficacy / futility”

Editor’s analysis

Efficacy failure. DIAGNODE-3 tested intralymphatic GAD antigen vaccine to preserve residual β-cell function in type 1 diabetes; a futility analysis triggered termination. Antigen-specific immune tolerance has repeatedly failed in type 1 diabetes, and the HLA-subtype-based positive signal from phase 2 did not replicate in phase 3.

Why it stopped

Efficacy / futility · “Stopped for futility.”
