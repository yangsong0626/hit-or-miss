ECHELON-3 NCT04404283

Brentuximab Vedotin Plus Lenalidomide and Rituximab for the Treatment of Relapsed/Refractory DLBCL

Met

  • Primary endpoint “Overall Survival (OS)”: Hazard Ratio (HR) 0.68 (95% CI 0.50–0.92), p==0.0127
  • Design: randomised, triple-blind, active-controlled
  • actual enrollment n=240
  • Serious adverse events: Brentuximab Vedotin + Lenalidomide + Rituximab 65%; Placebo + Lenalidomide + Rituximab 51%

Likely reasons

  • The confidence interval is close to the line of no effect; the effect is modest, so check whether secondary endpoints and subgroups agree
  • Won against an active comparator, which is more clinically meaningful
  • Serious adverse event rates differ by 14 percentage points across arms; safety needs attention
