Efficacy and Safety of Pembrolizumab Plus Investigational Agents in Combination With Chemotherapy as First-Line Treatment in Extensive-Stage Small Cell Lung Cancer (ES-SCLC) (MK-3475-B99/ KEYNOTE-B99)

No statistical test

  • Primary endpoint “Objective Response Rate (ORR) as Assessed by Blinded Indepen”: Pembrolizumab + MK-4830 + Chemotherapy 65.10 Percentage o; Pembrolizumab + Boserolimab + Chemotherapy 73.20 Percentage o; Pembrolizumab + Lenvatinib + Chemotherapy 73.70 Percentage o
  • Design: randomised, open-label, multi-arm
  • actual enrollment n=122
  • Serious adverse events: MK-4830 + Pembrolizumab + Etoposide/Platinum 30%; MK-5890 + Pembrolizumab +Etoposide/Platinum 39%; Lenvatinib +Pembrolizumab + Etoposide/Platinum 66%

Likely reasons

  • There is a control arm but no registered test of the primary endpoint; only the gap between arms can be seen
