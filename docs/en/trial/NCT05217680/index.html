PRO-169 NCT05217680

Clinical Study to Evaluate PRO-169 for Diabetic Macular Edema

No statistical test

  • Primary endpoint “Best Corrected Visual Acuity”: PRO-169 4.89 Letters; Lucentis ® 5.55 Letters
  • Design: randomised, double-blind, active-controlled
  • actual enrollment n=509
  • Serious adverse events: PRO-169 1%; Lucentis ® 1%

Likely reasons

  • There is a control arm but no registered test of the primary endpoint; only the gap between arms can be seen

Editor’s analysis

Met (possibly a non-inferiority or biosimilar comparison). PRO-169 vs ranibizumab in diabetic macular oedema had a best-corrected visual acuity difference of -1.5 letters, registered p<0.05. The difference suggests it shows equivalence to ranibizumab rather than superiority.
