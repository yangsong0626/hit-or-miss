BeyondSpring · Phase 3 · Oncology

DUBLIN-3 NCT02504489

Docetaxel + Plinabulin Compared to Docetaxel + Placebo in Patients With Advanced NSCLC

Met

  • Primary endpoint “Overall Survival”: Hazard Ratio (HR) 0.82 (95% CI 0.68–0.99), p=0.0399
  • Design: randomised, single-blind, active-controlled
  • actual enrollment n=559
  • Serious adverse events: Docetaxel (D) 33%; Docetaxel + Plinabulin (DP) 42%

Likely reasons

  • The confidence interval is close to the line of no effect; the effect is modest, so check whether secondary endpoints and subgroups agree
  • Won against an active comparator, which is more clinically meaningful
  • Serious adverse event rates differ by 9 percentage points across arms; safety needs attention

Editor’s analysis

Met. DUBLIN-3 in second-line advanced non-small cell lung cancer: plinabulin + docetaxel vs docetaxel, OS HR 0.82, p=0.04, with the upper confidence limit of 0.99 close to 1. A limited benefit; the FDA earlier rejected its neutropenia-prevention application for insufficient data, so support for a filing is moderate.
