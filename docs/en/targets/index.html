Pathways: upstream to downstream 34

Arrows run upstream to downstream; slashes separate targets at the same step. Groups without arrows are related targets for one disease mechanism, not a cascade.

RAS–MAPK
EGFR / HER2 / HER3 / c-MET / ALK / ROS1 / RET / FGFR (pan) / TRK (NTRK) → SHP2 → RAS (pan / RAS-ON) / KRAS G12C / KRAS G12D / KRAS (pan / other mutations) → SHOC2 / RAF (pan) / BRAF → MEK → ERK
Growth-factor receptors activate RAS via SHP2, then RAF, MEK and ERK drive proliferation.
PI3K–AKT–mTOR
EGFR / HER2 / HER3 / Insulin receptor → PI3Kα / PI3K (other) → AKT → mTOR
Receptors activate PI3K, signalling through AKT to mTOR to control growth and metabolism.
Tumour angiogenesis
VEGF / VEGFR / Ang-2 / PDGFR / FGFR (pan)
VEGF, Ang-2, PDGF and FGF drive new vessel growth.
Hormone-driven cancers
KAT6 → ER (ESR1) / AR → CDK4/6
KAT6 controls ER transcription; ER drives breast cancer (via cyclin D and CDK4/6) and AR drives prostate cancer.
Cell cycle
CDK4/6 → CDK2 / CDC7 → WEE1 / PKMYT1 → Aurora A / PLK1 / KIF18A
CDK4/6 and CDK2 push G1/S; WEE1 and PKMYT1 gate G2/M; Aurora A, PLK1 and KIF18A run mitosis.
DNA damage response
ATM / ATR → WEE1 / PKMYT1 → PARP1 / PARP (pan) / POLQ (Polθ) / WRN
ATM and ATR sense damage and pause the cycle via WEE1; PARP, Polθ and WRN are repair routes that are synthetic-lethal with specific defects.
Apoptosis
BCL-2 / BCL-XL
BCL-2 family proteins block mitochondrial apoptosis.
JAK–STAT
IL-4Rα / IL-13 / IL-6 / IL-6R / IL-23 / IL-23R / IL-2 (receptor) / IL-15 / IFNAR / type I interferon / IL-12 → JAK (pan) / JAK1 / JAK2 / TYK2 → STAT3 / STAT6
Cytokine receptors activate STATs via JAKs; IL-4/IL-13 signal through STAT6, IL-6 and IL-23 through STAT3.
Type 2 inflammation
TSLP / IL-33 / ST2 → IL-4Rα / IL-13 / IL-5 / IL-5R / IL-31 / IL-31RA → STAT6
Damaged epithelium releases TSLP and IL-33, driving IL-4, IL-13 and IL-5 — asthma, atopic dermatitis and COPD exacerbations.
IL-23 / Th17
TL1A / IL-23 / IL-23R / IL-12 → IL-17A/F / TNF / IL-36R
IL-23 sustains Th17 cells producing IL-17A/F; TL1A promotes Th17, while TNF and IL-36 amplify gut, joint and skin inflammation.
Innate immunity and inflammasome
TLR7/8/9 / TLR4 → IRAK4 / NLRP3 / STING / ENPP1 → IL-1β / IL-1R / IL-18 / IL-6 / IL-6R / IFNAR / type I interferon
TLRs signal through IRAK4; the NLRP3 inflammasome makes IL-1β and IL-18; STING senses cytosolic DNA and ENPP1 degrades its messenger cGAMP.
B-cell receptor signalling
CD19 / CD22 / CD20 → BTK
CD19 and CD22 are BCR co-receptors signalling through BTK; CD20 is the target for B-cell depletion.
Plasma cells and pathogenic IgG
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL sustain plasma cells (BCMA, CD38), which make IgG that FcRn recycles; blocking FcRn clears pathogenic antibodies.
T-cell checkpoints
PD-1 / PD-L1 / CTLA-4 / LAG-3 / TIGIT / TIM-3 / NKG2A / ILT2 / ILT4 (LILRB) / CBL-B / HPK1
PD-1 and CTLA-4 came first; LAG-3, TIGIT, TIM-3 and NKG2A are the usual add-ons; CBL-B and HPK1 are intracellular brakes.
Adenosine suppression
CD39 → CD73 → Adenosine A2A/A2B
CD39 and CD73 convert ATP to adenosine, which suppresses T cells through A2A/A2B.
“Don't eat me” signal
CD47 → SIRPα
CD47 on tumour cells binds SIRPα on macrophages to block phagocytosis.
Co-stimulation
CD40 / CD40L / OX40 / OX40L / 4-1BB
OX40/OX40L, 4-1BB and CD40/CD40L boost T cells and antigen presentation; in autoimmunity they are blocked instead.
Incretins and body weight
GLP-1R / GIPR / Glucagon receptor (GCGR) / Amylin receptor / MC4R / GDF15 / GFRAL / FGF21 / Myostatin / GDF8 / Activin / ActRII / ALK7
GLP-1R, GIPR, glucagon and amylin receptors are the core of obesity drugs; MC4R sits in the hypothalamus; GDF15, FGF21 and muscle preservation (myostatin/ActRII) are add-ons.
Lipids
PCSK9 / ANGPTL3 / APOC3 / Lp(a) / CETP
PCSK9 degrades the LDL receptor; ANGPTL3 and APOC3 inhibit lipoprotein lipase; Lp(a) and CETP are separate risk pathways.
Fatty liver (MASH)
THR-β / FGF21 / FXR / FASN / PNPLA3 / GLP-1R
THR-β, FGF21 and FXR improve liver fat metabolism; FASN blocks de-novo lipogenesis; PNPLA3 is the genetic risk gene.
RAAS and blood pressure
Renin / AGT → AT1 receptor / Aldosterone synthase (CYP11B2) → Mineralocorticoid receptor / Endothelin receptor
Renin cleaves AGT to make angiotensin acting on AT1; aldosterone synthase makes aldosterone acting on the mineralocorticoid receptor; endothelin is a separate vasoconstrictor axis.
Coagulation
Factor XII / Tissue factor (TF) → Factor XI / TFPI → FVIII mimetic (FIXa × FX) → Antithrombin
The contact path runs FXII → FXI; the extrinsic path starts with tissue factor and is held back by TFPI; both are amplified by FVIII/FIX into thrombin, which antithrombin shuts off. Haemophilia drugs rebalance via FVIII mimetics, TFPI or antithrombin.
Platelets
VWF / P2Y12
VWF mediates platelet adhesion and P2Y12 platelet activation.
Kallikrein–bradykinin
Factor XII → Kallikrein (KLKB1) → Bradykinin B2 receptor
FXII activates plasma kallikrein, releasing bradykinin acting on the B2 receptor — the driver of hereditary angioedema attacks.
Complement
C1s / C1q / MASP-2 / MASP-3 / Complement factor B / Complement factor D → Complement C3 → Complement C5
Classical (C1s/C1q), lectin (MASP-2) and alternative (factors B and D) paths converge on C3, then C5 and the membrane attack complex.
Iron and red cells
TMPRSS6 / hepcidin / TfR1 / Pyruvate kinase (PKR) / Hb / HbF induction
TMPRSS6 suppresses hepcidin; TfR1 takes up iron; PKR activators and HbF inducers treat haemolytic anaemias.
TGF-β superfamily
TGF-β / Activin / ActRII / Myostatin / GDF8 → ALK2 (ACVR1) / ALK7
TGF-β, activins, myostatin and GDFs signal through ALK receptor kinases; ALK2 mutations cause FOP.
Developmental signalling
Wnt pathway / Hedgehog / SMO / TEAD
Wnt, Hedgehog and Hippo–TEAD pathways are hijacked in some cancers.
Alzheimer's disease
β-amyloid → Tau
Amyloid cascade: amyloid-β deposits first, then tau tangles spread.
Parkinson's disease
LRRK2 / GCase / GBA → α-synuclein
LRRK2 and GCase are genetic risks converging on α-synuclein aggregation.
ALS and FTD
SOD1 / C9orf72 / Sortilin / progranulin / SARM1
SOD1 and C9orf72 cause ALS, progranulin loss causes FTD, and SARM1 drives axon degeneration.
Psychiatry and sleep
Dopamine receptor / Muscarinic M1/M4 / TAAR1 / 5-HT2A / NMDA receptor / κ-opioid receptor / GABA-A receptor / Orexin receptor
Schizophrenia is moving from dopamine receptors to muscarinic M1/M4 and TAAR1; depression has 5-HT2A psychedelics, NMDA and κ-opioid; sleep is the orexin receptors.
Pain, epilepsy and cough
Nav1.7 / Nav1.8 / Nav (other) / Kv7 (KCNQ) / SV2A / P2X3 / CGRP / CGRP receptor / FAAH / MAGL / CB1
Nav1.7/1.8 carry peripheral pain; Kv7 and SV2A treat epilepsy; P2X3 treats chronic cough; CGRP treats migraine.
Epigenetic and transcriptional dependencies
Menin / EZH2 / LSD1 / HDAC / SETDB1 / WDR5 / BRD4 / BET / CDK7 / CDK9
Menin–KMT2A drives specific leukaemias; EZH2, PRMT5, LSD1, BET and CDK7/CDK9 hit different points of transcriptional control.
