靶点小结

为什么重要

Galectin-3是一种β-半乳糖苷结合凝集素，主要由活化巨噬细胞分泌，可促进肌成纤维细胞活化和细胞外基质沉积，是肝、心、肾、肺纤维化的共同介质。它在NASH肝硬化中表达升高，阻断它被视为逆转纤维化、延缓门静脉高压的一条路径。

从临床结果学到了什么

  • 临床记录仍很单薄：本站追踪的唯一项目belapectin在NCT04365868中未能减少NASH肝硬化新发食管静脉曲张。按FDA意见，第一阶段作为独立试验分析，并非因安全性终止。未来6个月没有待读出的试验。

剩下的机会

  • 患者选择尚未检验。可假设循环Galectin-3水平较高或纤维化程度较轻的患者获益更多，NCT04365868的亚组和生物标志物分析可提供线索。
  • 本站追踪的项目只覆盖肝病，而Galectin-3在心衰、慢性肾病和肺纤维化中同样有生物学依据，这些适应症在本站仍是空白。
  • belapectin是静脉给药的复杂多糖。选择性更高的口服小分子或抗体在本站尚无追踪项目，与代谢类药物的联用也未经检验。
