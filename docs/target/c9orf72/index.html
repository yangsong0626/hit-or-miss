靶点小结

为什么重要

C9orf72第1内含子GGGGCC六核苷酸重复扩增是家族性和散发性ALS及FTD最常见的遗传病因。致病机制涉及三条途径：C9orf72蛋白功能丧失（损害自噬与溶酶体功能）、重复RNA形成核内聚集灶，以及RAN翻译产生有毒的二肽重复蛋白。因此，这一患者群体由基因定义，可明确识别。

从临床结果学到了什么

  • 临床证据仍很有限。本站目前仅追踪到1个项目：IRulya的小分子LAM-002A在ALS中开展的II期研究NCT05163886。该研究共15例受试者，主要终点为安全性和耐受性，属于无统计检验的读出，不能据此判断疗效。未来6个月内暂无已登记的读出可作为首个真正的检验。

剩下的机会

  • 本站追踪的唯一项目是作用于下游自噬/溶酶体通路的小分子。直接靶向重复RNA的手段，如ASO、siRNA或基因编辑，在本站数据中尚无项目，可作为验证RNA毒性假说的方向。
  • 可以考虑用脑脊液poly(GP)等二肽重复蛋白生物标志物做入组筛选和药效学读出，在小样本早期研究中先确认靶点调控，再推进疗效研究。
  • 在本站追踪的项目中，C9orf72相关FTD和症状前携带者均无项目覆盖。同一基因突变驱动ALS与FTD两种表型，适应症还有扩展空间。
