靶点小结

为什么重要

IKZF1/3（Ikaros/Aiolos）是淋巴细胞谱系的关键转录因子，多发性骨髓瘤细胞依赖其维持IRF4/MYC通路。lenalidomide、pomalidomide等IMiD通过cereblon（CRBN）诱导其降解，在杀伤肿瘤的同时增强T细胞功能，这一机制已获临床验证。新一代CELMoD追求更强、更快的降解。

从临床结果学到了什么

  • 本站尚未收录该靶点的任何读出或失败记录，临床证据仍偏少。首批关键检验将来自mezigdomide在多发性骨髓瘤中的两项III期（NCT05552976、NCT05519085），以及BMS-986369在复发/难治T细胞淋巴瘤中的I/II期（NCT06035497）。

剩下的机会

  • 本站收录的管线集中在多发性骨髓瘤，T细胞淋巴瘤仅有BMS-986369一项（NCT06035497）。可以检验的假说：IKZF依赖的T细胞或B细胞淋巴瘤亚型，可能成为差异化适应症。
  • IMiD经治患者常因CRBN通路改变而耐药，而收录管线几乎都是CRBN分子胶，且多数来自Bristol Myers Squibb。可以探索借助其他E3连接酶或不依赖CRBN的降解方式，并以CRBN状态作为入组标志物。
  • 目前收录的试验全部在肿瘤领域，与双抗联用的管线也只有一项。IKZF1/3降解能调节B细胞和T细胞，联合T细胞衔接器、或进入自身免疫病，是尚待检验的方向。
