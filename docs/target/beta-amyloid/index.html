靶点小结

为什么重要

淀粉样蛋白级联假说认为，APP裂解产生的Aβ聚集成寡聚体和斑块，进而引发tau病理、神经炎症和神经元丢失，最终导致阿尔茨海默病。APP、PSEN1/2致病突变、APOE4风险等位基因，以及降低Aβ生成的APP A673T保护性突变，为该靶点提供了人类遗传学证据。

从临床结果学到了什么

  • 目前临床记录仍很有限：本站跟踪的18个项目（其中6个处于3期）尚无已收录的读出或失败。首批检验将来自NCT03887455（Lecanemab 3期，早期阿尔茨海默病，主要完成日期2026年底）和NCT07213583（未披露药物的2期，ATTR心肌病，已过主要完成日期，结果尚待收录）。

剩下的机会

  • 本站跟踪的项目中，单抗占7个，且集中在Eli Lilly和Roche（包括Remternetug、Trontinemab）。小分子（如GAL-101 2期）和疫苗（Nuravax，1期）仍处于早期，可检验能否以口服或主动免疫方式实现长期维持或一级预防。
  • 明确针对认知正常的高危人群或临床前阿尔茨海默病的项目只有少数几个。结合血液生物标志物筛选入组，并更早开始干预，是否能扩大获益，仍是有待回答的问题。
  • Lewy小体病（1个项目）和ATTR心肌病（2个项目）提示了跨淀粉样蛋白病的方向。NCT07213583的结果将初步显示：清除淀粉样沉积物的思路能否从中枢延伸到心脏。
