靶点小结

为什么重要

NKG2A与CD94组成抑制性受体，表达于NK细胞和部分CD8+ T细胞，识别HLA-E后经ITIM向下传递抑制信号。许多肿瘤上调HLA-E，借此逃避NK和T细胞杀伤。阻断NKG2A有望同时释放先天和适应性免疫，并与PD-(L)1抑制互补。

从临床结果学到了什么

  • 本站追踪的NKG2A临床记录仍很薄：3个项目均处于1/2期，尚无读出、失败或终止记录，未来六个月内也没有追踪到达到主要完成日期的试验，近期尚无可检验该机制的数据节点。

剩下的机会

  • 本站追踪的项目集中在MSI-H/dMMR胃癌/胃食管结合部癌，另有NSCLC和转移性胰腺癌各1项。可检验的假设是：按肿瘤HLA-E表达或NKG2A+ CD8 TIL密度筛选患者，能否识别出获益人群。
  • 目前追踪到的形式只有单抗（S095029）和一项重组蛋白（HY-0102）。双特异性抗体、与可诱导ADCC的抗体联用，或在CAR-NK/T细胞中敲除NKG2A，都是本站尚未覆盖的思路。
  • 本站追踪的NKG2A试验全部属于肿瘤领域。鉴于NKG2A限制NK细胞和CD8+ T细胞功能，慢性病毒感染、移植后血液肿瘤复发等场景值得在机制层面进一步评估。
