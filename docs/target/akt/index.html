靶点小结

为什么重要

AKT（AKT1-3）是PI3K–AKT–mTOR通路的核心激酶，调控细胞增殖、存活和代谢。PIK3CA突变、PTEN缺失和AKT1 E17K突变都会使其过度激活，与HR阳性乳腺癌内分泌耐药及PTEN缺失前列腺癌进展相关。AKT2参与胰岛素信号，因此高血糖属于靶点相关毒性。

从临床结果学到了什么

  • 本站追踪范围内的临床记录仍然偏少。CAPItello-281（NCT04493853）在激素敏感性前列腺癌中达到rPFS主要终点；PROFECTA-II（NCT04374630）没有正式统计检验。下一个关键检验是capivasertib乳腺癌III期NCT06635447。

剩下的机会

  • 前列腺癌阳性结果（NCT04493853）提示AKT抑制在乳腺癌以外也可能有效。其他PTEN缺失瘤种，以及PROFECTA-II（NCT04374630）未作正式检验的卵巢癌，仍值得探索，可用PTEN或通路变异做患者筛选。
  • 不抑制AKT2的突变选择性或亚型选择性抑制剂，可能减轻高血糖并实现更充分的靶点抑制。Alterome、Atavistik、Terremoto的I期和I/II期项目将首次检验选择性能否拓宽治疗窗。
  • 本站追踪的8个项目均为小分子，降解剂等其他分子类型尚未出现，可尝试用来应对通路再激活引起的耐药。乳腺癌领域已有5个项目，三阴性和HER2-low亚群项目较少，可能是差异化方向。
