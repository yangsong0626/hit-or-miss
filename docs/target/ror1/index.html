靶点小结

为什么重要

ROR1是Wnt5a的受体，属癌胚抗原：胚胎期高表达，成人正常组织中表达很低，但在CLL、套细胞淋巴瘤及三阴乳腺癌、肺腺癌、卵巢癌等多种实体瘤中重新出现。它能促进肿瘤细胞存活和迁移，表达又相对局限于肿瘤，因此适合ADC、双抗和CAR-T等靶向肿瘤表面抗原的疗法。

从临床结果学到了什么

  • 目前临床证据很少。本站追踪的2个项目（CTTQ的ADC TQB2101、NEOK Bio的双抗）均在1期，尚无读出、失败或提前终止，未来6个月也没有到达主要完成日期的试验，首批1期数据才是第一次真正检验。

剩下的机会

  • 本站追踪的项目中，一个针对晚期血液肿瘤，一个针对晚期实体瘤，CAR-T等细胞疗法暂未出现。可以考虑在ROR1表达较高的CLL、套细胞淋巴瘤中验证细胞疗法。
  • 可以检验ROR1的IHC表达水平能否预测ADC或双抗的疗效，在三阴乳腺癌、肺腺癌、卵巢癌等瘤种中按表达分层入组，从而与不加筛选的篮式设计拉开差异。
  • ADC与双抗作用机制不同，可以对比两者在靶点表达偏低时的活性，以及在ROR1低表达正常组织中的毒性，这是早期数据最值得关注的问题。
