靶点小结

为什么重要

NTRK1/2/3分别编码TRKA/B/C。基因融合使激酶持续激活，驱动MAPK等通路。NTRK融合在常见实体瘤中很少见，但在婴儿型纤维肉瘤、分泌性癌等罕见肿瘤中高度富集。larotrectinib与entrectinib已获不限瘤种批准，验证了“按融合用药”的思路。

从临床结果学到了什么

  • 本站追踪的TRK临床记录仍然很少：目前没有已收录的读出或失败，未来6个月也没有项目到达主要完成节点。追踪到的最成熟项目是Bayer的larotrectinib 1/2期研究，但这里没有收录其结果，近期还不会有真正的检验。

剩下的机会

  • 一代TRK抑制剂治疗后常出现溶剂前沿区、xDFG等获得性耐药突变。本站追踪的早期小分子（Avistone的ANS03、Shenzhen NewDEL）是否针对耐药或入脑设计，目前不清楚，值得关注。
  • Toray的生物制品处于胃癌2期，腺样囊性癌和头颈癌也有项目在研，说明有人在探索不依赖融合的TRK靶向。TRK过表达而无融合时能否成药，取决于表达阈值等生物标志物的界定。
  • 适应症中出现了ROS1/NTRK融合实体瘤，提示有ROS1/TRK双靶点设计。如何与已上市药物形成差异（耐药谱、CNS活性、安全性），仍是开放问题。
