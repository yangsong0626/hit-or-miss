靶点小结

为什么重要

Sigma-1受体是位于内质网–线粒体接触面的分子伴侣，调节钙信号、内质网应激和自噬。SIGMAR1功能缺失突变可致青少年型ALS和远端遗传性运动神经病，提供了人类遗传学依据；激动剂和拮抗剂分别被用于探索神经退行性疾病、精神疾病和疼痛。

从临床结果学到了什么

  • 临床记录尚薄：此处仅追踪到2个小分子项目，即Anavex的一个II期项目和Luye的LY03015（I期），均无读出。未来6个月内也没有试验到达主要完成日，近期没有能真正检验该靶点的节点。

剩下的机会

  • 在此处追踪的项目中，尚无针对SIGMAR1突变相关运动神经元病的项目。在遗传学定义的人群中做概念验证，或可更直接地检验调节该受体能否改变病程。
  • 追踪项目中仅1个指向精神分裂症，且全部为小分子。可探索以SIGMAR1基因型或受体占有率PET作为患者分层和剂量选择工具，以便更清楚地识别疗效信号。
  • 此处未追踪到拮抗剂或疼痛适应症项目。Sigma-1拮抗在神经病理性疼痛中有临床前依据，在所追踪项目中仍属空白。
