靶点小结

为什么重要

P2X3是由ATP门控的阳离子通道，主要表达于迷走神经C纤维等初级感觉传入神经。气道炎症或损伤时释放的ATP激活P2X3，可使咳嗽反射敏化，被认为是难治性慢性咳嗽的核心机制之一。该通道也参与内脏痛和膀胱感觉，因此在咳嗽之外同样有合理的治疗依据。

从临床结果学到了什么

  • 临床记录仍很薄弱。本站目前仅追踪到一个项目，即Wuhan Createrna的一款针对咳嗽的2期小分子，尚无读出、终止记录，未来6个月内也没有到达主要完成日期的试验，暂时无法总结规律。

剩下的机会

  • P2X2/3异源三聚体存在于味觉传入神经，对P2X3同源三聚体的选择性可能决定味觉相关耐受性。值得验证高选择性分子能否在保持镇咳效果的同时减少味觉干扰。
  • 本站追踪的项目只覆盖咳嗽适应症。基于P2X3在内脏痛、膀胱过度活动和子宫内膜异位症疼痛中的生物学作用，这些适应症在本站记录中仍是空白，可作为研究假设。
  • 可探索以咳嗽高敏感性为生物标志物筛选患者（如辣椒素或ATP激发试验），用于检验富集人群能否放大疗效信号；本站追踪范围内尚无小分子以外的modality。
