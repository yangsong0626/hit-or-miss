靶点小结

为什么重要

IRAK4是TLR和IL-1受体家族下游Myddosome复合物的核心激酶，同时起支架作用，驱动NF-κB等炎症信号。MYD88 L265P突变通过这条通路驱动部分B细胞淋巴瘤。先天性IRAK4缺陷患者主要在儿童期易发化脓性细菌感染，其余方面基本正常，提示抑制该靶点的安全窗可能较宽。

从临床结果学到了什么

  • 临床证据仍很少：本站追踪的2个II期小分子项目（AstraZeneca、Leadingtac）尚无读出，也没有失败记录，未来6个月内没有追踪中的试验到达主要完成日期，近期没有可以检验该机制的数据。

剩下的机会

  • 本站追踪的试验同时覆盖COPD、特应性皮炎和血液肿瘤。在血液肿瘤中按MYD88 L265P等突变筛选患者，可能是最能直接检验通路依赖性的设计。
  • 追踪中的项目都是小分子，但现有信息无法区分激酶抑制剂和降解剂。IRAK4兼具激酶与支架功能，能否同时阻断两者，可能是与后来者拉开差距的关键问题。
  • 化脓性汗腺炎、类风湿关节炎、狼疮等IL-1/TLR驱动的疾病，在本站追踪的项目中还没有覆盖。长期给药时的细菌感染风险也值得系统监测。
