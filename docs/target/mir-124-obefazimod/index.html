靶点小结

为什么重要

Obefazimod（ABX464）是一种口服小分子，可结合帽结合复合物，促进一条长链非编码RNA的剪接，从而上调miR-124。miR-124能抑制IL-6/STAT3及Th17等炎症信号。其思路是在不造成广泛免疫抑制的前提下缓解溃疡性结肠炎和克罗恩病的肠道炎症，为注射类生物制剂提供口服替代方案。

从临床结果学到了什么

  • 临床证据仍然有限。ABX464的两项溃疡性结肠炎III期试验（NCT05507216、NCT05507203）在本站记录为无统计检验；ABX196肝细胞癌研究（NCT03897543）是描述性安全性研究，且作用机制可能与miR-124不同。未来六个月内暂无预计读出。

剩下的机会

  • 克罗恩病是最明确的待解问题。在本站追踪的项目中，仅有一项obefazimod II期研究针对该适应症，尚无读出。针对黏膜炎症的miR-124机制能否用于透壁性病变，目前仍未验证。
  • 已追踪试验中尚未见患者筛选策略。可以研究血液或结肠组织中miR-124的基线水平和治疗期间水平，看能否作为疗效预测或药效学标志物，帮助在口服与注射药物众多的领域中识别应答人群。
  • 本站追踪的项目均来自同一家公司的同一分子。其他miR-124诱导剂，以及obefazimod与现有先进疗法的联用，在本站追踪的项目中尚无人涉及。
