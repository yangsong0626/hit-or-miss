靶点小结

为什么重要

ACVR1编码BMP I型受体ALK2。经典FOP几乎都由R206H功能获得性突变引起：突变受体会对activin A产生异常应答，驱动异位骨化，遗传学验证非常明确。此外，DIPG中存在体细胞ACVR1突变，ALK2–hepcidin通路也与炎症性贫血相关。

从临床结果学到了什么

  • 临床证据仍很薄弱。本站仅追踪到Regeneron一项FOP III期单抗项目（2026年4月登记），目前没有读出，未来六个月内也没有试验达到主要完成，近期缺少可检验机制的数据。

剩下的机会

  • 本站追踪的项目只有抗体一种模式，小分子ALK2激酶抑制剂或选择性作用于突变受体的策略尚未出现。已有临床前研究提示部分ACVR1抗体可能激活突变受体，不同模式的比较值得探索。
  • 目前本站追踪的适应症仅限FOP。携带ACVR1突变的DIPG和hepcidin驱动的贫血在生物学上有依据，但尚无项目覆盖，可以作为扩展方向的假设。
  • FOP病程呈发作性，异位骨化进展缓慢。以影像学测得的新发骨化体积和发作频率作为终点并验证其可靠性，将决定Regeneron这项III期研究能否给出清晰结论。
