靶点小结

为什么重要

TLR4是识别细菌LPS及组织损伤释放的内源性危险信号的模式识别受体，经MyD88/TRIF通路驱动NF-κB与I型干扰素反应。过度激活与脓毒症、ARDS等炎症性肺损伤相关，因此可作为拮抗靶点；适度激活可增强适应性免疫，MPL等TLR4激动剂已作为疫苗佐剂使用。

从临床结果学到了什么

  • 临床证据仍然很薄。此处追踪的唯一读出是Edesa单抗在COVID-19中的2/3期试验NCT04401475，因商业原因提前终止，申办方明确表示与安全性无关，因此对机制有效性既无正面也无反面结论；未来6个月内也没有追踪到的试验到达主要完成节点。

剩下的机会

  • 拮抗TLR4能否降低炎症性肺损伤死亡率，这个问题仍未回答：NCT04401475因商业原因中止。可考虑转向非COVID病因的ARDS，并按炎症生物标志物富集高TLR4活性人群。
  • 两个1期项目分布在肺结核和黑色素瘤（包括黏膜型），可检验TLR4激活能否增强疫苗应答或抗肿瘤免疫；黏膜黑色素瘤对现有免疫治疗应答较差，适合作为联合用药的检验场景。
  • 在此追踪的项目中仅有单抗和重组蛋白，尚无小分子或口服药物，全领域仅3个项目，竞争稀疏；按激动或拮抗方向和组织靶向做出区分，仍有较大空间。
