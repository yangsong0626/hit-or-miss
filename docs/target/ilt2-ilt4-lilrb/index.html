靶点小结

为什么重要

LILRB1（ILT2）、LILRB2（ILT4）和LILRB4是髓系细胞、NK及T细胞上的抑制性受体，结合HLA-G等HLA I类分子后经ITIM传递抑制信号，维持肿瘤微环境的髓系免疫抑制。阻断后有望重塑巨噬细胞与MDSC表型，补足PD-1抑制剂未覆盖的髓系耐药。

从临床结果学到了什么

  • 临床证据仍很薄：本站追踪的5个项目均在1期或1/2期，尚无读出或失败记录，未来六个月亦无主要完成节点；最早的MK-4830（2019年起3项试验）结果仍待公开。

剩下的机会

  • 血液肿瘤布局稀少：本站追踪项目中AML和多发性骨髓瘤各仅1个。LILRB4在单核细胞型AML上高表达，可作直接靶向抗原，ADC或细胞疗法尚未见于追踪项目。
  • 患者筛选尚未建立：可检验肿瘤HLA-G表达或髓系细胞浸润程度能否富集获益人群，尤其在NSCLC、食管鳞癌、小细胞肺癌等已有项目覆盖的实体瘤中。
  • 多靶点设计仍属早期：仅Mabwell的6MW5311为双抗，2026年11月才首次登记。同时阻断ILT2与ILT4，或在单一分子中整合PD-(L)1阻断，能否优于单抗联用尚无数据。
