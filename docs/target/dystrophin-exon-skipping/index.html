靶点小结

为什么重要

DMD基因移码缺失导致肌营养不良蛋白缺失，引发Duchenne肌营养不良。外显子跳跃可恢复阅读框，产生截短但部分有功能的蛋白，类似病情较轻的Becker表型。每种药物只针对特定外显子（如44、45、51、53）的患者亚群。

从临床结果学到了什么

  • 目前追踪到的临床记录很少，没有已公布的读出，也没有失败记录。唯一的III期试验NCT03992430原定于2026-09-07达到主要完成，本站尚未追踪到其结果，这将是首个实质性检验。

剩下的机会

  • 本站追踪的9个项目中有4个是常规反义寡核苷酸（Sarepta、Biomarin、Daiichi Sankyo、NS）。Entrada和PepGen是2025年进入的新项目，未标注具体模式。可以检验的假设：提升骨骼肌和心肌递送效率、提高蛋白表达量，是与先行者拉开差距的主要途径。
  • 在本站追踪的项目中，明确指向外显子44的只有1个，其他较少见的外显子以及多外显子跳跃覆盖仍然很少。Roche和AO GENERIUM的基因治疗或编辑项目有望实现持久跳跃，可用于检验一次给药能否替代长期反复输注。
  • 蛋白表达量与功能获益之间的关系尚未确立。NCT03992430的结果加上Satellos的小分子项目，可以帮助判断单靠恢复肌营养不良蛋白是否足够，还是需要联合非蛋白恢复类的机制。
