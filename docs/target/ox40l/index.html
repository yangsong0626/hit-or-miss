靶点小结

为什么重要

OX40L主要表达于活化的抗原提呈细胞，与活化T细胞上的OX40结合，促进效应T细胞和记忆T细胞的存活与扩增，并推动Th2及其他炎症反应。阻断OX40L有望在上游重新调节T细胞失衡，而不只是抑制单一细胞因子，因此适用于特应性皮炎等多种T细胞驱动的免疫炎症疾病。

从临床结果学到了什么

  • 临床证据仍很有限。在本站追踪的项目中，两项Amlitelimab二期试验均已提前终止，分别为哮喘（NCT06033833）和斑秃（NCT06444451），原因是申办方决定，且明确与安全性无关，因此不能作为否定该机制的证据。首个真正的检验将是乳糜泻试验NCT06557772，其主要完成日期已过，结果尚待公布。

剩下的机会

  • 乳糜泻由麸质特异性T细胞驱动，与Th2型疾病不同。NCT06557772将检验OX40L阻断能否扩展到非Th2型自身免疫病。追踪的适应症中还有1型糖尿病，这一方向值得关注。
  • 哮喘和斑秃因商业原因停止，OX40L在这两个适应症中是否有效仍无答案。可以假设，按Th2高表达或T细胞活化标志物筛选的患者群体可能更适合重新验证。
  • 在本站追踪范围内，该靶点仅有Sanofi和Merck KGaA两家公司布局。Sanofi的双抗和Merck KGaA的一期生物制品提示，下一步的差异化可能来自同时阻断OX40L与另一条炎症通路，或延长给药间隔。
