靶点小结

为什么重要

MC4R位于下丘脑室旁核，接收leptin–POMC–α-MSH通路信号，调控饱腹感和能量消耗。MC4R功能缺失突变是最常见的单基因重度肥胖病因。上游通路受损时（如下丘脑损伤或POMC/LEPR缺陷），直接激动MC4R可以绕过病变。setmelanotide已获批用于部分单基因肥胖。

从临床结果学到了什么

  • 疗效取决于通路病变是否位于MC4R上游：下丘脑性肥胖的III期NCT05774756和II期NCT06046443均达到终点，而适应症标注为Obesity的III期NCT05093634未达到，提示患者选择是关键。
  • Rhythm的口服小分子在NCT06046443中复现了下丘脑性肥胖的BMI获益，提示该信号来自机制本身，与多肽剂型无关；但该试验仅28例、14周，持久性仍需验证。
  • 本站追踪的唯一失败是NCT05093634的疗效不足（同一试验记录了两次），没有安全性或商业原因的终止；所有项目均来自Rhythm一家公司，领域高度集中。

剩下的机会

  • Prader-Willi综合征是另一种下丘脑型疾病，NCT06772597已于2026年11月到达主要完成日期。其结果将检验PWS是否像下丘脑性肥胖一样对MC4R激动有应答。
  • 可对NCT05093634做基因型或通路生物标志物分层，找出更广泛肥胖人群中可能应答的亚组，并探索与incretin类药物联用，作为通路受损患者的补充机制。
  • 本站追踪的项目中，其他公司和其他模式（如长效制剂、偏向性激动剂）仍属空白；NCT06760546（2027年3月）将进一步检验下丘脑性肥胖的疗效重现性。
