靶点小结

为什么重要

TTR 主要由肝脏合成，以四聚体形式转运甲状腺素和视黄醇结合蛋白。四聚体解离后，单体错误折叠形成淀粉样纤维，沉积于心肌和周围神经，导致遗传型或野生型 ATTR。tafamidis 获批验证了稳定四聚体的思路，用沉默剂或基因编辑降低肝脏 TTR 合成是另一条路径。

从临床结果学到了什么

  • 此处追踪的临床记录仍较薄：唯一读出是 acoramidis 的 2 期描述性安全性研究（NCT03536767），标为商业原因的终止实为达成研究目标，不构成机制信号；未来六个月无追踪试验到达主要完成。

剩下的机会

  • CARDIO-TTRansform 中 eplontersen 未显著减少心血管事件，多数患者合用 TTR 稳定剂，未用稳定剂的亚组名义获益；可假设沉默剂的增量价值需在未用稳定剂或疾病进展人群中检验。
  • 追踪试验以心血管为主（13 项），神经 3 项、眼科仅 1 项；视网膜色素上皮和脉络丛自身合成 TTR，肝靶向药物难以覆盖，眼部与软脑膜 ATTR 仍是空白。
  • 在此处追踪的项目中，NTLA-2001 是唯一的基因编辑项目；一次性给药能否在持久性和安全性上与需长期给药的 siRNA、ASO 及稳定剂拉开差距，仍待回答。
