靶点小结

为什么重要

VEGF-A通过内皮细胞上的VEGFR2（KDR）驱动血管新生和血管渗漏，既为肿瘤供血，也是新生血管性眼病的核心介质。Bevacizumab、aflibercept等抗VEGF药物早已在肿瘤及nAMD、DME中获批，靶点验证充分，当前竞争集中在联合免疫、双抗和长效给药。

从临床结果学到了什么

  • PD-(L)1/VEGF双抗是本站追踪中数量最多的模态（23个项目），也带来了近期最明确的阳性结果：在一线晚期胆道癌中，ivonescimab联合化疗的OS优于durvalumab联合化疗（HARMONi-GI1）。
  • VEGFR TKI联合PD-1并非在所有瘤种中都有效：lenvatinib+pembrolizumab在宫颈癌中ORR未达到主要终点（NCT05007106），sitravatinib+nivolumab的III期OS未达标（NCT03906071），获益更像取决于适应症，而非类别效应。
  • 因商业原因终止的试验多于疗效失败（6比4）。lenvatinib食管癌（NCT04949256）、rivoceranib腺样囊性癌（NCT04119453）及申办方明确无安全性问题的axitinib联合方案（NCT05949632）都属于管线取舍，不能作为否定机制的证据。
  • 眼科领域机制已无悬念，近期读出多为安全性或描述性研究（NCT06491914、NCT06190093）；竞争转向降低注射负担，如EYP-1901、OTX-TKI等缓释TKI及11个基因治疗项目。

剩下的机会

  • nAMD长效化：EYP-1901（NCT06683742）、tarcocimab tedromer（NCT06556368）和ABBV-RGX-314（NCT04514653）待读出，将检验缓释或一次性给药能否以更少注射维持视力，以及各自适合哪类患者。
  • 双抗项目多集中在NSCLC和泛实体瘤；胆道癌结果提示，消化道肿瘤等PD-1单药疗效有限的领域可能仍有空间。能预测谁会从加用VEGF阻断中获益的生物标志物仍属空白，包括TKI+IO已失败的宫颈癌。
  • 罕见肿瘤研究不足：cabozantinib骨肉瘤研究因入组困难终止（NCT06341712），问题仍未回答；fruquintinib RCC（NCT05522231）和rivoceranib HCC（NCT04639180）的读出将显示新一代TKI能否在现有标准之上带来增益。
