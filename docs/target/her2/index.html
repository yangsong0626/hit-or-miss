靶点小结

为什么重要

HER2（ERBB2）是受体酪氨酸激酶，扩增或过表达时持续激活PI3K–AKT和RAS–MAPK通路，驱动约两成乳腺癌及部分胃癌、尿路上皮癌等。trastuzumab等药物早已验证该靶点；HER2突变还是部分NSCLC的独立驱动因素。

从临床结果学到了什么

  • HER2阳性乳腺癌近期两项III期均达到终点，分别为ADC（T-DXd新辅助pCR，NCT05113251）和小分子（tucatinib PFS，NCT05132582），两种药物形式都在继续拓展适用场景
  • ADC是最拥挤的赛道，占本站80个项目中的29个，SHR-A1811、TQB2102、disitamab vedotin、DP303c等多为中国企业；新闻显示T-Bren III期期中分析也达到终点，同类竞争加剧
  • poziotinib的NSCLC III期PINNACLE（NCT05378763）未入组即终止，原因为运营及与FDA协商重新设计，不构成对机制的否定；本站跟踪到的HER2突变肺癌项目已转向zongertinib、BAY 2927088等选择性TKI
  • 双抗zanidatamab的两项读出（NCT03929666、NCT04276493）以安全性和ORR为终点，无正式统计检验，双抗相对ADC的定位仍缺随机证据

剩下的机会

  • 乳腺癌以外适应症布局较少：胃癌（NCT04704934、NCT06221748）和尿路上皮癌（NCT05302284、NCT05911295）的读出将检验ADC能否复制乳腺癌的获益，宫颈癌、结直肠癌项目更少
  • HER2突变NSCLC中，zongertinib的III期（NCT06151574）将是选择性TKI的首个关键检验；脑转移控制及与ADC的序贯或联合仍是待验证的假设
  • 随着T-DXd前移至新辅助阶段，ADC耐药后的治疗缺乏系统研究；不同载荷的ADC、双抗或细胞治疗（本站跟踪6项）在ADC经治人群中的作用值得探索
