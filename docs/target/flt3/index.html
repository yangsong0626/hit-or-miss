靶点小结

为什么重要

FLT3是造血祖细胞上的受体酪氨酸激酶，约三成AML携带FLT3-ITD或TKD激活突变，其中ITD提示复发风险高、预后差。midostaurin和gilteritinib已获批，验证了这一靶点。FLT3在多数AML原始细胞表面表达，也可作为双抗和CAR-T的靶抗原。

从临床结果学到了什么

  • 本站目前未收录FLT3项目的读出、失败或提前终止，未来六个月内也没有试验到达主要完成日，暂时总结不出规律。现有10个项目以1期小分子为主，只有quizartinib进入3期。

剩下的机会

  • 非小分子路线仍少，本站仅收录CLN-049双抗和Hemogenyx的CAR-T，均处于早期。依靠表面表达而非突变，可能覆盖FLT3野生型AML；需要回答的是正常造血祖细胞和树突状细胞受损的程度。
  • quizartinib项目同时列出Kura Oncology，适应症中又有NPM1突变和MLL重排白血病，提示FLT3抑制剂联合menin通路的方向值得验证，可按共突变状态筛选患者。
  • HPB-092、Zhejiang ACEA等新小分子要做出差异，可能在于覆盖F691L守门突变和D835类TKD耐药突变，或GB3226这类双靶点设计；可以把既往FLT3抑制剂经治后的耐药人群作为切入点。
