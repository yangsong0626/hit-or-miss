靶点小结

为什么重要

SIRPα表达于巨噬细胞、树突状细胞等髓系细胞，与肿瘤细胞上的CD47结合后经SHP-1/2传递“别吃我”信号，抑制吞噬。CD47在红细胞上广泛表达，直接靶向SIRPα有望在保留吞噬激活的同时减少贫血等血液学毒性。

从临床结果学到了什么

  • 本站追踪的6个项目（4家公司）均处于1期，尚无读出、失败或终止记录，未来6个月也没有到达主要完成日的试验，因此目前还无法判断该机制在临床上能否成立，第一次真正的检验时间也尚不明确。

剩下的机会

  • 本站追踪的项目以晚期实体瘤为主，淋巴瘤和多发性骨髓瘤仅各有少数。可以验证一个假设：在血液肿瘤中联合利妥昔单抗等调理性抗体，吞噬增强效应是否更容易显现。
  • 目前追踪到的项目只有单抗和SIRPα-Fc融合蛋白两种形式，尚未见双抗或ADC。肿瘤靶向的双特异性设计也许能把髓系激活集中到肿瘤局部。
  • SIRPα存在V1/V2等多态性，SIRPγ在T细胞上表达，抗体对等位基因的覆盖度以及是否回避SIRPγ，可能成为同类项目差异化和患者筛选的依据。
