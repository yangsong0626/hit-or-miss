靶点小结

为什么重要

FGFR2是受体酪氨酸激酶，FGFR2融合或重排可持续激活下游MAPK和PI3K信号，约10%–15%的肝内胆管癌由其驱动，是该病为数不多的可靶向致癌驱动。泛FGFR抑制剂在临床上已验证这一机制，但FGFR1相关的高磷血症以及激酶域耐药突变限制了疗效持续时间。

从临床结果学到了什么

  • 临床记录仍很有限：本站尚未收录任何注册试验读出，唯一信号是新闻报道的lirafugratinib获FDA批准用于经治FGFR2阳性胆管癌；未来6个月也没有试验到达主要完成日期，近期暂无明确的下一次检验节点。

剩下的机会

  • 本站收录的项目集中在胆管癌，仅有少数项目覆盖其他FGFR2变异实体瘤。胃癌（FGFR2扩增）、子宫内膜癌等瘤种的跨瘤种开发仍有空间，值得研究者验证。
  • 前线FGFR抑制剂治疗后出现的耐药突变是尚未解决的问题。Cogent、Tyra、KinoTeck的早期项目能否覆盖这些突变，可结合ctDNA监测来筛选患者，以此检验与lirafugratinib的差异化。
  • 本站收录的项目均为小分子或模式未披露，未见抗体、ADC或降解剂。一线、辅助治疗或联合用药同样缺乏收录项目，可作为新的研究假设。
