分类与通路

分类：肿瘤表面抗原（ADC、双抗、CAR-T 靶点） › 血液肿瘤抗原
同家族：CD19 · CD22 · CD3 · BCMA · GPRC5D · FcRH5 · CD38 · CD123 · CD33 · CLL1 / CD371 · CD7 · CD30 · CD70

B 细胞受体信号 · 下游 BTK
CD19 / CD22 / CD20 → BTK
CD19、CD22 是 B 细胞受体的共受体，信号经 BTK 传递；CD20 是 B 细胞清除抗体的靶点。
