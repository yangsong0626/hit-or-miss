靶点小结

为什么重要

DPP1（cathepsin C）在骨髓中性粒细胞成熟过程中激活中性粒细胞弹性蛋白酶、PR3和cathepsin G。抑制DPP1可从源头降低这些蛋白酶的活性，减轻支气管扩张症、COPD等疾病中的气道损伤。CTSC功能缺失导致Papillon-Lefèvre综合征，但患者并无明显系统性免疫缺陷，这为长期抑制的耐受性提供了遗传学依据。

从临床结果学到了什么

  • 本站跟踪的临床记录仍很有限：目前没有读出或失败记录。首个关键检验是Haisco的HSK31858在非囊性纤维化支气管扩张症中的III期试验NCT06660992，主要完成日期在2026年11月下旬。

剩下的机会

  • 在本站跟踪的管线中，COPD和哮喘只有少数II期项目，DPP1抑制能否从支气管扩张症延伸到这些疾病尚无数据。以痰液弹性蛋白酶活性或中性粒细胞高表型筛选患者，可作为可检验的假设。
  • Onchilles的N17350是唯一的重组酶项目，用于三阴性乳腺癌和实体瘤，思路与呼吸领域相反：利用弹性蛋白酶杀伤肿瘤细胞。早期数据能否支持这一机制，仍是开放问题。
  • 本站跟踪的呼吸项目均为小分子DPP1抑制剂，同质化明显。可从两方面寻求差异：一是降低PLS相关的皮肤角化、牙周不良反应；二是进入尚无项目覆盖的中性粒细胞驱动疾病。
