靶点小结

为什么重要

ANGPTL3由肝脏分泌，抑制脂蛋白脂酶和内皮脂酶，从而升高甘油三酯和LDL-C。其降LDL作用不依赖LDL受体，因此适用于HoFH。ANGPTL3功能缺失变异携带者血脂全面偏低、冠心病风险下降，提供了人类遗传学验证。evinacumab已获批用于HoFH。

从临床结果学到了什么

  • 本站追踪的临床记录仍很薄：8个项目中尚无读出、无失败或提前终止，未来6个月也没有到达主要完成的试验。zodasiran进展最快，已进入3期，但首个真正的检验不在当前窗口内。

剩下的机会

  • 在本站追踪的项目中siRNA占5/8，主要集中在HoFH和严重高甘油三酯血症；后来者或需靠给药间隔、联合用药或新适应症来差异化。
  • DKD和混合型血脂异常各仅有1个项目，可检验ANGPTL3抑制在残余甘油三酯风险人群中是否带来肾脏或心血管获益。
  • CTX310和Verve的一次性基因编辑项目仍处1期，长期安全性和效应持久性是尚未回答的关键问题。
