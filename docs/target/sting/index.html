靶点小结

为什么重要

STING是内质网接头蛋白，接收cGAS感知胞质DNA后生成的cGAMP，经TBK1-IRF3诱导I型干扰素，促进树突状细胞交叉呈递和T细胞启动，被视为将“冷”肿瘤转“热”的靶点。STING1功能获得性突变致SAVI，提示抑制剂可用于干扰素病。

从临床结果学到了什么

  • 临床记录仍很薄：本站仅追踪到OncoNano一个1期项目（TNBC和DLBCL），尚无读出、失败或提前终止，未来6个月内也无试验到达主要完成日期，近期没有真正的检验节点。

剩下的机会

  • 本站追踪的唯一项目只覆盖TNBC和DLBCL，其他实体瘤尚无项目；可检验STING激活能否在T细胞浸润低或PD-1耐药的肿瘤中恢复免疫应答。
  • 肿瘤常通过表观遗传沉默STING或cGAS，按通路完整性（STING/cGAS表达、干扰素特征）筛选患者，可能区分应答者；本站尚未见按生物标志物入组的项目。
  • 本站追踪的项目均为肿瘤激动方向，未见针对SAVI等干扰素病或其他STING驱动炎症的抑制剂项目，抑制端仍是空白。
