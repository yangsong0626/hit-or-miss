靶点小结

为什么重要

MRGPRX2是皮肤等结缔组织型肥大细胞上的GPCR。P物质等神经肽及部分阳离子药物可通过它绕开IgE引发脱颗粒，参与假性过敏、神经源性炎症和瘙痒。因此阻断该受体被用于荨麻疹、特应性皮炎瘙痒和偏头痛的探索。

从临床结果学到了什么

  • 临床证据仍薄：唯一明确结果是EVO756在特应性皮炎2b期未达到主要终点（NCT07150845），Evommune随后据报放弃止痒方向；未来六个月本站跟踪范围内没有新的主要完成节点。

剩下的机会

  • 慢性自发性荨麻疹主要由肥大细胞驱动，比特应性皮炎更贴近该机制。本站尚未记录EVO756在荨麻疹的结果，这一数据有助于判断阴性结果出在适应症还是靶点本身。
  • Arcus的1期小分子可先用皮肤P物质或icatibant风团抑制等药效学模型确认靶点占据，排除暴露不足对阴性结果的解释，再推进2期。
  • 本站跟踪项目均为小分子，抗体等其他模态尚未出现；围术期药物诱发假性过敏等更直接依赖MRGPRX2的场景也少有项目覆盖。
