靶点小结

为什么重要

HER3（ERBB3）自身激酶活性很弱，但与 HER2 或 EGFR 异二聚化后能强效激活 PI3K–AKT 通路，是 EGFR-TKI、抗 HER2 及内分泌治疗耐药的常见逃逸途径，NRG1 融合肿瘤也依赖这一轴。HER3 在多种实体瘤中广泛表达，结合抗体后可被内吞，因此也是 ADC 的递送靶点。

从临床结果学到了什么

  • 本站追踪的项目中尚无登记读出或失败记录。目前只有公告称 EGFR×HER3 双抗 ADC iza-bren（BL-B01D1）在经治 HR+/HER2- 乳腺癌和 EGFR 突变 NSCLC 两项中国三期达到 PFS 终点，具体数据未公布。后续检验看 NCT06118333、NCT06382129、NCT06500026。

剩下的机会

  • BL-B01D1 有 55 项试验，进度领先，但它同时靶向 EGFR，HER3 臂贡献多少尚不清楚。SYS6023、JSKN016、HDM2024 等单靶 HER3 ADC 可以检验 HER3 表达水平能否预测疗效，目前很少有项目回答这个生物标志物问题。
  • NRG1 融合是 HER3 最明确的遗传依赖。本站追踪的项目中，围绕这一人群设计的似乎只有 HER2×HER3 双抗 zenocutuzumab。HER3 ADC 在融合阳性或 HER3 高表达人群中的作用尚未验证。
  • 乳腺癌和 NSCLC 之外，鼻咽癌（NCT06118333）和小细胞肺癌（NCT06500026）三期将检验双抗 ADC 能否扩展到 HER3 生物学依据较弱的瘤种。头颈鳞癌和消化道肿瘤的项目仍处早期。

分类与通路

分类：激酶 › 受体酪氨酸激酶
同家族：EGFR · HER2 · c-MET · ALK · ROS1 · RET · KIT · FLT3 · FGFR（泛） · FGFR2 · FGFR3 · FGFR4 · TRK (NTRK) · PDGFR · CSF1R · AXL · VEGF / VEGFR · 胰岛素受体

RAS–MAPK · 下游 SHP2
EGFR / HER2 / HER3 / c-MET / ALK / ROS1 / RET / FGFR（泛） / TRK (NTRK) → SHP2 → RAS（泛 / RAS-ON） / KRAS G12C / KRAS G12D / KRAS（泛 / 其他突变） → SHOC2 / RAF（泛） / BRAF → MEK → ERK
生长因子受体经 SHP2 激活 RAS，再依次激活 RAF、MEK、ERK，驱动增殖。
PI3K–AKT–mTOR · 下游 PI3Kα / PI3K（其他）
EGFR / HER2 / HER3 / 胰岛素受体 → PI3Kα / PI3K（其他） → AKT → mTOR
受体激活 PI3K，经 AKT 到 mTOR，调控生长和代谢。
