靶点小结

为什么重要

STAT3是IL-6/JAK等信号下游的转录因子，在多种实体瘤和血液肿瘤中持续激活，驱动增殖、存活和免疫抑制性微环境。它没有可结合的酶活性口袋，长期被视为难成药靶点，降解剂提供了新的干预方式。胚系功能缺失会导致高IgE综合征，提示需关注感染风险。

从临床结果学到了什么

  • 临床记录尚薄：此处追踪的仅有Medsyn一项STAT3降解剂1/2期项目（胃癌、三阴性乳腺癌），2026年10月才登记，尚无读出，未来六个月内也没有预计达到主要完成的试验。

剩下的机会

  • 此处追踪的唯一项目覆盖胃癌和TNBC。存在STAT3体细胞激活突变的血液肿瘤（如大颗粒淋巴细胞白血病、部分ALCL）尚无项目，遗传学依据更清晰，可作为验证机制的场景。
  • STAT3参与维持肿瘤免疫抑制。降解剂联用PD-1/PD-L1抑制剂，或按pSTAT3、IL-6水平筛选患者，在此处追踪的项目中均未见，可作为早期探索的假设。
  • 该模式首先要回答的问题是：降解剂能否在肿瘤中实现充分、持久的STAT3清除，又不出现类似高IgE综合征的感染或免疫缺陷。早期研究宜同时纳入药效学和免疫功能监测。
