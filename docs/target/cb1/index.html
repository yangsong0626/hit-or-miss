靶点小结

为什么重要

CB1是中枢表达最丰富的GPCR之一，位于突触前膜，介导内源性大麻素和THC对神经递质释放、疼痛、食欲和情绪的调节，外周CB1参与肝脏与脂肪代谢。rimonabant曾在欧盟获批治疗肥胖，后因精神不良反应撤市，既验证了代谢获益，也暴露了中枢风险。

从临床结果学到了什么

  • 本站追踪的CB1临床记录仍很薄：仅有Sinfatin S.L一个2期小分子项目，两项试验分别针对慢性卒中和新冠后综合征，2026年11月才登记，尚无读出，未来6个月也没有试验到达主要完成日。

剩下的机会

  • 本站追踪的项目中尚无针对肥胖、代谢相关脂肪性肝病或糖尿病肾病的项目，而外周CB1的生物学依据在这些领域最充分；不入脑的外周限制性反向激动剂是一个值得验证的方向。
  • Sinfatin两项试验的关键未知在于化合物是激活还是阻断CB1、入脑程度如何；同时纳入精神安全性监测和靶点结合标志物，结果才更具可解释性。
  • 本站目前只见到小分子。偏向性或别构调节剂，以及难以穿过血脑屏障的CB1抗体，可用于检验外周获益能否与中枢效应分开。
