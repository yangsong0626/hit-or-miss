靶点小结

为什么重要

IL-23由p19与p40组成，经IL-23R–JAK2/TYK2–STAT3通路维持致病性Th17细胞，驱动IL-17、IL-22分泌。IL23R基因多态性与炎症性肠病和银屑病相关，提供了遗传学验证。ustekinumab（p40）、guselkumab和risankizumab（p19）已在银屑病中获批多年，临床验证明确。

从临床结果学到了什么

  • 银屑病是该靶点确定性最高的领域：口服多肽IL-23R拮抗剂JNJ-77242113在NCT06095115、NCT06143878、NCT06220604中均达到主要终点，说明小分子级给药方式可以复现抗体的疗效。
  • JNJ-77242113在头皮、生殖器等难治部位（ICONIC-TOTAL，NCT06095102）同样达标，guselkumab在VISIBLE（NCT05272150）中也达标，证据已从泛银屑病延伸到特殊部位与特定人群。
  • 炎症性肠病虽是本站追踪项目最集中的适应症（CD 9个、UC 7个），近期读出却缺乏假设检验：ustekinumab儿科研究NCT04630028、NCT04673357均为描述性结果。
  • 本站追踪到的失败只有brazikumab（NCT03759288），因战略原因终止，不构成对机制的否定，更多反映后来者在成熟p19药物面前的商业压力；暂未见因安全性提前终止的研究。

剩下的机会

  • 口服IL-23R阻断在肠道能否达到足够暴露和疗效，在本站的读出中尚未验证；NCT06807424（银屑病关节炎）将检验JNJ-77242113向关节病的延伸，IBD适应症仍是空白。
  • 瘘管型克罗恩病仅有一个追踪项目（guselkumab，NCT05347095），属于难治表型，结合NCT06063967（risankizumab，CD）和NCT06260163（guselkumab，UC），可检验p19药物在难治或经治人群中的上限。
  • 在p19抗体趋于同质化的背景下，可探索按IL23R变异或IL-22/Th17通路标志物进行患者分层，以及与其他机制联用治疗难治性IBD；mirikizumab的2期UC研究（NCT06598943）结果仍待公布。
