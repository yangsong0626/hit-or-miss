靶点小结

为什么重要

SMO是Hedgehog通路中类似GPCR的信号转导蛋白。PTCH1缺失或SMO激活突变可直接驱动基底细胞癌和髓母细胞瘤，vismodegib、sonidegib已获批用于基底细胞癌。Hedgehog通路在组织损伤后重新激活，会促进成纤维细胞活化，所以肺纤维化成为该靶点的新方向。

从临床结果学到了什么

  • 临床记录仍然很少：本站尚无注册试验读出，只有一条新闻称Endeavor的taladegib在IPF IIb期试验达到终点。IPF II期试验NCT06422884已过主要完成期（2026-10），它的完整数据将是首次实质性检验。

剩下的机会

  • 纤维化方向的跟进者很少，本站仅追踪到一个小分子项目覆盖IPF和PF-ILD。值得验证的问题包括：与现有抗纤维化药物联用是否有增量获益，以及肌痉挛、味觉障碍、脱发等SMO类效应在长期给药下能否耐受。
  • 可探索用GLI1等通路活性标志物筛选纤维化患者，看Hedgehog信号高的亚组是否获益更大；也可以把适应症从IPF扩展到其他进展性纤维化ILD。
  • 肿瘤方向本站追踪的项目涉及基底细胞癌和胰腺导管腺癌，包括一个重组蛋白项目和一个模态未披露的项目，均处于II期及更早阶段。非小分子模态能否绕开SMO突变介导的耐药，仍有待检验。
