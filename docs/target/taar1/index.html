靶点小结

为什么重要

TAAR1是由痕量胺激活的Gs偶联GPCR，在中脑VTA和中缝核表达，可在突触前调节多巴胺和5-HT神经元的放电。激动TAAR1有望在不阻断D2受体的情况下产生抗精神病作用，从而避开锥体外系反应、高泌乳素血症和代谢负担，是精神分裂症领域的一条非D2新路径。

从临床结果学到了什么

  • SEP-363856的两项设计相近的III期研究都以第6周PANSS总分为主要终点、样本量都约460例，结果却不一致：NCT04092686达到，NCT04072354未达到。机制可能有效，但疗效能否稳定复现仍未确定。
  • 在本站追踪的项目中，后期证据全部来自Otsuka的SEP-363856。Roche的Ralmitaront和Newleos的项目都还在I期，这条靶点的临床判断目前几乎取决于单一分子。
  • 目前记录在案的失败只有一项，即NCT04072354，原因为疗效不足，没有安全性或商业原因导致的终止。阴性结果更可能与效应量不足或安慰剂反应有关，而非耐受性问题。

剩下的机会

  • 两项III期结果分化，说明患者选择可能是关键：按病程、症状维度（如阴性症状）或入组地区分层，或许能找到更稳定的获益人群，可作为后续研究假设。
  • 适应症拓展仍处于早期，广泛性焦虑障碍和酒精使用障碍各只有一个项目。TAAR1对多巴胺奖赏通路的调节与成瘾生物学相吻合，值得设计带生物标志物的概念验证研究。
  • 未来6个月没有预期读出。Otsuka在2026年8月新登记的III期项目会是复现性的下一次检验；联合D2拮抗剂的增效方案和非小分子形式在本站追踪的项目中尚未出现。
