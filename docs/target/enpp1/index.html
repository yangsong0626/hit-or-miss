靶点小结

为什么重要

ENPP1水解胞外ATP生成AMP和焦磷酸（PPi），PPi抑制异位钙化，ENPP1功能缺失可致婴儿全身性动脉钙化（GACI）和ARHR2，这为酶替代提供了遗传依据。在肿瘤中，ENPP1降解2'3'-cGAMP并促进腺苷生成，抑制它有望恢复STING介导的先天免疫。

从临床结果学到了什么

  • 记录仍薄：仅INZ-701有读出，1/2期为描述性结果（NCT04686175），3期因商业原因终止（NCT06046820），不能据此否定机制；肿瘤抑制剂尚无数据，未来六个月也没有到期试验。

剩下的机会

  • 肿瘤领域追踪到的4个抑制剂均为早期小分子，多数在泛实体瘤人群中开展。按肿瘤ENPP1表达或cGAS-STING通路是否完整入组，并联合放疗或PD-1抑制剂，是有待验证的差异化假设。
  • NCT06046820终止后，本站未追踪到其他针对ENPP1缺乏症或ARHR2的酶替代项目。恢复PPi能否改善骨骼和血管结局仍未回答，追踪项目中也还没有长效制剂或基因疗法。
  • 系统性抑制ENPP1会降低PPi，而PPi缺乏正是GACI钙化的成因。肿瘤局部化设计、早期试验中监测PPi与血管钙化，目前追踪的肿瘤项目都还没有报告相关数据。
