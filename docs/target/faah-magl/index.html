靶点小结

为什么重要

FAAH和MAGL分别降解内源性大麻素anandamide和2-AG。抑制这两种酶可以提高内源性大麻素水平，间接激活CB1/CB2，有望在获得镇痛、抗痉挛和抗焦虑作用的同时，避开直接激动剂的精神活性。MAGL还为脑内前列腺素合成提供花生四烯酸，因此兼具抗神经炎症的逻辑。

从临床结果学到了什么

  • 临床记录仍很有限：本站追踪的2个项目都来自Bristol Myers Squibb，处于2期，适应症为多发性硬化痉挛和阿尔茨海默病激越，目前没有读出，未来6个月内也没有预计完成的试验，短期内暂无数据可以检验这一机制。

剩下的机会

  • 该靶点所属通路覆盖疼痛、癫痫和咳嗽，但本站追踪的项目只涉及多发性硬化痉挛和阿尔茨海默病激越。神经病理性疼痛、难治性癫痫和慢性咳嗽仍是值得验证的适应症假设。
  • 单独抑制FAAH、单独抑制MAGL还是双重抑制，哪一种决定疗效，又是哪一种带来CB1相关的耐受和中枢副作用，目前尚无定论。可以用血浆anandamide/2-AG作为靶点结合标志物来指导剂量和患者筛选。
  • 本站追踪的项目只来自一家公司。外周限制型MAGL抑制剂用于炎症性疼痛，或采用以长期给药耐受性为核心的差异化设计，可能是其他研发者的切入点。
