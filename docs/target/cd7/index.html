靶点小结

为什么重要

CD7高表达于多数T-ALL/LBL原始细胞，也见于正常T细胞和NK细胞。复发/难治T系淋巴母细胞肿瘤治疗选择有限，CD7是少数可行靶点。CAR-T需敲除或阻断自身CD7表达以避免自相残杀，并存在T细胞长期缺失风险。

从临床结果学到了什么

  • 本站追踪的临床记录仍很有限：3家公司的4个细胞治疗项目均集中于T-ALL/LBL，最高仅至2期，尚无读出记录，未来6个月也没有试验到达主要完成日期。

剩下的机会

  • 所追踪项目全部集中于T-ALL/LBL。CD7也表达于部分AML及部分成熟T/NK细胞淋巴瘤，在本站追踪范围内，这些适应症尚无项目探索。
  • 所追踪项目均为细胞治疗。靶向CD7的ADC或CAR-NK可省去防自相残杀的工程改造，但正常T细胞被清除带来的免疫缺陷仍是核心安全性问题。
  • 首批读出值得关注：缓解能否持久、CD7阴性复发的比例，以及CD7 CAR-T更适合作为异基因移植的桥接还是独立治疗。监测CD7表达密度和T细胞恢复情况可能有助于患者筛选。
