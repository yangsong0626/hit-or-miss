靶点小结

为什么重要

RAS–MAPK通路中，BRAF/CRAF以二聚体形式传递信号。第一代BRAF V600抑制剂对二聚体无效，还会引起反常激活。pan-RAF抑制剂同时阻断单体和二聚体，主要面向BRAF非V600突变、BRAF融合，以及NRAS/KRAS突变驱动的肿瘤，例如儿童低级别胶质瘤和低级别浆液性卵巢癌。

从临床结果学到了什么

  • 本站跟踪的8个项目全部为小分子，其中tovorafenib、avutometinib、naporafenib已进入3期，但目前还没有收录任何读出或失败记录，临床证据仍然很少。avutometinib针对KRAS突变的NCT05669482已过主要完成日期，其结果将是本站收录的第一个实际检验。

剩下的机会

  • 本站跟踪的适应症集中在黑色素瘤、低级别浆液性卵巢癌和低级别胶质瘤。KRAS突变的常见实体瘤覆盖较少，可以研究pan-RAF或RAF/MEK抑制剂与KRAS直接抑制剂联用，能否延缓通路再激活。
  • 目前收录的全部是小分子抑制剂，RAF二聚体降解剂等其他机制尚未出现。考虑到胶质瘤这一适应症，入脑能力和CNS暴露量也可以作为区别于领先项目的方向。
  • RAF改变类型差异很大，包括非V600 BRAF、融合、NRAS和KRAS。可以检验按改变类型分层入组能否区分获益人群，NCT05669482在KRAS突变人群中的结果可作为第一个参照。
