靶点小结

为什么重要

IDH1 R132突变使酶获得新功能，产生致癌代谢物2-HG，抑制TET及组蛋白去甲基化酶，导致表观遗传紊乱和分化阻滞。该突变见于AML、低级别胶质瘤和肝内胆管癌，属于驱动事件，可用伴随诊断筛选患者；ivosidenib已获批用于IDH1突变AML。

从临床结果学到了什么

  • 本站追踪的IDH1项目尚无读出、失败或终止记录，未来6个月也没有到达主要完成的试验，暂时无法从数据中总结经验。目前只能看到格局：11个项目中10个为小分子，6个处于3期，以Servier的ivosidenib和vorasidenib为主，Nuvation Bio另有一个3期项目。

剩下的机会

  • 本站追踪的适应症集中在胆管癌、AML和胶质瘤；软骨肉瘤、MDS等同样存在IDH1突变的肿瘤尚无项目，可检验突变抑制剂在这些人群中能否带来获益。
  • 高级别胶质瘤仅有一个4级星形细胞瘤项目。脑渗透性更强的抑制剂，或与放疗、免疫治疗联用，能否把低级别胶质瘤中的获益延伸到高级别人群，仍待验证。
  • 现有项目几乎全是小分子。针对获得性耐药（IDH1二次突变、转换为IDH2突变）的下一代或双靶点抑制剂，以及靶向R132H新抗原的疫苗或细胞疗法，可作为差异化方向。
