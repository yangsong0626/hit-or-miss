靶点小结

为什么重要

ERα是配体激活的转录因子，驱动多数激素受体阳性乳腺癌生长。tamoxifen与fulvestrant验证了阻断或降解ER的价值，但耐药常见，芳香化酶抑制剂治疗后常出现ESR1配体结合域突变。口服SERD、PROTAC降解剂等新药旨在耐药肿瘤中持续抑制ER信号。

从临床结果学到了什么

  • 已追踪读出均为1/2期且无正式假设检验，临床记录尚薄。首批真正检验将来自palazestrant III期（NCT06016738）、vepdegestrant III期（NCT05909397）和afuresertib III期（NCT04851613）。

剩下的机会

  • 已追踪管线集中于乳腺癌，子宫内膜癌（giredestrant，NCT05634499）、卵巢癌、脂肪肉瘤项目很少。这些肿瘤的ER依赖性能否支持SERD或降解剂治疗、何种标志物可预测，仍待回答。
  • vepdegestrant联合ribociclib或samuraciclib的两项试验在1b期后以商业理由关停（NCT05573555、NCT06125522），PROTAC降解剂与CDK4/6或CDK7抑制剂的联合仍未被检验，而非被否定。
  • 已追踪项目中小分子占17个，差异化或来自模态（4个ADC、1个放射性药物）或治疗阶段：早期乳腺癌仅2个项目。即将读出的III期（NCT06016738、NCT05909397）可提示获益是否局限于ESR1突变人群。

分类与通路

分类：核受体与转录因子 › 激素核受体
同家族：AR · GR（糖皮质激素受体） · 盐皮质激素受体 · THR-β · FXR

激素驱动肿瘤 · 上游 KAT6 · 下游 CDK4/6
KAT6 → ER (ESR1) / AR → CDK4/6
KAT6 调控雌激素受体的转录；雌激素受体驱动乳腺癌（经细胞周期蛋白 D 激活 CDK4/6），雄激素受体驱动前列腺癌。

常在同一试验里出现的靶点

CDK4/6 · mTOR · PI3Kα · PARP1 · KAT6 · CDK7 · AR · AKT · MEK · CDK2
