靶点小结

为什么重要

激活素、GDF等TGF-β超家族配体经ActRIIA/IIB受体传导SMAD2/3信号，抑制晚期红系成熟，并在肺动脉高压中推动血管重构，同时负向调控骨骼肌量。luspatercept已获批用于β-地中海贫血和MDS贫血，sotatercept已获批用于PAH，均为配体陷阱类药物，该机制已有临床验证。

从临床结果学到了什么

  • 在肺动脉高压中，sotatercept的2期CADENCE（NCT04945460）以肺血管阻力为主要终点并达到，说明配体陷阱在血管重构适应症上的获益可通过血流动力学指标体现。
  • 骨髓纤维化是该机制目前的主要短板：luspatercept的3期INDEPENDENCE（NCT04717414）未达到输血独立终点，在MDS和地贫中有效的红系成熟机制不能直接外推到纤维化骨髓。
  • 本站追踪到的6个项目里，进度最快的两个都是融合蛋白（MSD、BMS），单抗处于1–2期；目前失败均因疗效，未见安全性或商业原因终止。

剩下的机会

  • 体重管理：Lilly的bimagrumab（2期）阻断ActRII以保留肌肉，本站尚未追踪到其读出。与肠促胰素联用能否改善减重质量（脂肪与瘦体重之比），仍是待验证的假设。
  • 受体或配体选择性单抗（CTTQ的TQF6422、GSK未命名项目）可用来检验：比广谱配体陷阱更窄的阻断，能否保住疗效同时改变耐受性特征。
  • INDEPENDENCE失败后，骨髓纤维化贫血或需按生物标志物（如纤维化程度、红系无效造血特征）筛选亚组再做验证。未来6个月本站没有到期读出，近期证据有限。
