靶点小结

为什么重要

GBA1编码溶酶体酶GCase。双等位突变导致戈谢病，杂合变异是帕金森病最常见的遗传风险因素。GCase活性下降会使葡萄糖神经酰胺蓄积，并促进α-突触核蛋白聚集，因此通过分子伴侣、激活剂或基因治疗恢复酶活性，被视为疾病修饰策略。

从临床结果学到了什么

  • 临床记录仍很薄。唯一读出是ambroxol的NCT06193421，因申办方决定提前终止，属商业原因，不能作为机制无效的证据。未来六个月内，本站追踪的试验中没有一项到达主要完成节点。

剩下的机会

  • 可按GBA1变异严重程度分层入组，或用GCase活性、葡萄糖鞘氨醇等生物标志物筛选患者，有望更早看到信号。本站追踪的项目中，明确限定GBA1人群的很少。
  • 三个项目均处于1/2期：两项为小分子，一项为Capsida的基因治疗。本站追踪范围内尚无脑穿透型酶替代等其他方式，哪种递送方式最能恢复脑内GCase仍待检验。
  • 本站追踪的试验全部集中在帕金森病。GBA1变异同样是路易体痴呆的强风险因素，该适应症以及GCase活性偏低的散发性PD，目前在本站追踪范围内仍是空白。
