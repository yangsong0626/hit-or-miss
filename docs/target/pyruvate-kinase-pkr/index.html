靶点小结

为什么重要

PKR由PKLR编码，是红细胞糖酵解最后一步的限速酶，为红细胞提供ATP。PKLR突变导致丙酮酸激酶缺乏症，属慢性溶血性贫血，这是来自遗传学的验证。激活PKR可提高ATP、降低2,3-DPG，有助于红细胞膜稳定，并提高血红蛋白氧亲和力，从而抑制HbS聚合。因此PKR激活剂被用于镰状细胞病和地中海贫血。

从临床结果学到了什么

  • 目前临床记录仍很薄。本站追踪到的唯一读出是etavopivat在低危MDS中的2期试验，因无效性评估提前终止（NCT05568225），提示克隆性无效造血可能不适合该机制。镰状细胞病和地中海贫血的3期结果尚未收录，未来6个月也没有追踪到的主要完成节点。

剩下的机会

  • 在本站追踪的项目中，镰状细胞病占7个，且集中在mitapivat和etavopivat两个分子上；儿童PK缺乏症和α-地中海贫血项目较少。后来者可以考虑转向这些适应症，或在药代、给药频次上做出区别，例如2期的tebapivat和1期的ScinnoHub分子。
  • MDS无效性终止（NCT05568225）提出了一个问题：哪些贫血适合PKR激活？可以假设以ATP、2,3-DPG基线及治疗后变化或PKLR基因型作为入组生物标志物，在溶血为主的人群中验证，而不是用于克隆性造血衰竭。
  • 本站追踪的9个项目全部是小分子激活剂。对酶活性残留极低的PK缺乏症，变构激活可能作用有限，针对PKLR的基因校正或其他非小分子路径在此尚无项目，可作为研究假设。
