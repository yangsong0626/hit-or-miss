靶点小结

为什么重要

BRAF是RAS–MAPK通路中的RAF激酶，V600E等激活突变使其不依赖RAS即可持续激活MEK–ERK信号。这类突变见于约半数黑色素瘤，以及部分结直肠癌、NSCLC和甲状腺癌。vemurafenib、dabrafenib、encorafenib已获批，BRAF作为致癌驱动靶点已得到验证。

从临床结果学到了什么

  • 本站目前只追踪到两项读出，均为达到PFS终点的3期试验（encorafenib NCT04607421，dabrafenib用于DTC NCT04940052），没有失败记录。接下来的检验是黑色素瘤试验NCT04657991、NCT05270044和mCRC试验NCT06008119。

剩下的机会

  • 在本站追踪的项目中，非V600突变和中枢肿瘤覆盖很少：针对广义BRAF变异的项目和针对HGG的项目各一项。II/III类突变与融合以二聚体形式传递信号，可以检验能抑制二聚体、并能透过血脑屏障的设计。
  • 8个项目都是小分子，后期管线集中在V600黑色素瘤、NSCLC和结直肠癌。降解剂等其他modality尚未出现。Shanghai Kechow的3期新药进入V600领域，需要在疗效持久性或延缓MAPK再激活上体现差异。
  • 结直肠癌中EGFR反馈会削弱BRAF抑制剂单药的效果，联合方案是关键。即将读出的mCRC 3期NCT06008119有助于判断联合策略和治疗线数的价值；耐药生物标志物可以用来优化患者选择。
