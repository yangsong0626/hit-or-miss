分类与通路

分类：心血管、代谢与肾脏 › RAAS 与血管张力
同家族：肾素 / AGT · sGC · CNP / NPR-B · APOL1

RAAS 与血压 · 上游 肾素 / AGT · 下游 盐皮质激素受体 / 内皮素受体
肾素 / AGT → AT1 受体 / 醛固酮合酶 (CYP11B2) → 盐皮质激素受体 / 内皮素受体
肾素切 AGT 生成血管紧张素，作用于 AT1 受体；醛固酮合酶产生醛固酮，作用于盐皮质激素受体；内皮素是另一条缩血管通路。
