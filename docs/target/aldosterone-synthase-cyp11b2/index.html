靶点小结

为什么重要

CYP11B2在肾上腺球状带催化醛固酮合成的最后几步。醛固酮过多会导致钠潴留、高血压，以及肾脏和心脏纤维化。盐皮质激素受体拮抗剂已验证这一通路，但会出现醛固酮逃逸和高钾血症。直接抑制醛固酮合成可从源头阻断，难点在于对CYP11B1（皮质醇合成酶）的选择性。

从临床结果学到了什么

  • Baxdrostat在两项III期研究中均达到主要终点：BaxHTN（NCT06034743）用诊室坐位收缩压，Bax24（NCT06168409）用24小时动态收缩压。两种测量方式下降压效应一致，可信度更高
  • 高血压以外的证据还很早期：CKD方面目前只有Mineralys的II期（NCT06150924）读出，且无统计检验；本站追踪的项目中尚无肾脏或心血管硬终点结果
  • 10个项目里没有失败或提前终止，已知模态都是小分子。III期集中在BI、AZ和Mineralys三家，Salubris、InnovStone和Zhejiang Yangli于2026年进入II期

剩下的机会

  • 降压疗效能否转化为肾脏获益，vicadrostat的CKD研究NCT06926660（II期）和NCT06531824（III期）将是首次检验，同时也会显示肾功能下降人群中的血钾安全性
  • 原发性醛固酮增多症和心衰分别只有1个和2个项目。用醛固酮/肾素比值等生物标志物富集患者，可能更清楚地呈现机制获益
  • II期跟进者若想区别于领先者，可在CYP11B1选择性、血钾控制、给药频次或与现有降压药组成固定复方等方面寻求差异
