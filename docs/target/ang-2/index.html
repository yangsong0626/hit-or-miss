靶点小结

为什么重要

Ang-2由受损内皮释放，拮抗Tie2信号，使血管失稳并对VEGF更敏感，导致渗漏、炎症和新生血管。DME和nAMD患者眼内Ang-2水平升高。VEGF/Ang-2双重阻断旨在比单纯抗VEGF更好地恢复血管稳定，faricimab已获批用于nAMD和DME。

从临床结果学到了什么

  • 本站追踪的临床记录仍很有限：尚无读出或失败，两个项目均为Roche的VEGF/Ang-2双抗，处于1/2期。首个真正检验是zifibancimig在黄斑变性中的NCT04567303，2026年8月主要完成，结果待公布。

剩下的机会

  • 本站追踪的项目全部是Roche眼科双抗，Tie2直接激动、基因治疗或口服药物等路径尚未出现，可借此检验稳定血管本身是否比单纯中和Ang-2更有获益。
  • 该靶点标注于肿瘤血管生成，另有一项试验涉及心血管/代谢/肾领域，但本站未追踪到肿瘤或全身性血管渗漏项目，Ang-2阻断在眼外的作用仍是开放问题。
  • 患者选择尚未探索：眼内Ang-2水平或渗漏表型或可识别相对单纯抗VEGF获益更大的人群。NCT04567303将显示第二代分子形式能否形成有别于faricimab的特征。
