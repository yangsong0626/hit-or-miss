靶点小结

为什么重要

STAT6是IL-4与IL-13经IL-4Rα信号的核心转录因子，驱动Th2分化、IgE类别转换和嗜酸性炎症。dupilumab阻断IL-4Rα，已在特应性皮炎和哮喘中验证这一通路。STAT6功能获得性突变可致严重过敏性疾病。转录因子过去难以成药，降解剂为口服替代生物制剂提供了可能。

从临床结果学到了什么

  • 临床记录仍很有限：本站暂无STAT6相关读出，未来六个月也没有试验到达主要完成日期。Sanofi已终止Nurix来源的Phase 1降解剂SAR448272，未披露原因，不能据此否定机制。Kymera的Phase 2小分子项目将是首个真正检验。

剩下的机会

  • 本站追踪的项目仅覆盖特应性皮炎和哮喘。嗜酸性食管炎、伴鼻息肉的慢性鼻窦炎、结节性痒疹等dupilumab已验证的2型炎症适应症，目前尚无STAT6项目覆盖。
  • 核心未解问题是口服降解剂能否达到与IL-4Rα抗体相当的通路抑制深度。可用TARC、IgE、FeNO、eotaxin-3等生物标志物，在早期确定剂量并检验靶点作用。
  • 可考虑按患者分层：STAT6功能获得性突变患者，或对生物制剂应答不足的2型炎症患者。另一方向是与TSLP、IL-5等机制联用，以区别于单纯替代注射剂的定位。
