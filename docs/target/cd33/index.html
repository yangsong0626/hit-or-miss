靶点小结

为什么重要

CD33（Siglec-3）是髓系表面受体，在多数AML患者的原始细胞上表达，是该病验证最充分的靶点之一，ADC gemtuzumab ozogamicin已获批用于CD33阳性AML。但正常髓系祖细胞同样表达CD33，骨髓抑制是CAR细胞等强效疗法的主要限制。

从临床结果学到了什么

  • 本站追踪的CD33项目仅有两项处于1期（iCell Gene的抗CD33-CLL1 CAR-T与Senti的SENTI-202），尚无读出或失败记录，未来六个月也无主要完成节点，临床证据仍很薄。

剩下的机会

  • iCell Gene的CAR-T同时靶向CD33与CLL1。双抗原设计能否覆盖异质性AML、同时避免长期骨髓抑制是核心未决问题，目前尚无追踪到的读出数据可作回答。
  • 本站追踪范围内暂无CD33 ADC、T细胞衔接器或放射性偶联物。将强效CD33疗法与敲除CD33的供者造血干细胞联用以保护移植物，或可使移植后维持治疗成为可能，值得验证。
  • 患者筛选几乎空白：CD33表达密度及去除IgV结构域表位的rs12459419剪接变异可能预测获益人群；MDS仅出现在一个追踪项目的适应证中。
