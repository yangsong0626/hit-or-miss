靶点小结

为什么重要

脊髓性肌萎缩症（SMA）由SMN1缺失引起。旁系同源基因SMN2的外显子7有一个单碱基差异，导致该外显子常被跳过，只能产生少量全长SMN蛋白。SMN2拷贝数与病情轻重相关。用剪接调节促进外显子7保留，是已获验证的治疗策略，nusinersen与risdiplam均已获批多年。

从临床结果学到了什么

  • 本站追踪的临床记录仍很有限：仅有2个项目（ASO nusinersen与小分子risdiplam），没有已追踪的读出和失败案例。nusinersen的III期试验NCT04729907原定2026年7月完成主要终点，但本站尚未追踪到结果，它将是首个真正的检验。

剩下的机会

  • 在本站追踪的范围内，在研项目都是作用于SMN2外显子7的剪接调节剂，与SMN无关的机制（如肌肉、神经保护）和SMN2基因编辑尚未出现。Scholar Rock出现在nusinersen试验中，提示联合用药可能是一个值得验证的方向。
  • 可以检验SMN2拷贝数、神经丝轻链等生物标志物，能否用于识别对剪接调节剂应答欠佳的患者，并指导剂量调整或换药。
  • 现有两类药物分别是鞘内注射和每日口服，作用更持久、给药负担更低的剂型能否改善成人及晚发型患者的长期获益，仍有待回答。
