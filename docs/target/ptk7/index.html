靶点小结

为什么重要

PTK7是一种缺乏催化活性的假激酶受体，参与Wnt/平面细胞极性信号，在卵巢癌、三阴性乳腺癌、非小细胞肺癌等实体瘤中高表达，并富集于肿瘤起始细胞，而在多数正常成人组织中表达较低。正因如此，它适合作为ADC等靶向表面抗原疗法的靶点。

从临床结果学到了什么

  • 临床证据仍很薄弱：本站追踪的3个项目（Whitehawk的HWK-007、Day One与Kivu各一个未命名药物）均为1期ADC，尚无读出，未来6个月内也没有试验到达主要完成日期，目前无法判断疗效或安全性规律。

剩下的机会

  • 本站追踪的项目集中在卵巢癌、子宫内膜癌及泛实体瘤，三阴性乳腺癌和非小细胞肺癌同样有PTK7高表达报道，但尚无专门针对这两类肿瘤的项目，可作为适应症假设加以验证。
  • 现有项目全部为ADC，双抗、CAR-T或放射性偶联药物尚未出现。PTK7富集于肿瘤起始细胞，可考虑验证这些模态能否覆盖ADC难以清除的细胞亚群。
  • 三个同类1期ADC之间如何拉开差异尚无答案。按PTK7表达水平筛选患者、选择不同载荷与连接子，可能是剂量扩展阶段需要回答的关键问题。
