靶点小结

为什么重要

SOD1突变约占家族性ALS的两成，突变蛋白错误折叠、聚集，以毒性获得性功能损伤运动神经元。降低SOD1表达是直接对因的思路。血液和脑脊液中的神经丝轻链（NfL）可作为药效和疾病进展的生物标志物，有助于在小样本中评估疗效。

从临床结果学到了什么

  • 本站追踪到的SOD1临床记录仍很少：仅有Biogen的tofersen（ASO，3期）和UniQure一个1/2期项目，没有已记录的读出或失败，未来六个月也没有试验到达主要完成日期，因此暂时没有近期的检验节点。

剩下的机会

  • 症状出现前干预：在本站追踪的项目中，还没有数据回答在SOD1突变携带者发病前降低SOD1能否推迟发病，可结合NfL升高来筛选高风险人群。
  • 给药负担上的差异化：tofersen需要反复鞘内注射，UniQure的1/2期项目是本站追踪到的唯一替代方案，一次性或长效递送方式还有探索空间。
  • 野生型SOD1错误折叠可能参与部分散发性ALS，但降低SOD1能否惠及非突变患者尚未得到验证，需要伴随生物标志物来做患者分层。
