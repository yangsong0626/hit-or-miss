靶点小结

为什么重要

FXR是肝脏和肠道中感知胆汁酸的核受体，激活后经SHP及肠道FGF19抑制CYP7A1，减少胆汁酸合成、促进胆汁酸外排，并有抗炎和抗纤维化作用。因此它一直是原发性胆汁性胆管炎（PBC）等胆汁淤积性肝病和MASH的经典靶点。

从临床结果学到了什么

  • 本站仅追踪到Intercept两项obeticholic acid II期PBC试验，均达ALP主要终点（NCT05239468、联用bezafibrate的NCT04594694），后者因FDA要求Ocaliva自愿撤市而出于商业原因终止；未来六个月无读出，临床记录仍很薄。

剩下的机会

  • NCT04594694提示FXR激动联合贝特类可降低PBC患者ALP；在Ocaliva路径受阻后，可假设换用安全性更好的FXR激动剂延续这一联合策略。
  • 本站追踪的项目均为同一公司的同一胆汁酸衍生分子；非甾体或肠道限制性FXR激动剂（经FGF19起效）尚未出现，可检验肠道激活能否保留疗效并降低全身暴露。
  • 尽管通路标签为MASH，本站未追踪到MASH或原发性硬化性胆管炎项目，且ALP只是替代终点；FXR获益能否延伸至组织学或临床结局仍待验证。
