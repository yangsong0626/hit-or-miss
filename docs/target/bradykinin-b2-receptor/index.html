靶点小结

为什么重要

缓激肽通过内皮细胞上的B2受体增加血管通透性。遗传性血管性水肿(HAE)患者缺乏C1抑制物,血浆激肽释放酶失去控制,缓激肽蓄积，引发水肿发作。注射剂icatibant已证实B2拮抗可治疗急性发作，现在要回答的是口服拮抗剂能否同时用于按需治疗和预防。

从临床结果学到了什么

  • 临床记录仍有限，本站仅追踪到deucrictibant一个项目。II期NCT05047185达到发作率终点，提前结束是因为申办方把患者转入延长研究，与疗效无关。III期NCT06669754的注册结果将是首个正式检验。

剩下的机会

  • deucrictibant的适应症中包含C1抑制物缺乏所致获得性血管性水肿(AAE-C1-INH),但本站追踪的专门开发很少。该病同样由缓激肽驱动，可用来检验B2拮抗能否推广到遗传型以外的患者。
  • ACE抑制剂相关血管性水肿、C1抑制物正常的HAE等其他缓激肽介导的水肿，本站未见在研项目。可以考虑用缓激肽生成类生物标志物筛选患者，再验证B2拮抗是否有效。
  • icatibant是间歇给药，预防用药则需要长期持续阻断B2,而B2在血管和心脏保护中也有作用。长期安全性仍待回答，延长研究NCT06679881的数据可以提供参考。目前追踪到的项目均为小分子。
