靶点小结

为什么重要

胰岛素受体是受体酪氨酸激酶，结合胰岛素后经IRS–PI3K–AKT通路促进肌肉和脂肪摄取葡萄糖，并抑制肝糖输出。1型糖尿病缺乏胰岛素，2型糖尿病胰岛素分泌不足且存在抵抗，因此外源性激动该受体是验证最充分的降糖手段。当前研发重点是把基础胰岛素的给药间隔延长到每周一次。

从临床结果学到了什么

  • 临床记录仍然有限：本站目前只有Novo Nordisk的insulin icodec两项2型糖尿病III期读出（NCT06340854、NCT05813912），均达到HbA1c主要终点，尚无失败或提前终止记录。真正的新检验是GZR4的III期NCT06767735（主要完成日期为2026-08，结果待公布）和icodec在1型糖尿病的NCT07076199（2027-01）。

剩下的机会

  • 1型糖尿病是尚未验证的领域：本站追踪的icodec阳性结果均来自2型糖尿病。NCT07076199将检验在低血糖风险更高、剂量需频繁调整的人群中周制剂是否同样可行，低血糖与剂量调整方案可能是关键区分点。
  • 在本站追踪的项目中，GZR4是唯一进入III期的第二款周制剂。NCT06767735能否在低血糖发生率、剂量调整的简便性或与GLP-1类药物联用方面体现差异，将决定后来者的定位空间。
  • 三个项目均为多肽/蛋白激素。本站未追踪到葡萄糖响应型胰岛素、口服制剂或胰岛素受体激动性抗体，也没有项目针对INSR突变导致的严重胰岛素抵抗综合征，这些都可作为研究假设进一步评估。
