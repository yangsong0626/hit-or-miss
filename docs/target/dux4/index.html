靶点小结

为什么重要

DUX4是一种胚胎期转录因子，在成熟肌肉中本应沉默。FSHD1中4q35 D4Z4重复序列缩短，或FSHD2中SMCHD1突变，导致其在允许性4qA单倍型上异常表达，激活下游基因，造成肌细胞毒性。这是一种毒性获得功能机制，因此直接沉默DUX4有明确的遗传学依据。

从临床结果学到了什么

  • 临床证据仍很薄弱：本站仅追踪到Sarepta一项DUX4 siRNA项目（1/2期），尚无数据读出，未来六个月也没有试验到达主要完成日期，近期没有读出能检验该机制。

剩下的机会

  • 本站追踪的项目中只有siRNA一种模态。ASO、抗体-寡核苷酸偶联物，或针对D4Z4区的表观遗传沉默，都可作为验证不同骨骼肌递送策略的方向。
  • DUX4在肌肉中呈散发、低水平表达，难以直接检测。以DUX4下游基因表达特征结合肌肉MRI作为药效和入组生物标志物，可能决定早期试验能否看到信号。
  • 目前仅有一项早期项目，多数问题尚无答案：沉默程度与肌力或功能获益之间的关系，以及FSHD1与FSHD2患者的应答是否不同。
