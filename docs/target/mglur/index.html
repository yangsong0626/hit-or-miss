靶点小结

为什么重要

mGluR属C类GPCR，调节谷氨酸能传递：mGluR2/3作为突触前自身受体抑制谷氨酸释放，mGluR5位于突触后，与NMDA受体功能偶联。谷氨酸失调假说认为精神分裂症存在皮层谷氨酸异常，因此激动mGluR2/3被视为不依赖D2阻断的抗精神病路径。

从临床结果学到了什么

  • 临床记录仍然很薄。本站追踪的读出全部来自pomaglumetad methionil：NCT01129674和NCT01487083均以长期安全性为主要终点，因总体精神分裂症人群疗效结果被终止，判定为未达到。未来六个月内没有待读出的试验，近期不会有新的检验。

剩下的机会

  • 两项试验的终止理由都指向“总体人群”疗效，可假设获益局限于某个亚群；用遗传或其他生物标志物前瞻性富集患者，是检验该机制的主要剩余问题。
  • 在本站追踪的项目中只有两个小分子，没有mGluR5负性/沉默变构调节剂或mGluR2正性变构调节剂的疗效研究；抑郁、焦虑、神经退行性疾病等适应证目前未覆盖。
  • Allyx的未命名1期项目目前只做药物相互作用研究，靶向哪个亚型、进入哪个适应证，将决定该领域是否突破单一精神分裂症路径。
