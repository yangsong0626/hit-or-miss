靶点小结

为什么重要

ATR是复制应激反应的核心激酶，被停滞复制叉上的单链DNA激活，经CHK1阻滞细胞周期并保护复制叉。癌基因驱动的复制应激以及ATM缺失等DDR缺陷使肿瘤依赖ATR，构成合成致死逻辑；但ATR本身是必需基因，治疗窗是核心问题。

从临床结果学到了什么

  • 临床记录仍很薄：此处追踪的3个项目均为1期或1/2期小分子，入组未经分子筛选的晚期实体瘤，尚无读出或失败，未来6个月也无试验达到主要完成，近期没有首个真正检验。

剩下的机会

  • 此处追踪的项目都未限定生物标志物人群。ATM缺失、ARID1A缺失或CCNE1扩增等高复制应激特征能否富集应答者，仍是值得验证的假设。
  • 三个项目都在泛实体瘤中探索，未见血液肿瘤，也未见明确的联合方案。与PARP抑制剂、铂类、拓扑异构酶载荷ADC或放疗联用，可能是寻找增效窗口的方向。
  • 三个项目全部是小分子，后来者FXS887和Actuate的项目需要与较早的RP-3500拉开差异。间歇给药、更高选择性或肿瘤靶向递送能否拓宽治疗窗，尚待检验。
