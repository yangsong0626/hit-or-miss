靶点小结

为什么重要

ROCK1/2是RhoA下游激酶，调控肌动球蛋白收缩与细胞骨架，参与血管收缩、组织纤维化、Th17/Treg失衡及轴突再生抑制。ROCK2选择性抑制剂belumosudil已获批治疗慢性GVHD，ripasudil在日本用于青光眼，说明该靶点可成药且有临床验证。

从临床结果学到了什么

  • 临床记录仍很有限：唯一读出为ripasudil白内障术后角膜水肿3期试验，第12周ECD主要终点未达到（NCT05528172）；未来六个月本站未追踪到新读出，其余项目尚待检验。

剩下的机会

  • 肺血管疾病是可检验的方向：本站追踪的PAH与PH-ILD各有一项试验。ROCK同时介导血管收缩与重构，可假设肺部局部给药或亚型选择性有助于避开全身低血压。
  • 神经领域覆盖稀少，本站仅追踪到ALS和Friedreich共济失调试验。结合神经丝轻链等体液标志物，或可尽早确认靶点结合并筛选可能获益的患者。
  • belumosudil在cGVHD中的免疫-纤维化逻辑或可延伸至肺移植排斥。角膜方向上，NCT05528172未达终点，提示可考虑第12周ECD以外的终点，如角膜厚度或更长随访。
