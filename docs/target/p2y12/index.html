靶点小结

为什么重要

P2Y12是血小板上的Gi偶联ADP受体，放大血小板活化并稳定动脉血栓。clopidogrel、prasugrel、ticagrelor早已是急性冠脉综合征及PCI术后抗血小板治疗的基石，靶点验证充分；新的竞争点在起效速度、给药方式、疗程和出血风险。

从临床结果学到了什么

  • 本站尚无该靶点读出或失败记录：Viatris的selatogrel有3项III期试验未出结果，首个实质检验是NCT05952206（冠心病1个月DAPT，III期），预计2027年1月主要完成。

剩下的机会

  • selatogrel是本站跟踪的唯一P2Y12新药，针对急性心梗。症状出现时自行注射能否改善结局而不增加出血，以及哪些患者获益，仍待回答。
  • NCT05952206将检验冠心病患者1个月DAPT是否足够。把短程方案与出血风险评分或按CYP2C19基因型选药结合，是值得验证的患者分层假设。
  • 本站跟踪的项目均为冠心病领域小分子。外周动脉疾病、缺血性卒中，以及手术或出血时快速逆转P2Y12抑制的方案，在本站跟踪范围内尚无项目。
