靶点小结

为什么重要

亨廷顿病由HTT基因第1外显子CAG重复扩增引起，突变huntingtin蛋白携带延长的多聚谷氨酰胺链，导致纹状体和皮层神经元进行性丢失。该病为常染色体显性单基因病，40次以上重复即完全外显，降低突变HTT表达是最直接的疾病修饰策略。

从临床结果学到了什么

  • 临床记录仍很薄：本站追踪到2个项目（Skyhawk小分子2/3期、Roche tominersen 2期），尚无读出。2027年5月主要完成的2/3期试验NCT06873334将是首个实质检验。

剩下的机会

  • 两个追踪项目分别代表口服小分子与鞘内注射ASO两种路径。口服给药能否在全身暴露可耐受的前提下实现足够的中枢HTT降低，是NCT06873334有望初步回答的问题。
  • 本站追踪项目中尚无明确的等位基因选择性方案或AAV基因治疗。基于SNP的突变HTT选择性降低可规避野生型huntingtin耗竭的顾虑，是值得验证的方向。
  • 患者分层仍有空间：以CAG重复长度、脑脊液突变HTT和NfL等指标筛选前驱期或早期患者，并据此确定降低幅度与给药时机，或可提高检出疾病修饰效应的概率。
