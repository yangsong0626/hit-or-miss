靶点小结

为什么重要

IL-36R（IL1RL2）与IL-1RAcP组成受体，接收IL-36α/β/γ信号，激活角质形成细胞并招募中性粒细胞，推动脓疱性炎症。IL36RN功能缺失突变导致天然拮抗剂IL-36Ra失效，可引发泛发性脓疱型银屑病（GPP），为该靶点提供了遗传学依据。spesolimab已获批用于GPP急性发作。

从临床结果学到了什么

  • 临床记录仍很有限：本站唯一读出是spesolimab在化脓性汗腺炎的NCT06241573，主要终点为安全性，无统计检验，且被记录为提前终止、原因未说明，既不能证明疗效，也不能否定机制；未来6个月本站跟踪的试验中没有预期读出。

剩下的机会

  • GPP之外的中性粒细胞性皮肤病仍待验证：本站跟踪的化脓性汗腺炎和坏疽性脓皮病各只有一个项目，按疗效设计的试验可检验IL-36通路能否延伸到这些适应症。
  • 患者分层是一个未解问题：可按IL36RN、CARD14、AP1S3突变或皮损IL-36表达特征入组，检验这类患者是否在非GPP适应症中应答更好。
  • 本站跟踪的两个项目均为单抗（spesolimab和处于2期的HB0034），尚无口服小分子、局部用药或双靶点药物，这些形式在长期维持或预防发作方面或有差异化空间。
