靶点小结

为什么重要

JAK1与JAK2、JAK3或TYK2配对，传导IL-6、干扰素、IL-4/IL-13、IL-31等炎症因子信号。选择性抑制JAK1可阻断这些通路，同时尽量保留JAK2依赖的造血信号。upadacitinib等已获批药物已在类风湿关节炎、炎症性肠病和特应性皮炎中验证该机制。

从临床结果学到了什么

  • 本站追踪的读出中，仅STOP-HS2（NCT05620836）有正式假设检验，povorcitinib在化脓性汗腺炎中达到主要终点，其余两项为描述性。下一步关键检验是povorcitinib结节性痒疹（NCT06516965、NCT06516952）和upadacitinib狼疮（NCT05843643）试验。

剩下的机会

  • 本站追踪的项目中，干扰素驱动和血管炎类疾病覆盖较少：Takayasu动脉炎1个、cGVHD 2个，狼疮仅NCT05843643一项。其结果可检验JAK1选择性能否控制I型干扰素驱动疾病，并为按干扰素特征选择患者提供依据。
  • 本站追踪的8个项目均为口服全身用小分子，未见外用或肠道限制型JAK1抑制剂。局部暴露能否在皮肤或肠道病中保留疗效、同时规避JAK类药物的全身安全性顾虑，值得验证；FINCH 4（NCT03025308）正在长期随访安全性。
  • povorcitinib正拓展至特应性皮炎（本站已有3个项目）以外的皮肤病。结节性痒疹试验（NCT06516965、NCT06516952）及第二项HS试验（NCT06212999）将显示STOP-HS2结果能否复现，以及瘙痒和中性粒细胞驱动的皮肤病能否成为独立方向。
