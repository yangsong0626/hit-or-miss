靶点小结

为什么重要

KIT是干细胞因子的受体酪氨酸激酶，调控肥大细胞的存活与活化。激活突变驱动多数GIST，D816V突变见于绝大多数系统性肥大细胞增多症。imatinib已在GIST验证KIT抑制的价值，抗KIT抗体通过清除肥大细胞，把这一靶点拓展到荨麻疹等炎症性疾病。

从临床结果学到了什么

  • 临床记录仍薄：唯一读出NCT06736262（briquilimab）因公司战略调整终止，与安全性无关，不能说明机制优劣。首个真正检验是barzolvolimab的CSU三期NCT06455202与NCT06445023，结果尚未收录。

剩下的机会

  • 除CSU外，本站收录的结节性痒疹、特应性皮炎、寒冷性荨麻疹各只有1个项目，可借此检验肥大细胞清除在哪些瘙痒性疾病中起主导作用。
  • KIT也表达于黑素细胞、生殖细胞和造血祖细胞，长期清除肥大细胞的耐受性仍待回答。可逆的口服小分子或间歇给药方案可能是慢性炎症适应症中的差异化方向。
  • 本站收录GIST项目3个、ISM项目2个，均无读出。用ctDNA按继发KIT突变（如外显子13与17）分层，或可明确不同抑制剂分别适合哪类耐药人群。
