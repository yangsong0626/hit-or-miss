靶点小结

为什么重要

BCR-ABL是t(9;22)易位（费城染色体）产生的融合激酶，持续激活下游增殖信号，是CML的始动驱动因素，也见于部分ALL。Imatinib的成功使其成为靶向治疗验证最充分的靶点，后续研发主要围绕耐药突变（如T315I）、耐受性和停药后无治疗缓解展开。

从临床结果学到了什么

  • 临床记录仍然偏少：目前只有一项读出，即Asciminib的III期ASC4START（NCT05456191）达到以不良事件停药时间为终点的主要终点，说明耐受性本身可以作为一线CML的注册路径。下一项检验是Olverembatinib在GIST中的III期NCT06640361。

剩下的机会

  • 在本站追踪的项目中，一线及难治CML已有多个III期药物，Enliven、CTTQ（TQB3911）和Hansoh的I期分子若要差异化，可能需要在T315I或复合突变、长期耐受性或无治疗缓解率上拿出证据。
  • 新诊断Ph+ ALL仅有少数项目在做，可以探索TKI联合减化疗方案，并以MRD为导向做分层，这一方向仍有空间。
  • NCT06640361将检验Olverembatinib能否拓展到GIST。需注意其在GIST中的活性主要来自对KIT/PDGFRA的作用，而非BCR-ABL，按突变类型筛选患者可能是关键。
