靶点小结

为什么重要

PDE10A富集于纹状体中型多棘神经元，水解cAMP和cGMP，调控直接与间接通路平衡。抑制它可不经D2阻断调节多巴胺相关信号，支撑精神分裂症和运动障碍的开发；PDE10A突变可导致儿童期起病的运动亢进障碍，提供了人类遗传学依据。

从临床结果学到了什么

  • 记录仍薄：CPL500036两项II期（异动症NCT05297201、精神分裂症NCT05278156）均无统计检验，不判成败；未来6个月无到期试验，Gemlapodect尚无读出。

剩下的机会

  • 在此追踪的项目中，只有Gemlapodect布局抽动症；结合PDE10A突变导致运动亢进的遗传学，运动障碍可能比精神病更契合机制，其读出将检验这一假设。
  • 在此追踪的项目中，亨廷顿病舞蹈症等其他运动亢进适应症尚无布局；纹状体PDE10A表达随亨廷顿病和帕金森病进展而下降，按病程早期分层入组可能是关键。
  • 可借助PDE10A PET配体，按靶点占有率确定剂量；NCT05297201与NCT05278156的完整数据或可显示，异动症与阳性症状哪个方向更值得推进确证性研究。
