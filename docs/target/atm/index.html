靶点小结

为什么重要

ATM是DNA双链断裂后最先被激活的PIKK家族激酶，通过磷酸化CHK2、p53等启动细胞周期检查点和同源重组修复。抑制ATM可阻断肿瘤细胞修复放疗及拓扑异构酶抑制剂造成的损伤，因此主要用作放化疗增敏剂，也可与其他DDR抑制剂联用。

从临床结果学到了什么

  • 临床证据仍很薄。本站仅追踪到CSPC Megalith的小分子SYH2051一个项目，处于1/2期，覆盖乳腺癌和晚期实体瘤，尚无读出。未来六个月内也没有到达主要完成日期的试验，机制的首次实际检验时间尚不明确。

剩下的机会

  • 本站追踪的项目只有单药或未注明联用方案的实体瘤试验。可以考虑与放疗、拓扑异构酶I类化疗或以其为载荷的ADC联用，验证ATM抑制的增敏作用能否转化为临床获益。
  • 可探索按生物标志物选择患者，例如其他DDR基因缺陷或p53功能异常的肿瘤，检验合成致死假设；同时需关注与PARP或ATR抑制剂联用时叠加的骨髓毒性。
  • 本站追踪范围内尚无具备脑渗透性的ATM抑制剂项目，与放疗联用治疗胶质瘤或脑转移是一个可检验的空白方向；降解剂等其他分子类型也还没有出现。
