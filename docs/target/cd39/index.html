靶点小结

为什么重要

CD39（ENTPD1）把胞外ATP/ADP水解为AMP，AMP再由CD73转化为腺苷，腺苷通过A2A受体抑制T细胞和NK细胞。CD39富集于Treg、耗竭CD8 T细胞和髓系细胞。阻断CD39可在两端同时起效，保留促炎ATP，减少腺苷生成。

从临床结果学到了什么

  • 目前临床证据仍很少：本站只追踪到一个CD39项目，即Elpiscience的未命名单抗，处于2期，适应症为实体瘤和硬纤维瘤。尚无读出，未来6个月内也没有试验到达主要完成日期。

剩下的机会

  • 免疫肿瘤药物很少做硬纤维瘤。硬纤维瘤间质中的CD39表达或腺苷信号能否预测获益，目前还没有答案，可以用肿瘤组织生物标志物研究来回答。
  • 本站追踪的项目中还没有看到患者筛选策略。富集CD39+ CD8 T细胞浸润高的肿瘤，或与PD-1、CD73、A2A受体阻断联用，都可以用来检验CD39阻断能否在现有检查点抑制剂之上带来额外获益。
  • 本站只追踪到单抗这一种形式。CD39与PD-1或CD73的双抗、小分子抑制剂，以及经CD39改造的细胞疗法，都是还没人走过的验证路径。
