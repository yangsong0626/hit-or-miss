靶点小结

为什么重要

IL-18属IL-1家族，经炎症小体与caspase-1剪切活化，驱动Th1/NK细胞产生IFN-γ，体内由IL-18BP中和。游离IL-18升高见于巨噬细胞活化综合征及NLRC4相关自身炎症病，IL18RAP变异与IBD相关，支持其在肠道炎症中的作用。

从临床结果学到了什么

  • 临床记录仍很有限：本站追踪的项目中仅有GSK一款未命名的1期单抗（溃疡性结肠炎，2026年8月首次登记），尚无读出，未来六个月内也无试验到达主要完成节点。

剩下的机会

  • 本站追踪范围内，尚无项目覆盖游离IL-18致病性最明确的适应症，如巨噬细胞活化综合征、Still病及NLRC4或XIAP相关自身炎症；血清游离IL-18可作为现成的入组筛选标志物。
  • 在溃疡性结肠炎中，临床前研究提示IL-18既促炎又参与上皮修复。按黏膜IL-18/IFN-γ特征分层并监测屏障指标，或可判断阻断是否仅在特定亚群获益。
  • 目前追踪到的仅为单抗。只中和游离IL-18的设计、基于IL-18BP的生物药，或IL-18与IL-1β/TNF双靶点分子在本站尚无项目，可作为机制差异化方向。
