靶点小结

为什么重要

多巴胺受体分为D1样（D1/D5）和D2样（D2/D3/D4）两类GPCR，调控运动、奖赏、冲动控制和性功能。D2拮抗剂和激动剂早已用于精神分裂症和帕金森病，但锥体外系和代谢副作用限制了使用。选择性阻断D1/D5被视为治疗抽动障碍、同时避开D2相关毒性的一条路径。

从临床结果学到了什么

  • 临床记录仍然很少：这里只跟踪到1项读出，即ecopipam在Tourette综合征中的小型Phase 2（NCT02102698，n=40），以YGTSS总抽动评分为主要终点并达到。它初步支持D1/D5拮抗治疗抽动，但样本量不足以评估长期安全性。Ecopipam虽列为Phase 3，FACTS中尚无Phase 3读出，未来6个月也没有待读出的试验。

剩下的机会

  • 在这里跟踪到的项目中，ecopipam是唯一的D1/D5拮抗剂。可以检验这一机制能否延伸到D2阻断因锥体外系或代谢负担而难以长期使用的其他抽动或冲动相关障碍，同时需要更大规模的Phase 3和儿童长期安全性数据。
  • 勃起功能障碍方向只有Yanping Kong一项早期Phase 1项目，靶向的受体亚型未披露。中枢多巴胺机制或许适合PDE5抑制剂应答不佳的人群，关键在于亚型选择性能否把恶心和低血压控制在可接受范围。
  • 目前跟踪的两个项目都是正构小分子。D1正向变构调节剂、偏向性激动剂等亚型选择性更高的分子在这里还没有出现，可以考虑用于认知或运动障碍，以拉开与传统D2药物的距离。
