靶点小结

为什么重要

BTK传导B细胞受体信号，驱动恶性B细胞存活与增殖，并参与肥大细胞、髓系细胞和小胶质细胞的Fc受体信号。BTK功能缺失导致X连锁无丙种球蛋白血症。Ibrutinib在CLL获批多年，早已验证该靶点，研发正向自免、过敏和神经炎症延伸。

从临床结果学到了什么

  • 非共价抑制剂pirtobrutinib在初治CLL达到PFS主要终点（NCT05023980），站内记录显示已获FDA批准。所追踪28个项目中19个在III期，集中于CLL/SLL和MCL，竞争拥挤。
  • 肿瘤之外，BTK抑制在肥大细胞或自身抗体驱动的疾病中见效：rilzabrutinib在CSU达到终点（NCT05107115），奥布替尼ITP III期据新闻达到主要终点；在特应性皮炎则未达到（NCT05018806）。
  • 近期多项读出没有正式假设检验：ASSURE（NCT04008706）、ibrutinib小样本CLL研究（NCT05105841）和LOU064花生过敏研究（NCT05432388）均属描述性，只能支持安全性评估和信号探索。

剩下的机会

  • CNS疗效仍待验证：LOU064两项RMS III期（NCT05147220、NCT05156281）已于2026年7月到达主要完成日，本站尚未收录结果，将检验同时作用于小胶质细胞和B细胞的BTK抑制能否转化为临床获益。
  • 自身抗体和肥大细胞相关适应症值得深挖：rilzabrutinib ITP III期（NCT07216079）和LOU064 CSU研究（NCT05677451）将于11月前后完成。AD失利提示可按IgE、肥大细胞或自身抗体特征筛选患者。
  • 降解剂有望在抑制剂治疗后的人群中实现差异化：tacabrutideg和NX-5948已列入III期，但尚无读出。清除BTK蛋白可能克服耐药突变和非激酶支架功能，按突变入组值得验证。
