靶点小结

为什么重要

GRN杂合功能缺失导致颗粒体蛋白（progranulin）水平不足，是遗传性额颞叶痴呆（FTD-GRN）的明确病因。progranulin参与溶酶体功能，sortilin负责结合并内吞降解细胞外progranulin。阻断sortilin或补充GRN基因可提高progranulin水平，因此遗传学依据扎实。

从临床结果学到了什么

  • 临床证据仍然有限：本站追踪的项目中，真正检验疗效的只有AL001的3期试验NCT04374136，该试验未达到减缓FTD-GRN进展的临床共同主要终点。Passage Bio的PBFT02（NCT04747431）提前终止，申办方说明是出于公司资源调配考虑，与安全性无关，不能据此否定机制。未来6个月内没有本站追踪的试验到达主要完成节点。

剩下的机会

  • AL001的阴性结果提示，单纯通过阻断sortilin提高细胞外progranulin可能不足以带来临床获益。AviadoBio等基因治疗项目直接补充GRN，检验的是另一种假设；Passage Bio退出后，这一方向的有效性仍待验证。
  • AL001试验的主要终点针对有症状患者。在症状前GRN携带者中，以progranulin水平、NfL等生物标志物入组并开展早期干预，是尚待验证的思路。
  • Denali项目（本站未注明其模态）等早期项目可探索提高脑内progranulin的不同路径。可以考察靶点结合与临床获益之间的脱节，究竟出在暴露部位、给药时机还是终点选择上。
