靶点小结

为什么重要

UBE3A 编码 E3 泛素连接酶，在神经元中只表达母源等位基因，父源拷贝被反义转录本 UBE3A-ATS 沉默。母源 UBE3A 缺失或突变导致 Angelman 综合征。用 ASO 敲低 UBE3A-ATS 可以解除父源拷贝的沉默、恢复蛋白表达，这是本靶点所有在研药物的共同思路。

从临床结果学到了什么

  • Ultragenyx 的 apazunersen 在 3 期 Aspire（NCT06617429）中以 Bayley-4 认知评分为主要终点，主要和关键次要终点均未达到。这是本站追踪到的首个该机制 3 期对照读出，结果为阴性。
  • Aspire 失败后，apazunersen 的 2 期 Aurora（NCT07157254）和 3 期安全性研究（NCT06415344）同日以疗效不足为由终止。这两项试验的主要终点都是安全性，终止反映的是整个项目被放弃，而不是出现了新的安全信号。
  • 目前的阴性证据只来自一个分子。obudanersen（Ionis）和 rugonersen（OHB Pediatrics）仍在 3 期，所以这次失败还不能直接推及整个 UBE3A-ATS 敲低机制。本站追踪的范围内，未来 6 个月没有可以验证这一点的读出。

剩下的机会

  • obudanersen 和 rugonersen 与 apazunersen 在剂量、CNS 分布、患者入组年龄和终点设计上有何差异，决定了它们能否避开 Aspire 的结局。可以检验的假设是：更早给药、更长观察期，或者换掉 Day 338 的 Bayley-4 认知评分，可能更容易测到获益。
  • 在患者选择和药效评估上，可以按缺失型、UBE3A 点突变、UPD 等基因型分层，并用 EEG delta 功率等生物标志物确认父源 UBE3A 是否真的被激活，从而区分是靶点没有调起来还是下游没有获益。
  • 本站追踪的 3 个项目全部是 ASO。UBE3A 基因替代、编辑 UBE3A-ATS 的基因编辑以及小分子去沉默等路线尚无临床项目，可以作为与 ASO 区分的方向。
