靶点小结

为什么重要

RAS（KRAS、NRAS、HRAS）突变见于约四分之一的人类肿瘤，胰腺导管腺癌中KRAS突变率超过90%。RAS-ON抑制剂直接结合活化的GTP结合态，可覆盖G12D、G12V、Q61等多种突变，弥补G12C特异性药物覆盖面窄、易因RAS再激活而耐药的不足。

从临床结果学到了什么

  • 本站跟踪的项目中尚无读出、无失败记录，未来六个月也没有到达主要完成日期的试验，临床证据仍很薄。daraxonrasib是唯一进入3期的项目，其余多处于1期或1/2期，首个真正的检验暂未排入本站跟踪的时间表。

剩下的机会

  • 本站跟踪的试验集中在PDAC和未经选择的晚期实体瘤，CRC和NSCLC各仅1个项目，黑色素瘤等NRAS驱动肿瘤尚无项目。30项试验均为肿瘤适应症，RAS病等非肿瘤方向也是空白。
  • 9个项目中仅ERAS-0015为降解剂。在可耐受剂量下，降解RAS能否比三元复合物等抑制剂带来更深、更持久的通路抑制，仍是一个可以通过临床前和早期临床对比回答的问题。
  • 泛RAS药物同时作用于正常组织中的野生型RAS，治疗窗是后来者面临的核心问题。按等位基因（G12D、G12V、G12R、Q61）及共突变选择患者、用于G12C抑制剂耐药后，或与上下游通路抑制剂联用，都是与daraxonrasib形成差异的可能路径。
