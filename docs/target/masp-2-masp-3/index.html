靶点小结

为什么重要

MASP-2是凝集素途径的效应丝氨酸蛋白酶，识别分子结合病原体或受损内皮后，由它切割C4和C2，启动补体级联。MASP-3可活化前体因子D，连接旁路途径。抑制MASP-2可阻断凝集素途径，同时保留经典途径，理论上适用于内皮损伤驱动的血栓性微血管病。

从临床结果学到了什么

  • 该靶点的临床记录仍然很薄：本站仅追踪到Omeros的narsoplimab一项2期单抗项目（造血干细胞移植相关血栓性微血管病），尚无读出或失败记录，未来6个月也没有到达主要完成日期的试验，暂无近期数据可作为第一次真正检验。

剩下的机会

  • 在本站追踪的项目中尚无直接针对MASP-3的项目。MASP-3抑制可切断因子D活化、调控旁路途径，可作为与MASP-2抑制并行验证的独立假设。
  • 目前追踪到的项目只覆盖移植相关血栓性微血管病。可用凝集素途径活化标志物（如MBL水平、C4d沉积）筛选患者，探索其他以内皮损伤为主的补体介导疾病。
  • 追踪到的唯一模式是静脉单抗。口服小分子或长效制剂能否在慢性适应症中实现持续的凝集素途径抑制，仍是未回答的问题。
