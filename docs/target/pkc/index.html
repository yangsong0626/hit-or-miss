靶点小结

为什么重要

PKC是一组丝氨酸/苏氨酸激酶。PKCβ位于B细胞受体（BCR）信号中BTK和PLCγ2的下游，可激活NF-κB，维持CLL细胞存活；PKCθ则介导T细胞受体信号。在BCR信号通路之下抑制PKC，有望覆盖上游靶点耐药的肿瘤。

从临床结果学到了什么

  • 临床记录仍很有限：本站仅追踪到1个项目，即MingSight的小分子MS-553，处于1/2期，适应症为CLL/SLL，目前尚无读出、失败记录，未来6个月内也没有预计达到主要完成日期的试验，暂时无法检验该机制。

剩下的机会

  • PKCβ位于BTK和PLCγ2下游，可检验MS-553等PKC抑制剂在携带BTK或PLCG2耐药突变的CLL中能否维持活性，并据此进行患者筛选。
  • 在本站追踪的项目中，PKC靶点仅有1个小分子、1家公司，与BCL2抑制剂（如venetoclax）的联合用药，以及其他依赖BCR信号的B细胞淋巴瘤，均尚无项目覆盖。
  • PKCθ在T细胞活化中起作用，但本站未追踪到针对自身免疫或炎症疾病的项目。可评估亚型选择性抑制剂在这类疾病中的潜力。
