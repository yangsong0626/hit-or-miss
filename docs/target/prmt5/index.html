靶点小结

为什么重要

PRMT5催化精氨酸对称二甲基化，调控RNA剪接。约10–15%肿瘤存在MTAP与CDKN2A共缺失，MTA蓄积使PRMT5部分受抑，形成合成致死窗口；MTA协同型抑制剂选择性作用于MTAP缺失细胞，有望避开第一代抑制剂的血液学毒性。

从临床结果学到了什么

  • 临床记录仍很有限：本站尚无PRMT5读出或失败记录。17个项目多为1–1/2期小分子，BMS-986504与navlimetostat已进入2/3期；未来六个月无追踪试验到达主要完成。

剩下的机会

  • 追踪项目集中于NSCLC、PDAC及MTAP缺失实体瘤泛瘤种。胶质母细胞瘤、间皮瘤、尿路上皮癌等同样常见MTAP缺失，却少有专门入组，可作为脑渗透型或瘤种特异开发的切入点。
  • 12家公司的小分子路线高度同质，差异化可能来自合理联用（如在PDAC、NSCLC中联合KRAS或MAT2A抑制剂），以及统一IHC与测序对MTAP缺失的判定标准。
  • 有2个追踪项目涉及非霍奇金淋巴瘤，血液肿瘤中能否按MTAP状态或剪接因子突变界定获益人群尚未验证；BMS的2/3期项目将是实体瘤中首个后期检验。

  • 项目最集中的适应症：Solid Tumors（6 个项目）、MTAP-deleted Solid Tumors（3 个项目）。
