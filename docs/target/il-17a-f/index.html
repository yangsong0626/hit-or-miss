靶点小结

为什么重要

IL-17A与IL-17F由Th17、γδ T细胞和ILC3在IL-23驱动下分泌，经IL-17RA/RC受体激活角质形成细胞和滑膜、附着点炎症，并募集中性粒细胞。secukinumab、ixekizumab已在银屑病、PsA和中轴型脊柱关节炎中验证该通路。IL-17F在化脓性汗腺炎等病灶中同样升高，这是A/F双重阻断的依据。

从临床结果学到了什么

  • sonelokimab的两项2期均达到主要终点，分别为PsA（NCT05640245）和化脓性汗腺炎（NCT05322473），支持IL-17A/F双重阻断在关节和皮肤两条线上同时成立，目前已推进至3期。
  • tibulizumab在一项皮肤病2期中未达到终点（NCT06843239），这说明把IL-17阻断带出银屑病、脊柱关节炎和HS这些核心适应症，或与其他机制组合，疗效并不能直接外推。
  • ZL-1102以溶媒为对照的2期因申办方决定终止（NCT06380907），属商业原因，不能作为否定机制的证据；局部或非注射给药路线因此仍未得到检验。
  • 本站追踪的13个项目中11个为单抗，集中在银屑病、PsA、HS和中轴型脊柱关节炎；netakimab、picankibart及secukinumab生物类似药的加入，使竞争更多转向适应症覆盖和价格。

剩下的机会

  • HS是接下来的主要检验场：bimekizumab（NCT04901195、NCT06921850）、sonelokimab 3期（NCT06768671）和tibulizumab（NCT06993610）结果待公布，可回答纳米抗体与IgG格式能否拉开差距，按病灶IL-17F水平或窦道负荷分层也值得探索。
  • 在本站追踪范围内，非抗体项目只有一个，且已因商业原因终止。口服或局部IL-17抑制剂用于轻中度或不愿注射的患者仍是空白，关键在于证明组织暴露足够。
  • 幼年型PsA、附着点炎相关关节炎和掌跖脓疱病只有少数项目覆盖，加上bimekizumab中轴型SpA 3期（NCT04436640），儿科和小众适应症仍是区分于头部产品的方向。
