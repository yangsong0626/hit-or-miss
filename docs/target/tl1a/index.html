分类与通路

分类：细胞因子与免疫受体 › IL-23 / Th17 与 TNF
同家族：IL-23 / IL-23R · IL-17A/F · TNF · IL-12 · IL-36R

IL-23 / Th17 · 下游 IL-17A/F / TNF / IL-36R
TL1A / IL-23 / IL-23R / IL-12 → IL-17A/F / TNF / IL-36R
