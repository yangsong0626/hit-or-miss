靶点小结

为什么重要

PSMA（FOLH1）是一种II型跨膜谷氨酸羧肽酶，在前列腺癌细胞表面高表达，并随去势抵抗和高级别病变而上调；配体结合后可内化，适合放射性配体的显像与治疗。177Lu-PSMA-617获批用于mCRPC，已在临床上验证该靶点。

从临床结果学到了什么

  • 检验性读出仍少：仅PSMAddition（NCT04720157）达到rPFS主要终点；acapatamab（NCT04631601）因商业原因停止，并非机制失败。下一步看NCT06004661、NCT06235151和NCT07052214。

剩下的机会

  • α核素是主要差异化方向：FPI-2265、225Ac-PSMA-R2、AZD2265处于早期临床。可检验其在177Lu治疗后进展患者中的获益，以及唾液腺和肾毒性的代价。
  • 非放射性配体路线仍处早期：本站追踪3个细胞治疗、2个偶联药物，T细胞衔接器acapatamab因商业原因停止。能否覆盖PSMA低表达或异质性肿瘤尚无答案。
  • 本站追踪试验全部集中于前列腺癌，但PSMA也表达于多种实体瘤的新生血管。以PET筛选的前列腺外适应症，以及PSMAddition之后的寡转移等更早阶段仍待验证。
