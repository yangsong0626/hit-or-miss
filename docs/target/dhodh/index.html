靶点小结

为什么重要

DHODH位于线粒体内膜，催化嘧啶从头合成的第四步，并与电子传递链偶联。快速增殖的肿瘤细胞高度依赖嘧啶从头合成，这是把该靶点用于肿瘤治疗的依据。leflunomide和teriflunomide已在自身免疫病中长期使用，说明该靶点可以成药。

从临床结果学到了什么

  • 临床证据仍然很少：本站目前只跟踪到Jabez的一个实体瘤I期小分子项目，没有读出，也没有失败记录，未来六个月内也没有试验到达主要完成日，短期内看不到第一次真正的临床检验。

剩下的机会

  • 本站跟踪的项目只覆盖实体瘤。血液肿瘤（如AML）里，DHODH抑制可诱导分化，这一方向在本站跟踪范围内还没有项目，值得作为假设去验证。
  • 肿瘤可以通过尿苷补救途径绕开DHODH抑制。按补救途径活性（如UCK2、核苷转运体表达）筛选患者，或联用补救途径阻断，可能是提高单药活性的思路。
  • 嘧啶耗竭可能影响肿瘤抗原呈递和代谢应激，与免疫治疗或DNA损伤类药物联用的合理性，目前尚无本站跟踪的临床数据检验。
