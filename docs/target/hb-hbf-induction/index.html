靶点小结

为什么重要

胎儿血红蛋白（HbF）不参与HbS聚合，能稀释镰状血红蛋白并减轻溶血和血管闭塞。BCL11A是成人期γ-珠蛋白的关键抑制因子。HPFH和BCL11A增强子变异的人群遗传学、羟基脲部分经HbF起效，以及离体BCL11A增强子编辑的临床结果，共同验证了这一机制。

从临床结果学到了什么

  • 临床记录仍很薄。本站唯一的读出是Fulcrum的Pociredir II期试验NCT07401823，仅入组1例即以申办方决定终止（biz），不能作为否定机制的证据。未来6个月没有已追踪的主要完成节点，近期难有新的检验。

剩下的机会

  • 本站追踪的2个项目都只针对镰状细胞病。HbF诱导在生物学上同样适用于β-地中海贫血，口服药在这一适应症上的空白值得评估。
  • 已追踪的项目只有小分子和细胞治疗。体内编辑、针对BCL11A的寡核苷酸或siRNA、BCL11A/ZBTB7A降解剂等路径在此尚未出现，可作为探索方向。
  • 口服HbF诱导剂与细胞治疗相比的定位，可能取决于能否实现全细胞（pancellular）HbF分布。按基线HbF或羟基脲应答对患者分层，以及与羟基脲联用，都是尚未回答的问题。
