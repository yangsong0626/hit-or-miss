靶点小结

为什么重要

PKMYT1磷酸化CDK1 Thr14位点使其失活，阻止细胞在DNA复制完成前进入有丝分裂。CCNE1扩增或FBXW7、PPP2R1A缺失的肿瘤高度依赖这一刹车，抑制PKMYT1可迫使细胞提前进入有丝分裂而死亡，该合成致死关系由CRISPR筛选发现。

从临床结果学到了什么

  • 临床证据仍很薄弱。本站追踪的仅有两款I期小分子：Lunresertib（Debiopharm，2021年登记）和FXS0260（Shanghai Fosun，2026年11月登记），均面向泛实体瘤。目前没有读出或失败记录，未来六个月也没有到达主要完成日的试验，近期无法从这里得到首次真正检验。

剩下的机会

  • 两项在追踪的试验均入组泛实体瘤。可前瞻性筛选CCNE1扩增或FBXW7、PPP2R1A改变的肿瘤（如卵巢癌、子宫内膜癌、胃癌），检验合成致死假设能否在临床上成立。
  • PKMYT1抑制与ATR抑制剂或吉西他滨等加剧复制压力的化疗之间可能存在协同。联合用药究竟能拓宽治疗窗，还是叠加骨髓毒性，本站追踪的记录尚未涉及。
  • 在追踪的项目中只有小分子。相对WEE1及其他激酶的选择性，或降解剂等新模态，可能是后来者的差异化方向。

分类与通路

分类：激酶 › 细胞周期激酶

细胞周期 · 上游 CDK2 / CDC7 · 下游 Aurora A / PLK1 / KIF18A
CDK4/6 → CDK2 / CDC7 → WEE1 / PKMYT1 → Aurora A / PLK1 / KIF18A
G1/S 由 CDK4/6 和 CDK2 推进；G2/M 由 WEE1、PKMYT1 把关，Aurora A、PLK1、KIF18A 负责有丝分裂。
DNA 损伤应答 · 上游 ATM / ATR · 下游 PARP1 / PARP（泛） / POLQ (Polθ) / WRN
ATM / ATR → WEE1 / PKMYT1 → PARP1 / PARP（泛） / POLQ (Polθ) / WRN
ATM、ATR 感知损伤，经 WEE1 让细胞周期停下修复；PARP、Polθ、WRN 是不同修复途径，各自和特定缺陷合成致死。
