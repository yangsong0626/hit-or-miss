靶点小结

为什么重要

Nav1.7（SCN9A）和Nav1.8（SCN10A）主要表达于外周伤害感受神经元，负责痛觉信号的产生与传导。SCN9A功能缺失导致先天性无痛症，功能获得突变引起红斑性肢痛症，人类遗传学验证充分。选择性外周阻断有望提供非阿片类镇痛，同时避开中枢和心脏钠通道。

从临床结果学到了什么

  • 临床记录尚薄：本站暂未收录该靶点的任何读出或失败。首批真正检验将是suzetrigine在糖尿病周围神经病理性疼痛中的两项III期试验，NCT06696443（主要完成日2027-01-25）与NCT07231419（2027-04-06）。

剩下的机会

  • 在本站收录范围内，三个项目均为Vertex的小分子，单一公司、单一模态。抗体、ASO/siRNA或基因治疗等手段在Nav1.7/Nav1.8上尚无收录项目，可作为差异化方向探索。
  • 收录试验集中于急性疼痛和DPN。SCN9A/SCN10A功能获得突变相关的小纤维神经病、红斑性肢痛症，以及通路所涉的慢性咳嗽，可借助遗传分层富集应答人群。
  • NCT06696443与NCT07231419将回答外周Nav1.8阻断能否从急性疼痛延伸到慢性神经病理性疼痛并在长期给药中维持疗效，这一结果决定后续VX-993等项目的适应症取舍。
