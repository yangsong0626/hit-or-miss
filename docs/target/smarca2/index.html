靶点小结

为什么重要

SMARCA2（BRM）与旁系同源蛋白SMARCA4（BRG1）是SWI/SNF染色质重塑复合物中可相互替代的ATP酶亚基。SMARCA4缺失的肺癌、胃食管癌等肿瘤依赖SMARCA2存活，因此SMARCA2是合成致死靶点。两者高度同源，能否抑制SMARCA2同时不影响正常组织中的SMARCA4是关键。

从临床结果学到了什么

  • 临床记录仍很薄：本站仅追踪到Plexium的PLX-61639和Eli Lilly一款未命名小分子，均为1期，尚无读出，未来六个月内也没有追踪到的试验到达主要完成节点。

剩下的机会

  • 已追踪项目列出的适应症为胃腺癌、食管鳞癌和转移性实体瘤。SMARCA4缺失在NSCLC中较常见，但在本站追踪的项目中未单列为适应症，可考察专门的NSCLC队列能否更早显示信号。
  • SMARCA4缺失的定义方式（截短突变、IHC蛋白缺失或错义突变）可能决定获益人群，SMARCA2表达同时缺失可能预示无效。早期试验可检验哪种生物标志物最能预测疗效。
  • 本站追踪的两个项目均为小分子。不同的选择性实现方式（降解剂、ATP酶或别构抑制）及与化疗、免疫治疗或KRAS抑制剂的联合，尚未见于追踪项目，可作为差异化方向。
