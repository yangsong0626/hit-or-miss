靶点小结

为什么重要

TROP2（TACSTD2）是一种跨膜糖蛋白，参与钙信号转导，促进肿瘤增殖与侵袭。它在乳腺、肺、尿路上皮、子宫内膜等多种上皮肿瘤中高表达，与抗体结合后会被内吞，因此很适合做ADC靶点。Sacituzumab govitecan自2020年获批用于转移性三阴性乳腺癌，证明了这条路线可行。

从临床结果学到了什么

  • 本站追踪的17个项目中有11个是ADC，进入3期的3个品种都是拓扑异构酶I抑制剂载荷ADC。单抗、双抗和细胞治疗还在1-2期，所以该靶点目前的临床验证几乎都来自ADC。
  • 获益因瘤种而异。TROPiCS-04（NCT04527991）中，sacituzumab govitecan未能改善经治尿路上皮癌的总生存。另据公告，sac-TMT在铂类和PD-(L)1治疗后进展的子宫内膜癌中改善了OS和PFS（TroFuse-005）。可见TROP2广泛表达本身不能预测生存获益。
  • 本站记录的失败都是疗效原因，且都出自同一项尿路上皮癌3期试验，没有因安全性或商业原因终止的记录。尿路上皮癌2期试验NCT05327530没有正式假设检验，对该适应症的判断既不能扭转，也不构成进一步的否定。

剩下的机会

  • 患者选择仍有空白。本站追踪的试验按瘤种开展，而不按TROP2表达水平分层。可以检验定量或膜定位的TROP2评分能否区分获益人群，这可能有助于解释尿路上皮癌的失败，也能改进弱势适应症的试验设计。
  • 子宫内膜癌的阳性结果能否推广到其他瘤种，有几项3期试验将给出检验：sac-TMT的NSCLC试验（NCT06448312、NCT06711900）和胃食管癌试验（NCT06356311），以及sacituzumab govitecan的乳腺癌试验（NCT04639986）。这几项试验均在2026年底前到达主要完成日。
  • 拓扑异构酶I载荷ADC以外的形式探索很少，本站仅追踪到一个双抗（AK146D1）和一个NK细胞疗法（EB-NK-301）。可以在TROP2 ADC治疗后进展的人群中验证不同载荷或非ADC形式。非肌层浸润性膀胱癌（NCT06637423）也是一个早期探索方向。
