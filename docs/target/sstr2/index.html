靶点小结

为什么重要

SSTR2是垂体生长激素腺瘤和分化良好神经内分泌瘤（NET）上表达最多的生长抑素受体亚型。激动该受体可抑制GH及多种激素分泌，并抑制细胞增殖。受体表达量高、配体结合后会内化，因此也适合做诊疗一体化靶点。octreotide、lanreotide和177Lu-DOTATATE已上市多年，靶点已经过验证。

从临床结果学到了什么

  • 在本站追踪的管线中，多肽、口服小分子和放射性配体三类分子都在推进。paltusotine的2期研究NCT04261712因商业原因终止，申办方说明与获益风险变化无关，不能据此否定口服非肽类激动剂，Crinetics仍有3期项目在推进。
  • SSTR2激动的适应症已从内分泌和肿瘤扩展到囊性疾病。CAM2029在多囊肝病的POSITANO研究（NCT05281328）中达到身高校正肝体积主要终点，与抑制cAMP驱动囊肿生长的机制相符。
  • 在放射性配体方向，换用更强的载荷可能克服耐药。ACTION-1期中分析显示，锕-225标记的RYZ101用于Lu-177治疗后进展的GEP-NET，PFS显著优于对照，说明患者β粒子治疗进展后SSTR仍可作为靶点，但公司未公布风险比。

剩下的机会

  • RYZ101的3期研究NCT05477576（GEP-NET）预计2026年12月到达主要完成日，另一款177Lu-DOTATATE（NCT07057622）的3期研究也在近期到达主要完成日。值得关注的是α粒子的获益能否持续，以及骨髓和肾脏的长期安全性。
  • 本站追踪的项目集中在GEP-NET和肢端肥大症，乳腺癌只有少量项目。小细胞肺癌、脑膜瘤、嗜铬细胞瘤等SSTR2阳性肿瘤在本站基本没有项目，可以用SSTR PET摄取程度筛选患者，探索适应症扩展。
  • 本站追踪的多囊肝病项目目前只有CAM2029注射剂。口服SSTR2激动剂能否用于多囊肝病或其他cAMP驱动的囊性疾病的长期治疗，是一个尚未检验的问题。
