靶点小结

为什么重要

PARP1/2参与DNA单链断裂修复，抑制剂可将PARP“捕获”在DNA上，在BRCA1/2突变或同源重组缺陷（HRD）肿瘤中造成合成致死。olaparib等早已获批，卵巢癌、乳腺癌、前列腺癌是这一机制验证最充分的领域。

从临床结果学到了什么

  • 在本站追踪范围内，该领域已高度成熟且集中：21个项目中12个处于3期，几乎全为小分子，以olaparib、niraparib、talazoparib、rucaparib为主，适应症集中在卵巢、乳腺和前列腺癌。
  • 卵巢癌仍是随机对照证据最扎实的领域：DUO-O（NCT03737643）达到PFS主要终点；L-MOCA（NCT03534453）为描述性分析，不构成成败判断。
  • 已记录的4条失败均为商业原因：olaparib联合pembrolizumab治疗TNBC（NCT04191135）及niraparib联合enfortumab vedotin治疗尿路上皮癌（NCT03869190）提前终止，并非机制被否定，但联合疗法的价值也因此仍未得到回答。
  • 超出HRD富集瘤种的探索多为无统计检验的单臂研究，如实体瘤篮式研究NCT03742895和mCRPC联合用药研究NCT03568656，泛瘤种和新联合方案尚缺乏对照证据。

剩下的机会

  • 新一代分子是差异化方向：PARP1选择性、可入脑的AZD9574，以及Acerand、Nerviano、Merck KGaA的早期项目，可检验降低血液毒性后能否实现泛PARP难以耐受的联合方案，以及脑转移场景。
  • 适应症外延将迎来检验：fuzuloparib治疗mCRPC（NCT04691804）和talazoparib（NCT05059522）预计2026年底完成，olaparib肺癌研究（NCT04380636）2027年完成，HRR突变或HRD评分的患者筛选可能决定成败。
  • 因商业原因中断的ADC或免疫联合问题仍有空间，可在HRD筛选人群中重新设计；另有NCT04884360、NCT06433219已过主要完成日期，结果尚待披露。

分类与通路

分类：DNA 修复、合成致死与有丝分裂 › PARP 家族
同家族：PARP1 · PARP7

DNA 损伤应答 · 上游 WEE1 / PKMYT1
ATM / ATR → WEE1 / PKMYT1 → PARP1 / PARP（泛） / POLQ (Polθ) / WRN
ATM、ATR 感知损伤，经 WEE1 让细胞周期停下修复；PARP、Polθ、WRN 是不同修复途径，各自和特定缺陷合成致死。
