靶点小结

为什么重要

RBP4由肝脏分泌，负责将视黄醇运送到包括视网膜在内的外周组织。抑制RBP4可减少视网膜的视黄醇供应，从而减少A2E等双视黄醛毒性产物的积累，因此被视为Stargardt病和地图样萎缩的潜在靶点。RBP4升高还与胰岛素抵抗相关。

从临床结果学到了什么

  • 该靶点的临床记录仍很有限：本站仅追踪到Aspire的1个2期小分子项目，暂无读出、失败记录，未来6个月也没有达到主要完成日期的试验，尚无可检验机制的近期数据节点。
  • 该项目的适应症标注为支气管肺发育不良，治疗领域却归入眼科，两者并不一致。早产儿补充维生素A被认为对支气管肺发育不良有保护作用，降低视黄醇供应的思路与此相反，建议对照注册信息核实真实适应症。

剩下的机会

  • 在本站追踪的项目中，Stargardt病和地图样萎缩尚无明确布局。可以验证的假设是：降低血清RBP4能否在这些患者中稳定减少视网膜双视黄醛积累，并转化为病灶进展减缓。
  • 血清RBP4和视黄醇浓度可作为药效学标志物，用来寻找既能抑制双视黄醛生成、又能尽量减少暗适应延迟等视觉循环相关不良反应的剂量窗口。
  • 胰岛素抵抗等代谢适应症在本站追踪的项目中尚无人布局。需要回答的问题是：RBP4与胰岛素抵抗的关联究竟是因果关系还是伴随现象，可借助人类遗传学数据先行检验。
