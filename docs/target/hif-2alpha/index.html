靶点小结

为什么重要

HIF-2α（EPAS1）是缺氧应答的核心转录因子。VHL失活后HIF-2α持续稳定，驱动VEGF、cyclin D1等靶基因，是透明细胞肾癌的主要致癌通路；EPAS1功能获得突变也见于嗜铬细胞瘤/副神经节瘤。belzutifan获批用于VHL病相关肿瘤，验证了这一靶点。

从临床结果学到了什么

  • 本站收录的临床记录仍很有限。唯一的疗效检验NCT05239728中，在Keytruda+Lenvima基础上加用belzutifan未能胜出；NKT2152研究NCT05935748因组合调整终止，不能说明机制无效。下一批数据看已过主要完成日期的belzutifan I/II期研究NCT04626518和NCT04626479。

剩下的机会

  • 在本站收录的项目中，仅1个覆盖嗜铬细胞瘤/副神经节瘤和VHL病。EPAS1突变或VHL驱动的遗传定义人群仍是值得验证的方向。
  • 4个项目全部是小分子。降解剂或RNA类药物有望应对药物结合口袋的获得性耐药突变，这一方向在本站收录的项目中尚无人尝试。
  • 三联疗法失败后，哪些联用伙伴真正增效仍是悬而未决的问题。HIF-2α与CDK4/6联用（cyclin D1轴）因NCT05935748出于商业原因终止而未获检验；casdatifan的III期研究或能说明，更强的靶点抑制能否带来差异。
