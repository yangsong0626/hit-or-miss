靶点小结

为什么重要

MUC1在多种腺癌中高表达且糖基化异常，其MUC1-C亚基本身具有促癌信号功能。MUC16是血清标志物CA125的来源，在上皮性卵巢癌中高表达，并通过结合mesothelin促进腹膜转移。两者都是膜表面抗原，但胞外段会脱落，抗体和细胞治疗因此更难靶向。

从临床结果学到了什么

  • 在本站追踪的项目中，临床证据仍然很少：7个项目都处于1期或1/2期，其中5个是细胞治疗，目前没有读出。未来6个月内也没有试验到达主要完成日期，短期内不会有对该机制的检验。

剩下的机会

  • 7个项目中有5个是细胞治疗，ADC和双抗只各有1个，分别来自Whitehawk和NEOK Bio。可以用抗体类药物靶向MUC1-C或MUC16近膜段这类不脱落的表位，验证避开脱落抗原能否提高肿瘤内暴露。
  • 已追踪项目集中在卵巢癌和乳腺癌，胰腺癌只有1个。MUC1在肺、胃、结直肠腺癌中也广泛表达，但本站追踪的项目都没有专门针对这些适应症，可作为MUC1靶向药物有待验证的方向。
  • 双靶点CAR-NK项目EB-DNK101可用来观察双靶点能否应对卵巢癌的抗原异质性。按肿瘤特异性糖型表达筛选患者，并把血清CA125作为药效学指标，可能让早期信号更清晰。
