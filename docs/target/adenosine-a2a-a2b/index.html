靶点小结

为什么重要

肿瘤微环境中，CD39/CD73把ATP降解为腺苷。腺苷作用于T细胞、NK细胞和髓系细胞上的A2A/A2B受体，升高cAMP，从而抑制抗肿瘤免疫。在纹状体中，A2A调节多巴胺通路，A2A拮抗剂istradefylline已获批用于帕金森病“关期”。

从临床结果学到了什么

  • 这里收录的临床记录仍然很少：4个小分子项目还没有读出，也没有失败或提前终止记录，未来6个月也没有到达主要完成期的试验。目前进展最快的是Zhejiang Vimgreen的VG081821AC（2/3期），它的结果可能会是第一次真正的检验。

剩下的机会

  • 收录的肿瘤适应症有晚期实体瘤、肾细胞癌和去势抵抗性前列腺癌。可以检验一个假设：用CD73表达或腺苷相关基因特征筛选患者，能否让肿瘤内腺苷水平高的人群更明确地获益。
  • 这里收录的项目全是小分子。仍未回答的问题包括：A2A/A2B双重阻断是否优于单靶点阻断，以及与PD-1抑制剂、CD73/CD39抗体联用，能否克服腺苷轴的代偿。
  • 神经领域只收录了1项帕金森病试验。A2A在运动症状之外的作用，例如异动症和非运动症状，在本站收录的项目中还很少涉及，可以作为差异化的研究方向。
