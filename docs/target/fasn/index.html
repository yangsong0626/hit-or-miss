靶点小结

为什么重要

FASN是从头脂肪合成（DNL）的关键酶，以乙酰CoA和丙二酰CoA合成棕榈酸。在肝脏，DNL过度活跃会加重MASH的脂肪堆积，并与炎症和纤维化相关。在皮脂腺，FASN提供皮脂的主要脂质来源，参与痤疮的发病。因此抑制FASN在代谢病和皮肤病中都有依据。

从临床结果学到了什么

  • 临床记录仍很薄，本站尚未收录任何读出或失败。目前追踪到的唯一项目是Sagimet的denifanstat，处于3期，适应症为寻常痤疮，2026年10月才登记。未来6个月内也没有试验到达主要终点完成，短期内不会有真正的检验。

剩下的机会

  • 该靶点归入MASH通路，但本站追踪的项目中没有脂肪肝适应症。可以用MRI-PDFF或DNL标志物筛选患者，开展肝脂或纤维化研究，检验同一机制在肝脏是否有效。
  • 多种肿瘤高表达FASN，依赖它合成膜脂，但本站未追踪到任何肿瘤项目。按肿瘤FASN表达水平筛选患者，或与标准治疗联用，都还没有答案。
  • 在痤疮中，关键问题是系统性抑制脂肪合成相对现有维A酸和激素类疗法如何定位。本站未追踪到皮肤局部或外用FASN抑制剂，这类药物可检验局部抑制皮脂能否避免系统性脂质影响。
