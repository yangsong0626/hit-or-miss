靶点小结

为什么重要

WRN是RecQ家族DNA解旋酶。微卫星不稳定(MSI-H/dMMR)肿瘤中TA二核苷酸重复序列扩增，会形成需要WRN解开的二级结构。失去WRN后，这类细胞出现大量染色体断裂并死亡，而微卫星稳定细胞基本不受影响。这种合成致死关系已在多项全基因组CRISPR筛选中得到确认，覆盖结直肠癌、子宫内膜癌和胃癌中的MSI-H亚群。

从临床结果学到了什么

  • 临床证据仍然很少：本站跟踪的5个项目均处于1至2期，以小分子为主，至今没有读出，也没有试验将在未来六个月内到达主要完成日，因此目前无法从临床数据判断这一合成致死机制能否在患者中兑现。

剩下的机会

  • 多数项目以“晚期实体瘤”为入组范围，仅少数明确限定MSI-H/dMMR。TA重复扩增负荷等比MSI状态更细的生物标志物，或许能更好地预测谁会获益。
  • MSI-H肿瘤对PD-1抑制剂敏感性高，PD-1治疗后进展的患者是需要回答的人群。WRN抑制剂单药用于这一后线，或与PD-1联用前移，都有待验证。
  • 本站跟踪的项目中，适应症仅一项点名结直肠癌，子宫内膜癌、胃癌的MSI-H亚群尚无专门项目。若出现靶点上的耐药突变，结合方式不同的分子（如共价与非共价）可能形成差异化。
