靶点小结

为什么重要

CD40L（CD154）表达于活化CD4+ T细胞，与B细胞和树突状细胞上的CD40结合，驱动生发中心反应、类别转换和自身抗体产生。CD40L缺陷导致X连锁高IgM综合征，从遗传上证实它是T细胞辅助B细胞的关键节点，因此适用于自身免疫病和移植排斥。

从临床结果学到了什么

  • 血小板也表达CD40L，血栓风险一直是该靶点类别的主要顾虑，现有分子多去除或沉默Fc。dazodalibep在OASIZ 301中未见血栓栓塞或机会性感染失衡，为这一设计提供了首个III期安全性证据。
  • 本站追踪范围内首个III期成功出现在干燥综合征：Amgen新闻稿报告dazodalibep达到主要终点，第4周即起效。B细胞驱动的疾病与该机制契合，但公司未公布效应量，难以与其他药物横向比较。
  • 移植领域，Eledon的tegoprubart在II期BESTOW中对比他克莫司，肾功能和生活质量呈积极信号，提示CD40L阻断有望替代钙调磷酸酶抑制剂，但目前仅有II期新闻稿数据。
  • 本站尚未追踪到该靶点的失败或提前终止，阳性记录几乎全部来自干燥综合征和移植；SLE、MS尚无结果，现有结论不宜外推到其他适应症。

剩下的机会

  • SLE机制最直接但尚无结果：SAR441344的II期NCT05039840已过主要完成日期，UCB的dapirolizumab pegol处于III期。按自身抗体谱或干扰素特征分层，可能是区分疗效的关键。
  • frexalimab的MS III期NCT06141473将检验CD40L阻断在中枢神经疾病中能否与B细胞清除疗法拉开差距；本站追踪的MS项目仅2个，结果将决定神经免疫方向是否成立。
  • 本站追踪的项目中，1型糖尿病、FSGS和微小病变肾病各仅1个，形式也只有单抗和1个融合蛋白；同时阻断CD40L与BAFF/APRIL等B细胞通路的双特异分子仍属空白。
