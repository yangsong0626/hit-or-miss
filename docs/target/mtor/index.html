靶点小结

为什么重要

mTOR是PI3K–AKT通路下游的丝氨酸/苏氨酸激酶，以mTORC1和mTORC2两种复合物整合生长因子与营养信号，调控蛋白合成和细胞生长。TSC1/TSC2失活会持续激活mTORC1，导致结节性硬化症。everolimus等雷帕霉素类似物早已获批用于HR+乳腺癌、肾癌和TSC，该机制已有临床验证。

从临床结果学到了什么

  • 本站追踪的临床记录仍然有限：唯一读出是Aadi的II期泛瘤种研究NCT05103358，主要终点为ORR，结果属描述性，没有正式统计检验。下一个实质性检验是everolimus在TSC中的III期研究NCT02962414，预计2027年2月达到主要完成。

剩下的机会

  • 本站追踪的新一代项目（AV078、sapanisertib、QLC1401、AL58805）仍处于I/II至II期。可以检验的假设是：mTORC1选择性抑制能否减少雷帕霉素类似物在mTORC2相关通路上的代谢毒性，同时维持疗效。
  • 神经/精神领域仅有2项试验。TSC相关癫痫等mTORC1过度激活驱动的神经疾病，可能适合研究脑渗透性更好的新分子。
  • 乳腺癌是项目最集中的适应症。用TSC1/TSC2或PI3K通路改变筛选患者，并探索纳米制剂（SAPU NANO）等新的给药方式，可能是与everolimus形成差异化的方向。
