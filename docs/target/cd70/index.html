靶点小结

为什么重要

CD70为CD27的TNF家族配体，正常仅见于活化淋巴细胞，但在透明细胞肾癌（VHL缺失、HIF驱动）和AML原始细胞及白血病干细胞上高表达，是肿瘤选择性靶点；它也标记活化的自身反应性T、B细胞，因而被拓展至狼疮等自身免疫病。

从临床结果学到了什么

  • 临床证据仍很有限：本站暂无读出或失败记录，未来六个月也无试验到达主要完成；10个项目均在1–2期，8个为细胞治疗，最快的是OncoVerity单抗cusatuzumab（2期）。

剩下的机会

  • 本站跟踪的10个项目中8个为细胞治疗，尚无ADC或T细胞衔接器；CD70在透明细胞肾癌中表达广泛，这类形式可绕开CAR-T自相残杀（活化T细胞也表达CD70）来验证靶点。
  • 本站跟踪3项自身免疫试验（SLE、肌炎、幼年皮肌炎、多关节型JIA）。清除CD70+活化淋巴细胞能否补充B细胞靶向疗法仍无答案，狼疮中升高的CD70+ T细胞或可用于患者筛选。
  • AML在本站仅有1个项目。去甲基化药物可上调原始细胞CD70表达，为联合用药和靶向白血病干细胞提供依据；治疗前后检测CD70密度或有助于患者筛选和剂量设定。
