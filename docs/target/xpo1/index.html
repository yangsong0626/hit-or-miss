靶点小结

为什么重要

XPO1（CRM1）把p53、p21、IκB等抑癌蛋白和部分致癌mRNA运出细胞核，在多种血液肿瘤和实体瘤中高表达，CLL和部分淋巴瘤中可见XPO1 E571K突变。抑制XPO1可让抑癌蛋白滞留在核内。selinexor联合地塞米松已获批用于复发难治多发性骨髓瘤。

从临床结果学到了什么

  • 目前最强的信号来自血液肿瘤中的联合用药：SENTRY中selinexor联合芦可替尼一线治疗骨髓纤维化，达到24周脾体积缩小的共同主要终点。在本站追踪的项目中，骨髓纤维化也是项目最集中的适应症。
  • XPORT-EC-042按TP53野生型筛选子宫内膜癌维持治疗人群，PFS数值上有改善，但未达统计学显著，说明只靠TP53状态富集人群不足以保证获益。公司随后收缩了这一适应症，部分原因是战略调整。
  • 本站追踪的XPO1项目全部是Karyopharm的selinexor，靶点前景高度依赖这一个分子。NCT04256707（SPRINT）在NSCLC中以药代动力学为主要终点，没有统计检验，因此子宫内膜癌以外实体瘤的疗效仍缺乏检验。

剩下的机会

  • NCT04562870（骨髓纤维化2期）已在2026年9月到达主要完成日期，可以关注获益是否不止于脾脏缩小。项目列出了中度血小板减少人群，可借此检验selinexor在芦可替尼剂量受限患者中的定位。
  • NCT04442022（复发难治DLBCL，2/3期）预计2026年12月到达主要完成日期，将检验selinexor在淋巴瘤中的疗效能否在更大样本中成立。
  • 本站未追踪到其他XPO1抑制剂或其他药物模式。药代或耐受性特征不同的新一代抑制剂，或者用XPO1 E571K突变等TP53以外的生物标志物筛选患者，都是值得探索的方向。
