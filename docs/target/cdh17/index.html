靶点小结

为什么重要

CDH17（肝肠钙黏蛋白）是肠上皮黏附分子，在多数结直肠癌及部分胃癌、胃肠神经内分泌肿瘤中高表达，适合作为ADC、CAR-T等疗法的表面靶点。核心顾虑是正常肠道的脱肿瘤毒性，不过它在正常组织中多位于细胞间连接处，药物可能较难接触到。

从临床结果学到了什么

  • 临床证据仍很薄：4个项目均处早期，尚无注册试验读出。唯一信号是ArriVent在ESMO 2026公布的ADC ARR-217初步I期数据，未来六个月也没有追踪中的试验到达主要完成。

剩下的机会

  • 本站追踪的项目中，结直肠癌有3个，胃肠神经内分泌肿瘤和胃癌各只有1个。CDH17阳性NET以及胰腺癌等其他表达CDH17的消化道肿瘤，可作为竞争较少的探索方向。
  • 追踪项目以抗体类（含ADC ARR-217）和CAR-T（CHM-2101）为主，未见T细胞衔接器或联合方案。双抗、ADC联合标准化疗或免疫治疗都是待验证的假设，前提是肠道耐受性可接受。
  • 核心未决问题是正常肠上皮能否不受损伤。如果ARR-217和CHM-2101的完整剂量递增数据能把消化道毒性和疗效与CDH17表达水平对照，就能判断按表达筛选患者是否可以拓宽治疗窗。
