靶点小结

为什么重要

BCL6 是生发中心 B 细胞形成所必需的转录抑制因子，通过 BTB 结构域招募共抑制复合物，压制 DNA 损伤应答和终末分化程序。DLBCL 中常见 BCL6 易位或持续高表达，小鼠模型中组成性表达 BCL6 可诱发类 DLBCL 淋巴瘤，因此它是淋巴瘤的驱动靶点，但作为转录因子长期难以成药。

从临床结果学到了什么

  • 临床证据仍很薄弱：本站目前只追踪到 BMS-986458 一个项目（Bristol Myers Squibb，1/2 期，复发/难治性 NHL），尚无读出、失败或提前终止记录，未来六个月也没有到达主要完成日期的试验，暂无法判断该机制在临床上是否成立。

剩下的机会

  • 适应证留白：本站追踪到的项目都集中在复发/难治性 NHL。BCL6 依赖性在滤泡性淋巴瘤、Burkitt 淋巴瘤中同样有生物学依据，Tfh 细胞依赖 BCL6 也提示自身免疫方向，可作为可验证的假设。
  • 患者选择：可以按细胞起源（GCB 与 ABC）、BCL6 易位或表达水平富集患者，检验 BCL6 依赖性能否预测疗效。这一问题在目前追踪的项目中尚无数据回答。
  • BMS-986458 的首批数据将确定安全性和活性基线，后续进入者可以围绕联合用药（如与标准免疫化疗或其他淋巴瘤靶向药联用）和起效深度做差异化设计。
