靶点小结

为什么重要

GSPT1（eRF3a）是翻译终止因子，经cereblon分子胶可被降解，引发整合应激反应和细胞凋亡。MYC驱动的肿瘤和AML高度依赖蛋白翻译，对GSPT1缺失尤为敏感。但GSPT1在正常组织中同样必需，治疗窗口是核心问题。

从临床结果学到了什么

  • 临床记录仍很有限：本站追踪的仅有Monte Rosa（1/2期，小分子）和Orum（1期）两个项目，尚无读出、失败记录或未来6个月内到期的试验，暂无法判断该机制在哪些适应症有效。

剩下的机会

  • 已记录的适应症为NSCLC、SCLC和CD123+ AML。抗原导向的递送（如针对CD123）能否降低GSPT1降解的全身毒性、拓宽治疗窗口，是值得验证的假设。
  • 按MYC家族扩增或高表达等翻译依赖性生物标志物筛选患者，可能是提高响应率的路径，在本站追踪的项目中尚无明确的标志物驱动设计。
  • 除肺癌和AML外，其他MYC驱动的实体瘤以及骨髓增生异常综合征等血液病在本站追踪的项目中尚无覆盖，可作为探索方向。
