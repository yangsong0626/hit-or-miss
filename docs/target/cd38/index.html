分类与通路

分类：肿瘤表面抗原（ADC、双抗、CAR-T 靶点） › 血液肿瘤抗原
同家族：CD19 · CD20 · CD22 · CD3 · BCMA · GPRC5D · FcRH5 · CD123 · CD33 · CLL1 / CD371 · CD7 · CD30 · CD70

浆细胞与致病抗体 · 上游 BAFF / APRIL · 下游 FcRn
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL 维持浆细胞（BCMA、CD38），浆细胞产生 IgG，FcRn 让 IgG 循环延长半衰期；阻断 FcRn 可快速清除致病抗体。

常在同一试验里出现的靶点

BCMA · PD-1 / PD-L1 · IKZF1/3 (Ikaros/Aiolos) · CD3 · LAG-3 · CD19 · EGFR · VEGF / VEGFR · HER2 · CD20
