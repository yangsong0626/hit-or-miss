靶点小结

为什么重要

GR是配体激活的核受体，介导皮质醇的大部分作用。激动GR可抑制炎症，但长期使用会带来代谢、骨骼等毒性；在肿瘤中，GR激活可上调抗凋亡基因，削弱化疗效果。因此这个靶点同时有两条开发方向：解离型激动剂和选择性拮抗剂。

从临床结果学到了什么

  • 临床数据仍然有限，且本站跟踪的两个项目方向相反：拮抗剂Relacorilant的卵巢肿瘤III期NCT05257408达到主要终点（BICR评估的PFS及OS）；解离型激动剂Vamorolone的Becker肌营养不良II期NCT05166109仅为安全性描述，无统计检验。未来六个月本站未跟踪到新的读出。

剩下的机会

  • NCT05257408提示GR拮抗可在卵巢肿瘤中增强疗效。其他GR高表达、化疗耐药的实体瘤在本站跟踪项目中尚无覆盖，可以考虑以肿瘤GR表达作为入组生物标志物来检验这一机制。
  • Vamorolone在Becker中目前只有安全性数据。下一步值得验证解离型激动剂能否在保留疗效的同时减轻激素毒性，并扩展到其他需要长期用激素的慢性炎症或肌病。
  • 本站跟踪的项目都是小分子。组织靶向递送糖皮质激素（例如抗体偶联或局部给药）有可能把抗炎作用与全身毒性分开，目前仍是空白方向。
