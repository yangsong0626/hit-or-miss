靶点小结

为什么重要

心肌肌球蛋白是肌节的分子马达，水解ATP驱动收缩。MYH7、MYBPC3等肌节突变造成过度收缩，是肥厚型心肌病（HCM）的主要遗传基础。抑制剂减少肌动蛋白-肌球蛋白横桥形成，可缓解流出道梗阻，mavacamten已获批用于梗阻型HCM。激动剂则用于增强射血分数降低心衰的收缩力。

从临床结果学到了什么

  • 梗阻型HCM是这一机制证据最清楚的适应症：aficamten的MAPLE-HCM（NCT05767346）达到pVO2主要终点。超出梗阻人群后结果分化：ACACIA-HCM在非梗阻型中改善了症状和运动能力，mavacamten的ODYSSEY-HCM（NCT05582395）则在KCCQ和pVO2上均未达到。
  • 过度抑制收缩是这一类药物共同的安全问题。ACACIA-HCM治疗组LVEF降至50%以下的比例明显高于安慰剂，需要超声监测。剂量滴定和监测负担可能成为同类药物之间的主要差异。
  • 把肌球蛋白抑制延伸到骨骼肌尚未成功：sevasemten在Becker肌营养不良的关键性试验（NCT06066580）因疗效不足未达到终点，减轻肌肉损伤的思路还没有转化为功能获益。
  • BMS-986435（NCT05556343）因商业原因终止，不能作为否定机制的证据。在本站追踪范围内，9个项目集中于3家公司，竞争格局高度集中。

剩下的机会

  • 非梗阻型HCM中为何ACACIA-HCM和ODYSSEY-HCM结果不同，可从基因型、基线LVEF、NT-proBNP等生物标志物和滴定策略寻找答案。aficamten非梗阻型试验NCT06081894的数据将检验阳性结果能否重复。
  • 激动剂方向尚无已追踪的读出：omecamtiv mecarbil在心衰中处于3期，射血分数极低等特定亚组能否获益仍是开放问题。
  • 儿童HCM在本站追踪中仅有1个项目，基因型阳性的早期患者能否通过早期抑制延缓疾病进展尚未验证。Becker方向，2期NCT05291091将显示关键性试验失败后是否仍有可用的亚组或终点信号。
