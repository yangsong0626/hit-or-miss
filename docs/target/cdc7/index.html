靶点小结

为什么重要

CDC7与DBF4组成DDK激酶，磷酸化MCM2-7解旋酶以启动复制起点放电，是DNA复制起始的关键开关。肿瘤细胞复制压力高、高度依赖CDC7，抑制后易发生复制灾难和凋亡，正常细胞多为可逆停滞，因此被视为具有治疗窗口的周期靶点。

从临床结果学到了什么

  • 临床记录仍很薄：本站目前仅追踪到Lin公司一个未命名的1/2期项目，适应症为复发或难治性急性白血病，尚无读出、失败记录，未来6个月内也没有到达主要完成日的试验，该试验结果将是首个真正检验。

剩下的机会

  • 本站追踪的项目只覆盖急性白血病，复制压力高的实体瘤（如TP53突变或MYC驱动肿瘤）尚无项目，可作为检验CDC7依赖性的候选人群。
  • 可探索以复制压力相关标志物（如MCM2磷酸化、TP53状态）进行患者筛选，以区分可能获益的亚群。
  • 与DNA损伤类化疗、ATR抑制剂或白血病标准方案联用是否存在协同，以及降解剂等其他分子形式，在本站追踪范围内均未见验证。
