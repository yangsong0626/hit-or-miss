靶点小结

为什么重要

IL-13是2型炎症的核心效应细胞因子，经IL-4Rα/IL-13Rα1激活JAK–STAT6，驱动皮肤屏障破坏、瘙痒、气道黏液分泌和高反应性。IL13基因变异与哮喘和特应性皮炎易感性相关，dupilumab与tralokinumab的获批也从临床上验证了这条通路。

从临床结果学到了什么

  • 哮喘中lebrikizumab结果不一致：NCT01867125达到急性加重终点，NCT02104674未达到FEV1终点；NCT01875003和NCT01987492随后因申办方停止哮喘开发而终止，属商业原因，不能作为否定机制的证据
  • 以FEV1为主要终点的气道试验在哮喘（NCT02104674）和COPD（NCT02546700）中均未达到，提示单独阻断IL-13改善肺功能的作用有限，降低急性加重的信号相对更明确
  • 皮肤适应症表现更一致：tralokinumab在手部特应性湿疹中达到主要终点（NCT05958407），本站追踪的4个项目均覆盖特应性皮炎，lebrikizumab的NCT06280716、NCT05990725为描述性设计，不构成正式检验
  • 气道方向转向多靶点：Sanofi的双抗lunsekimig已有9项试验进入3期、覆盖哮喘和COPD，但本站尚未追踪到其读出，双靶点能否弥补单抗在肺部的不足仍待验证

剩下的机会

  • 气道疾病中按2型炎症生物标志物（如血嗜酸性粒细胞、FeNO）富集患者，并以急性加重而非FEV1为主要终点，可检验IL-13在高2型亚群中的真实效用
  • 特应性皮炎的细分表型（手部湿疹、钱币状湿疹）只有少数项目涉及，可作为差异化方向；NCT06526182预计2027年4月完成主要终点，是下一个检验lebrikizumab的节点
  • 本站追踪的项目全部为注射用抗体，尚无口服小分子或长效制剂，延长给药间隔或开发口服IL-13通路抑制剂仍是空白
