靶点小结

为什么重要

ALK7（ACVR1C）是主要在脂肪组织表达的TGF-β超家族I型受体，被GDF3及activin B/E激活后抑制脂解、促进脂肪储存。人群遗传学显示ACVR1C功能缺失变异与较低的腰臀比及2型糖尿病风险下降相关，提示抑制ALK7可能改善脂肪分布与代谢。

从临床结果学到了什么

  • 临床记录仍很薄：本站仅追踪到Suzhou Siran一个1期项目（超重/肥胖，2026年3月登记），尚无读出，未来6个月也没有到达主要完成的试验，机制在人体中的首次检验仍待公布。

剩下的机会

  • 遗传学指向的是脂肪分布而非单纯体重：早期试验可检验内脏脂肪、腰臀比等影像或人体测量终点，并按中心性肥胖富集患者，而非照搬常规减重终点。
  • 与肠促胰素类药物联用：可假设ALK7抑制使减重更偏向脂肪、保留瘦体重，从而补充GLP-1类疗法；本站追踪的项目中尚无此类联合研究。
  • 适应证与模式空白：追踪项目仅覆盖超重/肥胖且模式未披露，2型糖尿病、MASLD等代谢适应证，以及脂肪组织靶向的siRNA或阻断抗体，均是可检验的方向。
