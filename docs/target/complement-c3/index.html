靶点小结

为什么重要

C3是经典、凝集素和旁路三条补体途径的汇合点，其裂解产物C3b驱动调理作用和旁路放大环，并启动下游C5和膜攻击复合物。CFH、C3等基因变异与AMD和C3G相关。在PNH中，阻断C3可同时控制血管内和血管外溶血，这是C5抑制剂做不到的。pegcetacoplan已获批用于PNH和地图样萎缩。

从临床结果学到了什么

  • 临床记录仍然很薄。已披露的读出只有pegcetacoplan的两项长期安全性研究（NCT03531255、NCT04770545），均无正式假设检验；NCT07020832（移植肾功能延迟恢复）虽被标为疗效失败，但终止说明写明是管线优先级调整、与安全性无关，不能据此否定机制。第一次真正的疗效检验将是IBI302的nAMD III期研究NCT05972473。

剩下的机会

  • 本站追踪的项目中已有两款C3 siRNA（Qilu II期、Rigerna I期），可验证肝脏沉默C3能否实现低频给药，并充分抑制肾脏和眼部的局部补体活性。深度、持续的全身C3耗竭会带来荚膜菌感染风险，需前瞻性监测。
  • IBI302是融合蛋白，设计上在抗VEGF基础上叠加补体阻断。NCT05972473将检验这一组合能否在nAMD中超越单纯抗VEGF，例如是否减少纤维化或萎缩进展，这是该适应症目前尚未回答的问题。
  • 肾脏适应症（C3G、IC-MPGN、移植后复发性肾小球病、ESRD）在本站追踪的项目中各只有一个。以低血清C3、C3肾炎因子或补体基因变异筛选患者，可能是提高信号的方向；NCT07020832终止后，C3在缺血再灌注损伤中的作用仍未得到验证。
