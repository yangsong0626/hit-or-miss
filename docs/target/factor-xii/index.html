靶点小结

为什么重要

FXII在接触表面活化为FXIIa，裂解前激肽释放酶生成血浆激肽释放酶，进而释放缓激肽。C1-INH缺乏时这一通路失控，引发遗传性血管性水肿（HAE）发作；F12功能获得突变本身也可致病。FXII缺乏者无出血倾向，因此FXII是出血风险较低的上游靶点。

从临床结果学到了什么

  • 临床记录仍很薄。本站追踪的FXII项目只有CSL312一个，两项Phase 3（NCT04739059，n=171；NCT05819775，n=22）均以TEAE为主要终点，属描述性读出，没有疗效假设检验，也没有失败或提前终止的案例。未来6个月本站未追踪到即将读出的试验，近期没有新的验证节点。

剩下的机会

  • FXII缺乏不导致出血，提示可在抗凝方向试验：体外循环、医疗器械相关血栓和血栓性炎症。目前本站追踪的项目全部集中在HAE。
  • 本站追踪的唯一形式是单抗。靶向肝脏F12表达的siRNA/ASO，或口服FXIIa小分子抑制剂，可能在给药频率和便利性上形成差异，尚未见于本站记录。
  • CSL312现有数据以安全性为主要终点。下一步可回答的问题包括：C1-INH正常型HAE（含F12突变）患者是否获益，以及与激肽释放酶抑制剂相比的长期疗效与转换数据。
