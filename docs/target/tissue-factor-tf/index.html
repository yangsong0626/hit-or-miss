靶点小结

为什么重要

组织因子(TF，F3)结合FVIIa，启动外源性凝血途径，并经PAR2信号促进肿瘤血管生成、侵袭和转移，同时与肿瘤相关血栓有关。TF在宫颈癌、胰腺癌、头颈鳞癌、NSCLC等实体瘤中高表达，结合抗体后内吞较快，适合做ADC靶点。tisotumab vedotin已获批用于复发性宫颈癌。

从临床结果学到了什么

  • 本站追踪的临床记录仍然很少。唯一的读出NCT03786081(tisotumab vedotin联合bevacizumab等，宫颈癌)因申办方战略决定提前终止，不能说明机制无效。upcoming_6m中没有即将读出的试验，近期没有可检验的节点。

剩下的机会

  • 本站追踪的新一代TF ADC(Adcendo、Evopoint、Nanolattix、Sutro)均处于1期，适应症覆盖NSCLC、胰腺癌、结直肠癌和头颈鳞癌。可以检验更换载荷或偶联技术能否把疗效从宫颈癌推广到这些瘤种。
  • 目前追踪的项目多以泛实体瘤入组。TF表达水平(IHC)能否预测疗效、能否用来筛选患者，还有待验证，这可能是新进入者区分于领先项目的切入点。
  • 已追踪项目几乎都是ADC，没有看到TF双抗、CAR-T或放射性偶联药物。NCT03786081终止后，联合抗血管生成治疗的价值也没有得到回答。

凝血 · 下游 凝血因子 XI / TFPI
因子 XII / 组织因子 (TF) → 凝血因子 XI / TFPI → FVIII 模拟 (FIXa × FX) → 抗凝血酶
接触途径从 FXII 到 FXI，外源途径由组织因子启动、TFPI 抑制；两者汇合后由 FVIII/FIX 放大生成凝血酶，抗凝血酶负责关停。血友病药物从 FVIII 模拟、TFPI、抗凝血酶三个方向重新平衡。
