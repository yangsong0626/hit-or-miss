靶点小结

为什么重要

RXFP1是肽类激素relaxin-2的G蛋白偶联受体，经cAMP和一氧化氮通路舒张血管，增加肾血流和肾小球滤过率，并抑制纤维化与炎症，妊娠期肾脏的适应性变化即由其介导。这一特性契合肾灌注骤降的场景，如心脏手术相关急性肾损伤。

从临床结果学到了什么

  • 本站仅追踪到River 2 Renal一个2期项目（药物与分子类型未披露），针对心脏及瓣膜手术相关急性肾损伤，2026年6月首登。尚无读出，未来六个月亦无主要完成节点。

剩下的机会

  • 本站未见长效relaxin类似物、RXFP1小分子或激动型抗体。围术期AKI可用短期输注，肾脏、心脏纤维化等慢性适应症则需长效选择性激动剂，信号偏向性是设计要点。
  • 仅按临床风险入组易稀释疗效。可检验的假设：以尿TIMP-2·IGFBP7等肾应激标志物富集人群，并在体外循环前给药，在损伤形成前发挥舒血管与抗纤维化作用。
  • 慢性肾病、伴肾淤血的HFpEF、肝肺纤维化、子痫前期等场景本站均无追踪项目。River 2 Renal试验日后的肾血流或GFR数据可为拓展方向提供早期参考。
