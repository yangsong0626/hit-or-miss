靶点小结

为什么重要

M1/M4毒蕈碱受体调控皮层与纹状体环路，M4激活可间接抑制纹状体多巴胺释放，M1参与认知。激动该通路可不经D2阻断实现抗精神病作用，避开运动和代谢副作用。Xanomeline曾显示疗效，但受外周胆碱能副作用所限，由此催生了联用外周拮抗剂及M4选择性的策略。

从临床结果学到了什么

  • 临床记录尚薄：此处两项读出均为描述性安全性研究，未做正式假设检验（KarXT NCT06572449；emraclidine NCT05443724因商业原因终止，与安全无关）。首批疗效检验是KarXT阿尔茨海默病研究NCT06585787和NCT06126224，均在2026年12月前到达主要完成日。

剩下的机会

  • 阿尔茨海默病是下一个主要战场：此处追踪4个相关项目，KarXT的NCT06585787和NCT06126224将检验老年神经退行性人群中的疗效与胆碱能耐受性。激越、孤独症易激惹各仅1个项目。
  • 选择性路线仍待验证：NBI-1117568等M4选择性药物已进入3期，可检验不激动M1、不联用外周拮抗剂能否兼顾疗效与耐受。emraclidine因商业原因终止（NCT05443724），PAM路线尚未得到充分检验。
  • 认知领域仍是空白：此处追踪的项目均未针对精神分裂症相关认知障碍，而M1与认知功能相关。现有项目均为小分子，M1偏向型药物，以及用胆碱能或认知缺陷生物标志物筛选患者，都还是待验证的假设。
