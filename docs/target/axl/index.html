靶点小结

为什么重要

AXL是TAM家族受体酪氨酸激酶，由配体GAS6激活，可促进上皮间质转化、肿瘤侵袭和免疫抑制性微环境。AXL高表达与多种实体瘤预后不良相关，也是EGFR-TKI、化疗及免疫治疗耐药的旁路机制之一，因此被视为逆转耐药的候选靶点。

从临床结果学到了什么

  • 本站追踪的AXL项目仅有Xuanzhu Biopharmaceutical一款处于1期的小分子，适应症为晚期实体瘤和NSCLC。目前尚无读出，未来六个月也没有试验到达主要完成日期，现有临床数据还不足以总结经验。

剩下的机会

  • 可在EGFR-TKI治疗后进展、AXL高表达或带EMT特征的NSCLC中检验AXL抑制，看生物标志物富集能否让耐药机制假说转化为可测量的获益。
  • 本站追踪的项目中还没有抗体、ADC或降解剂。AXL位于细胞表面且在耐药肿瘤中上调，ADC有可能不依赖激酶活性，直接靶向AXL高表达细胞。
  • 鉴于AXL参与免疫抑制，可探索与PD-1/PD-L1抑制剂联用，以及NSCLC以外的适应症，如血液肿瘤或纤维化。这些方向在本站追踪范围内尚无项目。
