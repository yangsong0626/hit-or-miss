靶点小结

为什么重要

CD123（IL-3Rα）在AML原始细胞及白血病干细胞上高表达，BPDCN几乎全部阳性，正常造血干细胞表达较低，是清除白血病干细胞的候选靶点。tagraxofusp已获批用于BPDCN，验证了该靶点；主要难点是对正常髓系细胞和内皮的靶上毒性。

从临床结果学到了什么

  • 临床记录仍很薄：本站唯一读出是IMGN632在BPDCN的NCT03386513，为描述性分析，无正式假设检验；未记录失败，未来6个月也无试验到达主要完成，近期缺少新的检验点。

剩下的机会

  • 本站追踪的10个项目均涉及AML，但多处于1期；3个细胞治疗与双抗MGD024能否在不造成长期骨髓抑制的前提下清除病灶，或作为移植桥接，仍是待解问题。
  • MDS（2个）和MPN（1个）项目稀少；已有报道CD123在高危MDS干细胞上表达，按CD123表达密度或干细胞负荷筛选患者，是可检验的方向。
  • 进度最快的pivekimab sunirine（2/3期，与本站分列的IMGN632为同一分子）将检验ADC路线能否从BPDCN延伸至AML；其与去甲基化药物或venetoclax联用的定位尚待回答。
