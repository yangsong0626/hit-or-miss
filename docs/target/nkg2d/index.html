靶点小结

为什么重要

NKG2D是NK细胞、CD8+ T细胞和γδ T细胞上的激活型受体，识别MICA/MICB及ULBP家族配体。这些配体在细胞应激和恶性转化时上调，NKG2D因此成为广谱识别肿瘤的通路。肿瘤常通过脱落可溶性MICA逃逸，以NKG2D胞外域构建的CAR可同时覆盖多种配体。

从临床结果学到了什么

  • 临床记录仍然很少：本站目前追踪到的2个项目（Leucid Bio的LEU011和Nkarta的NKX101）均无读出，未来6个月内也没有到达主要完成日期的试验，暂时无法判断该机制在哪类患者中有效。
  • 在本站追踪范围内，NKG2D项目全部集中在肿瘤领域的细胞疗法：NKX101针对复发/难治AML，LEU011针对实体瘤，且最高阶段仅为1/2期。

剩下的机会

  • 配体表达异质性和可溶性MICA脱落可能削弱疗效，可以假设：按MICA/MICB、ULBP表达或血清可溶性配体水平筛选患者，或联用抑制配体脱落的抗体，可提高应答率。
  • 本站追踪的项目尚未涉及双特异性衔接分子等非细胞疗法模态，现货型、可调剂量的NKG2D配体靶向分子值得验证。
  • NKG2D–配体相互作用与乳糜泻、1型糖尿病等自身免疫组织损伤相关，在本站追踪范围内尚无阻断NKG2D的自身免疫项目。
