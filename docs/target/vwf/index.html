靶点小结

为什么重要

VWF为多聚体血浆糖蛋白，经GPIb介导血小板黏附于内皮下胶原，并携带FVIII以减缓其清除。VWF缺陷导致最常见的遗传性出血病血管性血友病（VWD），1型为部分数量缺乏；反之VWF过度活化可驱动TTP微血管血栓。

从临床结果学到了什么

  • 临床记录仍很薄：此处仅追踪到Hemab ApS一个1/2期项目（VWD，含1型），尚无读出，未来六个月内也没有试验到达主要完成日期，近期缺少检验该机制的数据节点。

剩下的机会

  • 此处追踪的项目仅覆盖1型VWD。2型与3型患者对去氨加压素反应有限，仍属空白；待解问题是，作用于内源性VWF的疗法在VWF几近缺失时能否起效。
  • 1型VWD异质性高，部分患者以VWF清除加快为主（VWFpp/VWF:Ag比值升高），部分以合成减少为主。按此类标志物分层，或可明确不同机制疗法的适用人群；月经过多女性是可行的终点人群。
  • 此处未追踪到VWF抑制类项目，而抗VWF阻断已在获得性TTP中获临床验证（caplacizumab）。高剪切力下VWF–GPIb结合参与的动脉血栓（如缺血性卒中）值得作为假设检验，但需同时评估出血风险。
