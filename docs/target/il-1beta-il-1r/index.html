靶点小结

为什么重要

IL-1β经NLRP3炎症小体与caspase-1切割活化，通过IL-1R1及辅助受体IL-1RAP信号放大中性粒细胞主导的炎症。CAPS等自身炎症病存在炎症小体功能获得性突变，IL-1受体拮抗剂anakinra已长期用于临床，通路的人体验证较充分。

从临床结果学到了什么

  • 本站跟踪的IL-1β/IL-1R项目尚无已报告的读出或失败记录，临床记录仍很薄。首个实质检验是lutikizumab在化脓性汗腺炎的3期试验NCT06468228，主要完成时间预计为2026年12月。

剩下的机会

  • 在本站跟踪范围内，化脓性汗腺炎、克罗恩病、溃疡性结肠炎和特应性皮炎各只有1个项目。NCT06468228的结果可以检验IL-1阻断在中性粒细胞浸润的屏障性炎症中能否带来获益，并决定是否值得在其他适应症单独布局。
  • 现有项目以注射用生物制品为主，小分子仅HPB-092处于1期，基因治疗FX201和细胞治疗也都在早期。慢性病需要长期给药，口服或可在局部长效作用的递送方式可能是与领先抗体拉开差异的方向。
  • 肿瘤领域有3项试验，但本站跟踪的项目适应症中没有肿瘤。IL-1β参与促瘤炎症，可以研究用炎症标志物筛选患者、或与免疫治疗联用这类假设。FMF已有2个项目，秋水仙碱应答不足人群也可作为分层方向。
