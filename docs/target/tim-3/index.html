靶点小结

为什么重要

TIM-3（HAVCR2）在耗竭的CD8+ T细胞上常与PD-1共表达，也表达于Treg、髓系细胞及AML/MDS白血病干细胞，配体包括galectin-9、磷脂酰丝氨酸和CEACAM1。临床前研究中PD-1/TIM-3双重阻断可恢复T细胞功能，因此被视为克服PD-1耐药的候选靶点。

从临床结果学到了什么

  • 临床记录仍薄：唯一做了统计检验的读出是2/3期COSTAR Lung（NCT04655976），cobolimab联合dostarlimab治疗NSCLC，OS未达到；Incyte的NCT04370704只有安全性数据。下一个检验是cobolimab黑色素瘤试验NCT06521567。

剩下的机会

  • 髓系肿瘤的立论不同：TIM-3表达于白血病干细胞，不只依赖T细胞耗竭。本站追踪的项目中仅Novartis的sabatolimab覆盖MDS/CMML，这条路径能否不受NSCLC失败影响仍待回答。
  • 本站追踪的读出均未检验生物标志物富集。按浸润T细胞TIM-3/PD-1共表达或配体表达筛选患者是一个待验证的假设；即将公布的黑色素瘤读出或可提示瘤种之间是否存在差异。
  • 本站追踪的5个项目均为单抗。若新形式能把TIM-3阻断限定在PD-1+耗竭T细胞，或作用于同样表达TIM-3的髓系及树突状细胞，可用来区分失败出在机制本身还是药物形式。
