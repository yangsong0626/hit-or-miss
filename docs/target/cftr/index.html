靶点小结

为什么重要

CFTR是上皮细胞顶膜上的氯离子/碳酸氢根通道，两个等位基因均发生功能缺失突变会导致囊性纤维化。ivacaftor和ELX/TEZ/IVA已获批上市，证明恢复通道功能可以改变病程。但无义突变等对调节剂无应答的患者，仍需要基因层面的疗法。

从临床结果学到了什么

  • 目前临床记录较少。唯一的读出NCT05882357是ELX/TEZ/IVA的III期PK与安全性描述性研究，没有正式假设检验，本站也没有失败记录。首批真正的检验将是NCT06237335（ivacaftor，II期，2026-11）和NCT05331183（ELX/TEZ/IVA，III期，2027-04）。

剩下的机会

  • 调节剂无效患者需要不依赖突变类型的基因疗法。本站追踪的项目中，只有ARCT-032（吸入mRNA，II期）和SpliSense项目（模态未标明）走这条路线，尚无DNA基因治疗或基因编辑项目。气道递送的效果能否持久仍待验证。
  • CF以外的适应症：本站有一个项目针对射血分数降低的心衰，可以检验CFTR调节在上皮以外是否有作用。吸烟相关气道疾病中的获得性CFTR功能障碍在生物学上说得通，但本站尚未追踪相关项目。
  • 与Vertex形成差异：ELX/TEZ/IVA和D-IVA都已进入III期。Qanatpharma等的新小分子（II期）可能需要聚焦罕见突变或残余功能突变，并借助类器官或汗液氯离子检测来筛选患者。
