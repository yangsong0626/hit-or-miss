分类与通路

分类：细胞因子与免疫受体 › 淋巴细胞归巢与抗体循环
同家族：α4β7 整合素 · VAP-1 · 半乳糖凝集素-3 · GAD65（抗原特异性免疫）

浆细胞与致病抗体 · 上游 BCMA / CD38
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL 维持浆细胞（BCMA、CD38），浆细胞产生 IgG，FcRn 让 IgG 循环延长半衰期；阻断 FcRn 可快速清除致病抗体。

常在同一试验里出现的靶点

CD19 · BCMA · CD20 · CD3 · BTK · BAFF / APRIL · 补体 C5 · JAK（泛） · IL-6 / IL-6R · CD38
