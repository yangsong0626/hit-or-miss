靶点小结

为什么重要

MAT2A负责合成SAM，是细胞主要的甲基供体。约15%的肿瘤存在MTAP与CDKN2A共缺失，MTA蓄积会部分抑制PRMT5。此时再抑制MAT2A、降低SAM，可进一步压低PRMT5活性，形成合成致死。这一关系已由功能基因组筛选验证，为按MTAP缺失选择患者提供了依据。

从临床结果学到了什么

  • 临床证据仍很薄弱：本站跟踪的4个小分子项目（S095035、IDE397、InSilico未命名化合物）均处于1期或1/2期，尚无读出，也无失败记录。未来6个月内没有已登记的主要完成节点，近期缺少检验该机制的关键数据。

剩下的机会

  • 本站跟踪项目多以MTAP缺失实体瘤做篮式入组，仅胃食管癌和肺腺癌被单独列出。胰腺癌、间皮瘤、尿路上皮癌等MTAP缺失高发瘤种，可以作为单独验证队列的假设。
  • 四个项目均为小分子单药或剂量探索。机制上，MAT2A抑制与MTA协同型PRMT5抑制剂，或与紫杉类等化疗联合，可能实现更深的通路抑制，值得设计联合研究来检验。
  • 患者选择和药效标志物尚需标准化：MTAP缺失用IHC还是NGS判定、血浆SAM下降幅度能否预测疗效，都会影响早期信号的解读。
