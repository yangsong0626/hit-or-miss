可能原因

编辑分析

注册库没有填写原因，背景是安全性。JAKARTA 是 JAK2 抑制剂 fedratinib（SAR302503）在骨髓纤维化中的关键试验，疗效达标，但 2013 年因出现韦尼克脑病病例被 FDA 叫停开发。后经补充数据分析，fedratinib 在 2019 年仍获批上市，并要求监测维生素 B1。

终止原因

未填写
