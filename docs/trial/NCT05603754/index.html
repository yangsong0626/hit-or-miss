可能原因

  • 点估计几乎落在无效线上，两组基本没有差别，更像药物本身无效
  • 各组数值非常接近，安慰剂组反应可能偏高

编辑分析

未达到。Wnt 通路抑制剂 lorecivivint 关节腔注射治疗膝骨关节炎，疼痛评分差值 -0.12，与赋形剂几乎没有差别。骨关节炎疼痛试验的安慰剂（关节腔注射）反应很高，而结构改善转化为疼痛改善需要的时间可能超过试验期，这是改善病情类骨关节炎药物的共同难题。
