可能原因

  • 各组数值非常接近，安慰剂组反应可能偏高

编辑分析

未达到。NK1 受体拮抗剂 tradipitant 在胃轻瘫中恶心评分改善与安慰剂无差别（p=0.74）。胃轻瘫试验安慰剂反应向来很高，症状评分又主观、波动大，这是此类药物反复失败的共同原因。安全性无明显问题，失败更像疗效不足或终点不够敏感。
