信号通路与上下游 34

箭头从上游指向下游，斜杠分隔同一环节上并列的靶点；没有箭头的是同一疾病机制下的相关靶点分组。

RAS–MAPK
EGFR / HER2 / HER3 / c-MET / ALK / ROS1 / RET / FGFR（泛） / TRK (NTRK) → SHP2 → RAS（泛 / RAS-ON） / KRAS G12C / KRAS G12D / KRAS（泛 / 其他突变） → SHOC2 / RAF（泛） / BRAF → MEK → ERK
生长因子受体经 SHP2 激活 RAS，再依次激活 RAF、MEK、ERK，驱动增殖。
PI3K–AKT–mTOR
EGFR / HER2 / HER3 / 胰岛素受体 → PI3Kα / PI3K（其他） → AKT → mTOR
受体激活 PI3K，经 AKT 到 mTOR，调控生长和代谢。
肿瘤血管生成
VEGF / VEGFR / Ang-2 / PDGFR / FGFR（泛）
VEGF、Ang-2、PDGF 和 FGF 共同驱动血管新生。
激素驱动肿瘤
KAT6 → ER (ESR1) / AR → CDK4/6
KAT6 调控雌激素受体的转录；雌激素受体驱动乳腺癌（经细胞周期蛋白 D 激活 CDK4/6），雄激素受体驱动前列腺癌。
细胞周期
CDK4/6 → CDK2 / CDC7 → WEE1 / PKMYT1 → Aurora A / PLK1 / KIF18A
G1/S 由 CDK4/6 和 CDK2 推进；G2/M 由 WEE1、PKMYT1 把关，Aurora A、PLK1、KIF18A 负责有丝分裂。
DNA 损伤应答
ATM / ATR → WEE1 / PKMYT1 → PARP1 / PARP（泛） / POLQ (Polθ) / WRN
ATM、ATR 感知损伤，经 WEE1 让细胞周期停下修复；PARP、Polθ、WRN 是不同修复途径，各自和特定缺陷合成致死。
凋亡
BCL-2 / BCL-XL
BCL-2 家族蛋白阻止线粒体凋亡。
JAK–STAT
IL-4Rα / IL-13 / IL-6 / IL-6R / IL-23 / IL-23R / IL-2 (受体) / IL-15 / IFNAR / I 型干扰素 / IL-12 → JAK（泛） / JAK1 / JAK2 / TYK2 → STAT3 / STAT6
细胞因子受体经 JAK 激活 STAT；IL-4/IL-13 走 STAT6，IL-6 和 IL-23 走 STAT3。
2 型炎症
TSLP / IL-33 / ST2 → IL-4Rα / IL-13 / IL-5 / IL-5R / IL-31 / IL-31RA → STAT6
上皮受损释放 TSLP、IL-33，激活 Th2 和 ILC2，产生 IL-4、IL-13、IL-5，引起哮喘、特应性皮炎和 COPD 急性加重。
IL-23 / Th17
TL1A / IL-23 / IL-23R / IL-12 → IL-17A/F / TNF / IL-36R
IL-23 维持 Th17 细胞，产生 IL-17A/F；TL1A 促进 Th17，TNF、IL-36 放大肠道、关节和皮肤炎症。
先天免疫与炎症小体
TLR7/8/9 / TLR4 → IRAK4 / NLRP3 / STING / ENPP1 → IL-1β / IL-1R / IL-18 / IL-6 / IL-6R / IFNAR / I 型干扰素
TLR 经 IRAK4 激活 NF-κB；NLRP3 炎症小体产生 IL-1β 和 IL-18；STING 感知胞质 DNA，ENPP1 降解其信号分子 cGAMP。
B 细胞受体信号
CD19 / CD22 / CD20 → BTK
CD19、CD22 是 B 细胞受体的共受体，信号经 BTK 传递；CD20 是 B 细胞清除抗体的靶点。
浆细胞与致病抗体
BAFF / APRIL → BCMA / CD38 → FcRn
BAFF/APRIL 维持浆细胞（BCMA、CD38），浆细胞产生 IgG，FcRn 让 IgG 循环延长半衰期；阻断 FcRn 可快速清除致病抗体。
T 细胞检查点
PD-1 / PD-L1 / CTLA-4 / LAG-3 / TIGIT / TIM-3 / NKG2A / ILT2 / ILT4 (LILRB) / CBL-B / HPK1
PD-1、CTLA-4 是第一代；LAG-3、TIGIT、TIM-3、NKG2A 是常见的联用尝试；CBL-B、HPK1 是胞内刹车。
腺苷免疫抑制
CD39 → CD73 → Adenosine A2A/A2B
ATP 经 CD39、CD73 降解成腺苷，作用于 A2A/A2B 受体抑制 T 细胞。
“别吃我”信号
CD47 → SIRPα
肿瘤细胞上的 CD47 和巨噬细胞上的 SIRPα 结合，阻止吞噬。
共刺激
CD40 / CD40L / OX40 / OX40L / 4-1BB
OX40/OX40L、4-1BB、CD40/CD40L 增强 T 细胞和抗原呈递；在自身免疫里则反过来阻断。
肠促胰素与体重
GLP-1R / GIPR / 胰高血糖素受体 (GCGR) / 胰淀素受体 / MC4R / GDF15 / GFRAL / FGF21 / Myostatin / GDF8 / 激活素 / ActRII / ALK7
GLP-1R、GIPR、胰高血糖素受体和胰淀素受体是减重药的主轴；MC4R 在下丘脑；GDF15、FGF21、肌肉保护（Myostatin/ActRII）是补充方向。
血脂
PCSK9 / ANGPTL3 / APOC3 / Lp(a) / CETP
PCSK9 降解 LDL 受体；ANGPTL3、APOC3 抑制脂蛋白脂肪酶；Lp(a) 和 CETP 是独立风险通路。
代谢性脂肪肝
THR-β / FGF21 / FXR / FASN / PNPLA3 / GLP-1R
THR-β、FGF21、FXR 改善肝脏脂肪代谢；FASN 抑制从头合成脂肪；PNPLA3 是遗传风险基因。
RAAS 与血压
肾素 / AGT → AT1 受体 / 醛固酮合酶 (CYP11B2) → 盐皮质激素受体 / 内皮素受体
肾素切 AGT 生成血管紧张素，作用于 AT1 受体；醛固酮合酶产生醛固酮，作用于盐皮质激素受体；内皮素是另一条缩血管通路。
凝血
因子 XII / 组织因子 (TF) → 凝血因子 XI / TFPI → FVIII 模拟 (FIXa × FX) → 抗凝血酶
接触途径从 FXII 到 FXI，外源途径由组织因子启动、TFPI 抑制；两者汇合后由 FVIII/FIX 放大生成凝血酶，抗凝血酶负责关停。血友病药物从 FVIII 模拟、TFPI、抗凝血酶三个方向重新平衡。
血小板
VWF / P2Y12
VWF 介导血小板黏附，P2Y12 介导血小板活化。
激肽释放酶–缓激肽
因子 XII → Kallikrein (KLKB1) → 缓激肽 B2 受体
FXII 激活血浆激肽释放酶，产生缓激肽作用于 B2 受体，引起遗传性血管性水肿发作。
补体
C1s / C1q / MASP-2 / MASP-3 / 补体因子 B / 补体因子 D → 补体 C3 → 补体 C5
经典途径（C1s/C1q）、凝集素途径（MASP-2）、旁路途径（因子 B、因子 D）汇合到 C3，再到 C5 和膜攻击复合物。
铁代谢与红细胞
TMPRSS6 / 铁调素 / TfR1 / 丙酮酸激酶 (PKR) / Hb / HbF 诱导
TMPRSS6 抑制铁调素；TfR1 负责铁摄取；PKR 激活剂和 HbF 诱导用于溶血性贫血。
TGF-β 超家族
TGF-β / 激活素 / ActRII / Myostatin / GDF8 → ALK2 (ACVR1) / ALK7
TGF-β、激活素、肌生长抑制素和 GDF 通过 ALK 受体激酶信号；ALK2 突变导致进行性骨化性纤维发育不良。
发育信号通路
Wnt 通路 / Hedgehog / SMO / TEAD
Wnt、Hedgehog 和 Hippo–TEAD 通路在部分肿瘤里异常激活。
阿尔茨海默病
β-淀粉样蛋白 → Tau
淀粉样蛋白级联假说：β-淀粉样蛋白沉积在先，随后 Tau 缠结扩散。
帕金森病
LRRK2 / GCase / GBA → α-突触核蛋白
LRRK2 和 GCase 是遗传风险，汇合到 α-突触核蛋白聚集。
ALS 与额颞叶痴呆
SOD1 / C9orf72 / Sortilin / 颗粒体蛋白 / SARM1
SOD1、C9orf72 是 ALS 的致病基因，颗粒体蛋白缺失导致额颞叶痴呆，SARM1 驱动轴突变性。
精神与睡眠
多巴胺受体 / 毒蕈碱受体 M1/M4 / TAAR1 / 5-HT2A / NMDA 受体 / κ 阿片受体 / GABA-A 受体 / 食欲素受体
精神分裂症从多巴胺受体转向毒蕈碱 M1/M4 和 TAAR1；抑郁有 5-HT2A 致幻剂、NMDA 和 κ 阿片；睡眠是食欲素受体。
疼痛、癫痫与咳嗽
Nav1.7 / Nav1.8 / Nav（其他） / Kv7 (KCNQ) / SV2A / P2X3 / CGRP / CGRP 受体 / FAAH / MAGL / CB1
Nav1.7/1.8 是外周痛觉通道；Kv7、SV2A 用于癫痫；P2X3 用于慢性咳嗽；CGRP 用于偏头痛。
表观遗传与转录依赖
